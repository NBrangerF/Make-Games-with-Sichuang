# 接起机制：拿到东西以后，规则接着做什么

“轮抽＋组合计分”还不是可执行的规则。拿来的东西什么时候能用？交出去以后放哪儿？一次可以交几组？本课把这些连接写进山谷邮站的一个配件实验。

## 摆好这次的初始状态

这是新的原创局部阶段。林和乔各 0 分。林面前已有一张红色地址卡，乔面前已有一张蓝色邮资卡；所有卡都公开。公共区另有一张红卡和一张蓝卡。另留一个空的“已交付”区，卡进那里后本阶段不会回来。颜色只是本实验规定的分类，不表示真实邮件的要求。

林先行动，乔后行动。每人必须从公共区拿一张仍在那里的卡，加入自己面前。然后可以交出自己的一红一蓝，放入已交付区并得 3 分；也可以不交。每次行动最多交一组，不能用别人的卡。没有交易、补牌或其他效果。

乔的行动及其交付机会都结束后，阶段才结束。剩余卡不计分；已得分数保留。本课记录这段结果，不接入邮站前两课或过河主线的分数。

## 先取得，再检查是否能交付

林拿公共区的蓝卡，面前变成一红一蓝，可以交付。他交出这两张卡，得 3 分，面前没有卡。公共区此时只剩红卡。

乔拿剩下的红卡，和自己的蓝卡组成一组。他交出这两张卡，也得 3 分。阶段结束：两人各 3 分、都没有剩余卡；公共区空，已交付区有两红两蓝。

公共区在乔拿卡时已经空了，但不能立刻跳到结束：乔还没有处理这次行动中的交付机会。把“公共区空了”当作立即结束，会错误地让林得 3 分、乔得 0 分。

## 换一个合法选择，再追踪两个人

回到初始状态。林这次拿红卡，面前有两红，没有蓝，不能交付；仍为 0 分。公共区只剩蓝卡。乔拿蓝卡后有两蓝，没有红，也不能交付。

阶段结束，两人各 0 分，各保留两张同色卡。公共区空，已交付区也空。轮抽决定谁获得哪些材料，交付规则决定材料怎样转换成分数；二者接起来，才产生刚才两个不同的结果。

这里没有“拿得越多就越好”的结论。两个过程每人都只新增一张卡，差别是它是否与已有卡组成可交付的一组。

## 只移动检查时点，结果也会变

仍用同样的初始卡和先后顺序。现在只把交付机会移到拿卡之前：玩家先决定是否交出一红一蓝，然后拿公共卡；拿完不再检查。每次行动仍最多交一组，最后一个人行动结束才结束阶段。

林最初只有一红，不能交付；随后拿蓝卡。乔最初只有一蓝，也不能交付；随后拿红卡。两人最后各握着一红一蓝，却都得 0 分，因为自己的交付时点已经过去。

| 相同选择：林拿蓝，乔拿红 | 拿卡后交付 | 拿卡前交付 |
| --- | --- | --- |
| 林／乔得分 | 3／3 | 0／0 |
| 林的剩余卡 | 无 | 一红一蓝 |
| 乔的剩余卡 | 无 | 一红一蓝 |
| 已交付区 | 两红两蓝 | 空 |

两个版本的机制名字可以相同，接法却不同。要向另一位设计者解释变化，直接说“新拿到的卡能否赶上本次交付”，比说“组合不顺”更容易核查。

## 自查：有两组，也未必能交两次

回到拿卡后交付的规则，只改林的初始持有：林有两红一蓝，乔仍有一蓝；公共区仍为一红一蓝。林拿蓝卡，乔随后拿红卡，两人都尽可能交付。这段结束时各得多少分，林剩什么？

答案：林拿卡后有两红两蓝，但每次行动最多交一组，所以只得 3 分，剩一红一蓝。乔拿红后交出一组，也得 3 分。已交付区共两红两蓝，公共区空。林剩下的那组不会在阶段结束时自动计分，因为结束计分规则没有给它分数。

## 将连接处写进自己的原型

为一次完整行动写出次序：取得材料、检查条件、支付或交出、获得效果、检查结束。你的游戏未必采用这个顺序；关键是把自己的顺序明写出来。如果一个效果能再次触发，另写次数或停止条件。不要让玩家用“应该还能再做吧”替设计者补规则。

先用纸片重演一个会成功的过程，再重演一个不满足条件的过程。完整游戏仍要补更长的流程和目标，这些局部实验不能代替整局测试。

## 来源与范围

概念研究参考 Geoffrey Engelstein 与 Isaac Shalev 的 *Building Blocks of Tabletop Game Design*，第二版，CAR-06 “Drafting”与 SET-01 “Set Valuation”：取得元素的方式与组合的收益规则需要分开描述。本课的交付次序、一次一组限制和全部数字是本站设计的实验。

Kathleen Mercury 的 [Prototyping](https://www.kathleenmercury.com/prototyping.html) 鼓励尽早用足以测试主要想法的材料做原型。本课据此采用少量纸片演示；不照搬课堂工期，也不声称这些算例已经证明学习效果。
