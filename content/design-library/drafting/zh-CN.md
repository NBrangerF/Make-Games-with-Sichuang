# 轮抽：我拿走这一张，谁的选择变了？

公开摆着两张相同的月亮卡，为什么有人愿意先拿一张，有人却想先拿太阳？因为同一张牌，对不同玩家未必有同样价值。拿牌又会改变别人接下来能选什么。轮抽的判断就发生在自己的需要与逐渐减少的机会之间。

## 三个人分六张卡

下面是自行构造的局部游戏。A、B、C 三人分配六张公开图案卡：太阳 1、太阳 2，月亮 1、月亮 2，星星 1、星星 2。编号只用于区分同图案的两张牌，不影响分数。每位玩家的计分表都公开：

| 谁拿到这张卡 | 每张太阳 | 每张月亮 | 每张星星 |
| --- | --- | --- | --- |
| A | 3 分 | 2 分 | 0 分 |
| B | 0 分 | 3 分 | 2 分 |
| C | 1 分 | 4 分 | 0 分 |

按 A、B、C、A、B、C 的顺序，每人每次必须从公共区拿一张，免费、正面朝上放到自己面前。拿走的牌不补充，其他人不能再拿；不允许跳过、交换或弃牌，也没有另一个买牌阶段。两张同图案可以都拿，分别计分。

第六次取选后，每人恰有两张牌，公共区为空，立即结束。每人把自己两张的分数相加，最高者获胜，最高分并列则共享胜利。没有隐藏牌，也没有秘密目标。

## 走完一次取选，看机会如何减少

为了比较过程，先让三人采用同一种简单选法：每次都拿当前对自己分数最高的牌，同图案优先拿编号小的。这只是这里采用的选择方法，不是规则强迫玩家这样做，也不保证长远最好。

| 次数 | 玩家拿牌 | 公共区剩余数量：太阳／月亮／星星 |
| --- | --- | --- |
| 1 | A 拿太阳 1，值 3 分 | 1／2／2 |
| 2 | B 拿月亮 1，值 3 分 | 1／1／2 |
| 3 | C 拿月亮 2，值 4 分 | 1／0／2 |
| 4 | A 拿太阳 2，值 3 分 | 0／0／2 |
| 5 | B 拿星星 1，值 2 分 | 0／0／1 |
| 6 | C 只能拿星星 2，值 0 分 | 0／0／0 |

A 共 6 分，B 共 5 分，C 共 4 分，A 获胜。六张牌全部转移到三人面前，没有牌被复制或消失。

注意第三次取选。月亮对 C 值 4 分，对 B 值 3 分；C 取走最后一张月亮后，B 第二次取选的最好选择只剩星星。C 得到的分数与 B 失去的机会，是同一次取选的两个后果。即使 C 只想着自己拿 4 分，也会产生这个影响。

**轮抽**是按规定的取选过程，把牌或其他游戏要素分配给玩家。这里演示的是公开轮抽：选择池可见，取走一张就从公共机会中移除一张。它比“拿到一张牌”多了两个关系：玩家能从哪些选项中挑，以及哪些人会在自己下一次取选前改变这些选项。

## 只把第二轮的次序倒过来

重开同样的六张牌，只把取选顺序改为 A、B、C、C、B、A，常称为蛇形顺序。计分表和刚才的选法都不变。

前三次仍是 A 拿太阳 1，B 拿月亮 1，C 拿月亮 2。此时剩太阳 2、星星 1、星星 2。第四次改由 C 拿太阳 2，值 1 分；第五次 B 拿星星 1，值 2 分；最后 A 只能拿星星 2，值 0 分。

结果变成 A 3 分、B 5 分、C 5 分，B 与 C 共享胜利。A 的第一次取选没有变，第二次却晚了：原本能拿到的太阳已被 C 取走。C 第一次在三人中最后选，现在换得连续两次取选。

倒序把两次取选的位置重新搭配，并不自动保证公平。这里三人的计分需求本就不同，也只比较了一种选法；不能凭一次分配判断哪个顺序普遍更好。设计师需要看牌的相对价值，以及重要的组合是否会在某个位置之前被拿光。

## 公开挑选、传递手牌与截走机会

轮抽也可以采用传递手牌的形式：各人从收到的一组牌中留下牌，把未选的部分传给下一人。大家可以同时作决定，但每个人通常只面对自己收到的那部分选项，某张牌可能在到自己手中以前就被拿走。它与全桌面对同一个公开池，在信息和可接触的选项上有区别。

随机发一张、没有选择，不是在演示这里的轮抽关系；从自己早已拥有的手牌中决定先用哪张，则主要是手牌使用问题。轮抽负责分配机会，取得的牌何时能用、是否还要付使用费，需要另外规定。本例直接留牌计分，因此没有后一笔费用。

玩家有时会拿走自己不太需要、别人很需要的牌。这是轮抽可能产生的一种选择行为，不是每次都应执行的额外规则。它可能牺牲自己的收益，也需要知道或推测别人的需要。公开池越大、计分组合越多，比较的工作也可能越多；最后只剩一张时，有取牌动作，却已没有图案可选。

## 自查：截走太阳，会让 C 更好吗？

回到原顺序 A、B、C、A、B、C。前两次不变，第三次 C 改拿太阳 2；之后三人继续按“当前对自己分数最高”取选。结果怎样？

剩下月亮 2 和两张星星。A 第四次拿月亮 2，B 第五次拿星星 1，C 最后拿星星 2。总分为 A：3＋2＝5；B：3＋2＝5；C：1＋0＝1。A 和 B 共享胜利。

C 确实让 A 比原过程少了 1 分，但自己从 4 分降到 1 分。截走别人所需，不等于改善自己的结果。回到自己的设计，可以记录：玩家预测会留下哪张牌？在下一次轮到他之前，谁需要它？如果总有一种牌无人愿取，先查它对不同玩家何时有用，以及拿它会放弃什么，而不是只看它有没有漂亮的牌面。
