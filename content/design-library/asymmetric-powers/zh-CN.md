# 非对称能力：相同资源，哪些行动规则不同？

两名玩家各有 2 能量，不代表他们能完成同样的事情。一个人可能少花一次移动，另一个人可能免付交付费。非对称能力要落实为“谁在什么条件下，可以怎样改变共同规则”，而不只给角色起不同名字。

## 能力、资源、信息与角色分开看

Geoffrey Engelstein 与 Isaac Shalev 在 ACT-12 “Variable Player Powers”讨论专属行动以及对通常行动、结算程序的修改。本页采用这个能力层面的范围。

仅在开局多放一枚能量，是初始资源差异；只有一人能看到订单，是信息差异；扮演不同角色，则还可能改变目标或叙事身份。这些安排可以与能力并存，但必须分别写出。若两人只是名字不同，能做的行动和费用完全一样，就没有本页要观察的能力差别。

## 同一条路线上的两位送件员

这是两人原创局部阶段。路线只有三个地点，依次相连：仓库 0—近站 1—远站 2。林与乔都从 0 出发，各带 1 包裹、2 能量，起始 0 分。近站有一份 3 分合同，远站有一份 6 分合同，均公开且各只能完成一次。能量库与已交付区初始为空。

共三轮，每轮林先、乔后，各行动一次。通常行动为：移动到相邻地点，付 1 能量；在有未完成合同的近站或远站送达，付 1 能量并交出本人 1 包裹，取得合同分；或等待，不付费也不产生效果。费用先支付，包裹进已交付区，合同移到完成者面前。费用、包裹或合同不足就不能送达。

可以同处一地，不能交易、借能量或重新拿包裹。移动与送达是两种行动：到达或经过站点不会自动完成合同。所有支付的能量进入能量库，不补充到玩家手中。第三轮两人都行动完才结束，合同提前完成也不增加或取消名额。比较已获合同分，最高者胜，同分并列；剩余能量、包裹和位置不计分。

两项能力从开始就公开，归属固定：林的“跨步”每阶段可用一次，把一次移动变成沿线连续走两边，不能折返，仍付 1 能量；只有走满两边才使用这项能力，先付费并标记用过，再移动。乔的“免交付费”把本人的送达能量费从 1 改为 0；仍需花一次行动、交出包裹并取得未完成合同，移动费照付。

因此林可以用跨步从 0 到 2，却不能无限次跨步；乔可以没能量时送达，却不能没包裹时送达。两人不能使用对方的能力。

## 过程一：林去远站，乔去近站

第一轮林跨步到 2，付 1 能量，剩 1；乔普通移动到 1，付 1，剩 1。林经过近站没有取合同，两份合同都还在。

第二轮林先付最后 1 能量，交包裹完成远站合同，得 6 分；乔以自己的能力免能量费，交包裹完成近站合同，得 3 分。第三轮两人等待。

结束时林在 2、乔在 1，能量为 0／1，包裹都已交出，能量库有 3，已交付区有 2 包裹；两份合同分属林、乔。林以 6 比 3 获胜。跨步用一次行动走完了远路，免交付费让乔留下了一枚能量，但剩余能量在本阶段并不加分。

## 过程二：近站先被林完成

回到相同初始状态。第一轮林与乔都普通移动到 1，各付 1 能量，剩 1。两人可以同处近站；林尚未用跨步。

第二轮林先付最后 1 能量，交包裹取得近站 3 分合同。乔不能再交同一份合同，于是花最后 1 能量普通移动到 2。第三轮林等待，乔虽然为 0 能量，仍能用免交付费交出包裹，取得远站 6 分合同。

结束时林在 1、乔在 2，两人能量与包裹都为 0；能量库有 4，已交付区有 2 包裹。乔以 6 比 3 获胜。林的跨步能力尚未使用，不能因此自动补一份奖励。两条过程显示能力何时能发挥作用，没有证明两个角色整体平衡。

## 只提高林跨步的费用

现在只把跨步的能量费从 1 改为 2，普通移动与乔的能力不变。沿用过程一的计划：林先跨步到远站，第二轮若能合法送达就送达，否则等待，第三轮等待；乔仍移动近站、送达、等待。这个“付不起则等待”的选择在比较两版时相同。

第一轮林能支付 2 能量完成跨步，但到站后能量为 0。第二轮他没有送达所需的 1 能量，因此选择等待，既不交包裹也不得分。乔仍以免交付费完成近站合同，得 3 分；最后两人等待。

| 完整过程 | 剩余能量：林／乔 | 剩余包裹 | 合同分 |
| --- | --- | --- | --- |
| 林远站、乔近站 | 0 / 1 | 0 / 0 | 6 / 3 |
| 林近站、乔远站 | 0 / 0 | 0 / 0 | 3 / 6 |
| 跨步改付 2，沿用第一计划 | 0 / 1 | 1 / 0 | 0 / 3 |

改价版能量库仍有 3，已交付区只有乔的 1 包裹；林还携带 1 包裹，远站合同未完成。地图位置与过程一相同，结果却不同，因为到达位置与能否支付下一步费用是两件事。

这个对照只识别跨步费用在当前预算、行动次数和合同下的后果。若要判断平衡，还需改变先手、任务距离、奖励、资源以及对手选择，并观察实际玩法，不能把一次胜负或两次分数交换当成证明。

## 自查：能力到底免除了什么？

1. **乔在远站有 0 能量、1 包裹，远站合同还在，能送达吗？**能。免掉的是送达的能量费；交出包裹、使用行动和合同可领取这三项条件仍要满足。不会倒赚 1 能量。
2. **林刚取走近站合同，乔在同一地点也能交包裹拿 3 分吗？**不能。合同只有一份，已经完成。同格不代表有第二份合同。
3. **林用过跨步后还剩 1 能量，可以再次从 2 跨回 0 吗？**不能。付得起费用不等于还有使用次数；林仍可选择合法的普通移动。
4. **两人三轮都等待，谁获胜？**两人均为 0 分，按规则并列；各保留 2 能量、1 包裹，公共合同都未完成。
