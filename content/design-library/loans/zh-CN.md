# 借款：手上有钱，为什么还可能还不起？

银行交来4币，当前确实多了4币可花；但若规则同时要求以后交回5币，就不能只记前半笔。设计借款，要把可支出现金、后续责任和最终成绩放在不同栏里，再看它们何时发生联系。

《Building Blocks of Tabletop Game Design》第二版第7章ECO-07“Loans”，印刷第322–323页，讨论了帮助启动项目、补救缺钱，以及期末扣分、持续付息或降低收入等不同处理。书中的贷款并不都要求归还本金。下文只构造一种有明确到期偿还的游戏规则；所有币和项目均为虚构，不复现书中的商业游戏。[书目信息](https://doi.org/10.1201/9781003179184)

## 把借款条款写在行动之前

单人进行三轮，起始1币、0项目分；银行有29币。没有手牌或隐藏结果，所有费用提前公开。开局可选择借一次4币，或者不借；这项决定不占轮内行动，之后不能再借。选择借款，就从银行拿4币，并放置一枚“第3轮末应还5币”的债务标记。

5币由本金4和固定费用1组成；费用不随轮数增长，没有每轮利息或复利。不能提前偿还、主动少还，也不能用分数代替钱。每轮只做下列一项：

| 行动 | 条件和费用 | 立即结果 |
| --- | --- | --- |
| 开幕项目 | 仅第1轮可选，付银行5币 | 得10项目分 |
| 小项目 | 付银行3币，可在不同轮重复 | 得5项目分 |
| 打工 | 不收费 | 从银行领3币 |
| 跳过 | 无条件 | 不发生变化 |

付不起费用的行动不能执行，不先拿奖励再补钱。第3轮行动后自动处理债务：有5币就全还；不足时必须交出全部现金，每少1币扣3分，然后移除债务标记。欠额已经转换为罚分，本段不再追收，也不能用后来取得的钱撤销罚分。这里没有玩家被淘汰。

随后结束，最终分数＝项目分＋余币−罚分。分高的计划较好，同分视为相同成绩，允许负分。钱币只在玩家和银行之间转移，总量始终为30；债务与罚分不是额外的钱币。

## 借相同的钱，第三轮留下什么？

两条路线都开局借4，手上从1变5，应还额同为5。前两轮行动相同，第三轮才分开。

| 时点 | 路线A：留出还款能力 | 路线B：再换一笔项目分 |
| --- | --- | --- |
| 第1轮 | 花5做开幕项目：余0币、10项目分 | 相同：余0币、10项目分 |
| 第2轮 | 打工领3：余3币、10项目分 | 相同：余3币、10项目分 |
| 第3轮行动 | 打工领3：余6币、10项目分 | 花3做小项目：余0币、15项目分 |
| 到期结算 | 还5，余1币，无罚分 | 无现金可还，短缺5币，罚15分 |
| 最终分数 | 10＋1＝11 | 15−15＝0 |

A的现金流水为1＋4−5＋3＋3−5＝1，银行最后有29币。B最后现金为0，银行有30币。两条路线债务标记都移除，但B记录的15罚分仍参与终局计算，不能因为标记消失就当作没借过。

B第三轮的小项目是合法的：当时有3币，确实付得起。问题出现在之后的强制结算。把“行动现在能做”当成“这条路线最终更好”，便漏掉了后面的责任。新增5项目分也不能用来替代还款；项目分只在终局账本里发挥作用。

A同样不是把借到的4币直接变成4净分。借款让第1轮的5币项目及时可做；后来两次打工补回现金，并承担1币费用。若根本不借，三轮都打工，最终是1＋3＋3＋3＝10币，也就是10分。这个明确的替代路线，才让A的11分有可比较的含义。

## 只把到期提前到第2轮末

重开，保持本金、费用、三轮时限和所有行动不变，只将债务结算改在第2轮行动后。沿用A的开幕项目→打工→打工路线：

| 时点 | 现金与责任 |
| --- | --- |
| 借款后、第1轮项目后 | 从5币付掉5币，余0；应还5 |
| 第2轮打工后 | 有3币；到期交出3，短缺2，记录6罚分并移除债务 |
| 第3轮打工后 | 新得3币，保留；不能倒回上一轮补交 |
| 终局 | 10项目分＋3余币−6罚分＝7 |

同一行动路线由11变7。提前结算还改变合法选择：若想沿用B第三轮的小项目，第2轮末已被收走全部现金，第3轮开始为0币，不能支付3币费用，必须另选合法行动。

这不证明提前到期的版本最高只能7分。玩家可以重新安排整条路线；例如仍然不借、三轮打工，就有10分。表格证明的是期限改变了这条项目路线，以及它之后能做的事，不能把一条固定路线的结果冒充所有策略的上限。

## 设计时还要检查什么

先确定借款出现的用途：是让暂时缺钱的人继续参与，还是让玩家争取即将消失的项目机会。本例开幕项目只存在一轮，因此资金提前可用有具体价值。如果它永远开放，或者分数也能偿债，当前算例就不能原样使用。

再检查费用与不足后果分别压在哪里。本例固定费用只收1币，真正严厉的是每欠1币扣3分。提高其中一项，不等于提高另一项；一种改变所有借款路线的成本，另一种主要改变没准备好还款的路线。罚分强度是否让玩家不愿尝试，需要试玩，不能从这两张表直接得知。

借款、投入项目和取得收益也不是同一个动作。本例借款先给现金并附责任；项目消耗现金换分；打工领取现金。可以把借款与延迟回报组合，但要特别核对回报是否在债务到期之前进入手中。它与“收入与生产”相关，却不能只凭现金增加就断定后续没有代价。

## 自查（含答案）

1. 第1轮拿到4币后，应还4还是5？**5：本金4加固定费用1，不再逐轮加息。**
2. B第三轮为什么可以做小项目，却最终只有0分？**行动时能付3币，但后来无钱偿债，15项目分被15罚分抵消。**
3. 提前到期版能用第3轮的新钱取消罚分吗？**不能。第2轮已按不足规则结算并关闭债务，罚分不撤销。**
4. 借款后做开幕项目，再连续跳过，最终会怎样？**现金0、项目分10、短缺5罚15，最终−5分。负分在本例允许。**
