# 边玩边学 01：只分析一局里的一个时刻

## 读完以后，你会得到什么

你会从最近玩过的一局里，抓住一个让人停顿、改计划、追问、等待或惊讶的时刻，把它整理成一张可以再次核对的设计记录。

这张记录不会只写“很好玩”“不平衡”或“这个机制很聪明”。它会留下七样东西：

1. 一个有开始和结束的具体时刻。
2. 摄像机能看见、麦克风能听见的行动。
3. 当时桌面上真正可见的信息。
4. 一条暂时的“规则—选择—后果—体验”关系。
5. 至少两种可能的其他解释。
6. 这一次还不能知道的事情。
7. 下一局只需要追的一个观察问题。

这里不要求你会 MDA、5PM 或任何英文术语。第一次做时，只要记住两句话：

> 先拍下发生了什么，再猜它为什么发生。

> 一个时刻可以提出好问题，不能替所有玩家下结论。

## 先选入口：你现在有多少时间

### 只有十五分钟

完成这五步：

1. 写下一局里的一个时刻。
2. 写三条看得见或听得见的行动。
3. 圈出当时最重要的一条规则或限制。
4. 写两种可能解释。
5. 写下一局只观察的一个问题。

### 第一次做，而且不知道怎样写

直接使用本文的《Kingdomino》构造示范。你不需要拥有或玩过这款游戏；先读“只够理解这个时刻的规则”，再跟着表格判断哪些是事实、哪些是猜测。

### 已经习惯写游戏笔记

在基础记录后多做三件事：补齐行动前的信息状态，写出至少一个反事实版本，并说明你准备怎样把关系迁移到自己的游戏，而不是复制原游戏的表面机制。

## 第一步：冻结一个时刻，不评价整款游戏

“分析《某游戏》”太大。一次游玩可能包含几十轮、许多玩家、偶然抽牌、教学错误和桌边交流。把它们压成一句评价，会让你找不到哪条规则与哪次行动真正有关。

一个可用的时刻通常有四个边界：

| 边界 | 要回答的问题 | 合格例子 |
| --- | --- | --- |
| 人 | 谁正在做决定或回应 | 玩家 A 正在选择一张骨牌，B、C、D 已经等待 |
| 开始 | 从哪个可见信号开始 | 四张新骨牌翻开，轮到 A 选择 |
| 结束 | 到哪个可见结果停止 | A 把国王放上选择的骨牌，下一位开始行动 |
| 焦点 | 这次只追哪一种变化 | A 怎样在眼前价值与下一轮顺序之间取舍 |

下面这些仍然太宽：

- “这款游戏的策略是什么？”
- “孩子为什么不喜欢它？”
- “拍卖机制好不好？”
- “这局输掉是因为运气吗？”
- “我想完整分析所有互动。”

可以缩成：

- “第二次竞价时，玩家为什么停止加价？”
- “第一次需要查规则前，玩家连续做了哪些动作？”
- “公开下一轮顺序后，谁改变了当前选择？”
- “最后一轮揭示隐藏目标时，哪名玩家先检查了别人的区域？”

只选一个时刻不是说其他问题不重要，而是给第一次分析一个能完成的边界。

## 第二步：先写摄像机记录

把纸分成两栏：左边写“能被看见或听见”，右边写“我认为它表示”。先只填左边。

### 摄像机可以记录什么

- 手指指向哪张牌、哪个区域或哪名玩家。
- 眼睛或头部在几个信息区之间移动。
- 拿起组件又放回，改变摆放位置，遮住或公开信息。
- 停顿了多久；停顿从什么事件开始，到什么动作结束。
- 玩家说出的原话，包括提问、确认、笑声或叹气。
- 选择前后可见状态怎样改变。
- 设计者是否补充规则、暗示策略或纠正操作。

### 摄像机不能直接知道什么

- “他很贪心。”
- “她觉得没有选择。”
- “大家已经无聊。”
- “这个机制制造了紧张感。”
- “玩家理解了设计意图。”
- “他这样做是为了阻挡我。”

这些句子可能以后成为解释，但不能放进事实栏。摄像机能记录“玩家看了三张牌后说‘好像只能拿这个’”，却不能直接记录“玩家没有选择”。后者仍要检查合法行动、信息理解和玩家自己的描述。

### 感受词不是禁词

“紧张”“后悔”“安心”“兴奋”非常重要，只是要注明来自哪里：

- 如果玩家说“我刚才很紧张”，记录为**玩家自述**。
- 如果观察者看见玩家握住代币十秒并深呼吸，记录动作；“可能紧张”放在**解释候选**。
- 如果规则要求在时间结束前行动，“时间压力存在”可以是规则事实；“每个人都会感到紧张”仍不是事实。

## 第三步：补上“当时能够知道什么”

行为离不开信息。不要用结局以后才知道的事情解释当时的选择。

在决定发生前画一张小快照：

| 信息 | 当事玩家能看见吗 | 其他玩家能看见吗 | 当时确定吗 |
| --- | --- | --- | --- |
| 可选行动 | 是 / 否 / 部分 | 是 / 否 / 部分 | 是 / 否 |
| 每项立即代价 |  |  |  |
| 行动后的公开状态 |  |  |  |
| 随机或隐藏结果 |  |  |  |
| 其他玩家的资源与位置 |  |  |  |
| 下一轮顺序或机会 |  |  |  |

如果玩家漏看了一条公开信息，不要立刻写“这条信息无效”。先记下信息放在哪里、何时出现、是否有人提醒、玩家什么时候第一次注意到它。机制可能没有问题，呈现可能有问题；也可能规则与呈现一起工作，不能轻易分开。

## 一段完整示范：《Kingdomino》里的高号选择

### 先声明示范边界

下面是一段**本站依据官方规则构造的虚构教学记录**。玩家 A、B、C、D、他们的动作、停顿和话语都不是一次真实测试的数据，也不是规则书中的故事。它只帮助你练习分开“规则事实、构造记录、本站推断和未知”。

《Kingdomino》官方产品页把游戏标示为 8 岁以上、2–4 人、约 15 分钟。这里采用四人规则，只介绍理解这个时刻需要的部分：每轮有四张骨牌按号码从低到高排开；本轮行动顺序由玩家先前选中的骨牌顺序决定。玩家在自己的回合先把先前骨牌放入王国，再把国王放到下一排一张尚未被选的骨牌上。官方规则说明，较高号码通常有更高价值，例如混合地形或王冠，但选择较高号码也通常让玩家下一轮较晚选择。游戏计分会把相连同类地形的格数与该区域的王冠数相乘。

这几条是规则背景，不等于玩家一定会算分、一定会看见顺序代价，也不等于游戏必然制造某种感受。

### 构造的一个时刻

情境设在一场四人游戏的中段。A 因为上一轮选到当前队列的最低号骨牌，所以这轮最先行动。A 已经把上一轮选中的骨牌放进自己的王国；下一排四张骨牌已经翻开并按号码排好。最低号骨牌没有王冠；最高号骨牌带有一个王冠。按 A 此刻的王国形状看，这张骨牌下一轮至少有一个同时符合地形相连与 5×5 王国边界的合法摆放位置。

从“A 放好上一张骨牌，开始比较下一排四张骨牌”开始，到 A 把国王放上最高号骨牌结束，本站构造以下记录：

1. A 从低号到高号依次看过四张骨牌。
2. A 把手指放在最高号骨牌上，又移到自己王国中的同类地形区域。
3. A 看了一眼其他三名玩家的王国。
4. A 停顿数秒，说：“我想先锁住这个王冠，但下轮我就最后挑了。”
5. A 把国王放在最高号骨牌上。
6. B 随后开始选择剩余骨牌。

再次提醒：这六条是为了教学而写的**构造记录**，不是项目观察到的真人行为。真实分析时，你必须填写实际发生的动作和原话。

## 第四步：把记录分成四层

### 第一层：规则与状态事实

只写可以从当前规则和桌面确认的关系：

- A 这轮先选。
- 四张骨牌按号码由低到高排列。
- 最高号骨牌有一个王冠；按 A 此刻的王国形状看，它下一轮至少有一个同时符合地形相连与 5×5 王国边界的合法摆放位置。
- A 若把国王放在最高号位置，下一轮会排在选择队列后部。
- A 最终预定了最高号骨牌；它要到 A 的下一回合才会尝试放入王国。

这里还没有“正确策略”“高风险”“贪分”或“紧张”。

### 第二层：可见或可听行动

- A 按顺序看四张骨牌。
- A 在高号骨牌和自己的王国之间移动手指。
- A 查看其他三人的王国。
- A 明说王冠和下一轮最后选择。
- A 最终把国王放到最高号骨牌上。

如果是真实记录，最好保留大致时点和设计者是否介入。精确到毫秒通常没有必要，除非时间本身就是问题。

### 第三层：暂时系统推断

现在才可以提出一个可讨论的关系：

> 最高号骨牌让 A 现在锁定一项下一回合可能放入王国的王冠收益，同时把 A 排到下一轮选择队列后部；在这个构造时刻里，A 的话语和指向动作与“把可预定的区域价值和未来选择余地放在一起比较”相符。

把它画成一条链：

> 骨牌号码与顺序规则 → 现在锁定的下回合王冠机会和下轮选位形成取舍 → A 比较骨牌、王国与他人状态 → A 接受下轮晚选 → 可能产生“先锁定价值还是保留选择机会”的张力

注意“相符”和“可能”。动作支持这项解释，却没有排除其他原因；体验词也没有得到真人自述。

### 第四层：替代解释与未知

至少写两种其他解释。本例可以写：

- **空间适配解释**：A 选择高号骨牌，主要因为它看起来最容易在下一回合合法放入王国，而不是因为王冠收益。
- **阻挡解释**：A 查看他人王国后，可能更想拿走某名对手需要的地形。
- **规则复述解释**：A 的话只是复述顺序规则，不代表它真的进入决定权衡。
- **偏好解释**：A 可能单纯偏爱某种地形、图案或收集王冠。
- **误解解释**：A 可能错误估计下一轮顺序或计分价值。

仍未知包括：

- A 给每个因素多少权重。
- 如果最高号骨牌不能连接，A 是否仍会选择它。
- 其他三名玩家是否注意并利用了顺序关系。
- 这个决定是熟练策略、临时直觉还是规则误解。
- 真人是否感到紧张、满意、后悔或平静。
- 相同关系在不同轮次、人数、经验和桌面呈现下是否仍出现。

写下未知不是分析失败。它告诉你下一局值得看什么，也防止一个漂亮故事盖过证据。

## 第五步：只带一个问题去下一局

不要把所有未知同时塞进观察表。选择一个最能区分解释的问题。

本例的下一次观察问题可以是：

> 当玩家现在可以锁定一张带王冠、并在下一回合尝试摆放的高号骨牌，而这会让自己下一轮较晚选择时，玩家在落下国王以前，是否会同时查看自己的可连接区域和下一轮选择顺序？

这个问题有几个优点：

- 指定了可重复识别的局面。
- 观察的是查看、指向、说话和落子等行为。
- 不要求玩家必须选择高号骨牌。
- 不预先宣布规则一定制造某种情绪。
- 即使没有出现预期行为，也会留下有用结果。

### 同时写一个反驳信号

> 如果相关局面出现多次，而玩家在选择前不查看顺序、不提未来机会，并且事后也说顺序没有进入考虑，那么“顺序取舍在这些局面中被主动权衡”的解释会受到削弱。

“受到削弱”不等于整款游戏失败。也可能是图形呈现、教学、经验、当前局势或样本范围造成；下一步应根据事实决定是否继续查，而不是强行保护原解释。

### 开始观察前先写边界

- 记录哪一版规则和哪个游戏版本。
- 记录人数、是否第一次玩、谁负责教学。
- 说明是否录音或录像，并先取得同意。
- 不把儿童、同学、朋友或资深玩家中的一组自动代表所有人。
- 参与者可以随时停下，不必为了完成记录继续不舒服的游戏。

## 第六步：把关系迁移到自己的设计

学习不是把《Kingdomino》的王冠、骨牌或号码复制进自己的游戏。要带走的是更抽象、但仍能落桌的关系：

> 现在锁定的未来收益和下一轮行动位置被同一次选择连接，玩家可能需要在“先预定什么”与“以后还有多少选择”之间取舍。

在自己的游戏里填写：

1. 哪个选择让玩家**现在锁定一项未来收益**？
2. 同一个选择怎样改变玩家**下一次机会、顺序或信息**？
3. 这两项是否在决定发生前都能被看见？
4. 玩家会做出什么可观察动作，说明他们把两者放在一起比较？
5. 哪个行为会削弱你的解释？

例如，你的游戏没有骨牌，而是让玩家选择任务：高奖励任务会让玩家下一轮最后挑装备。你可以先预测玩家会在任务奖励和剩余装备之间来回查看，再制作一段只出现两次该决定的短切片。这样迁移的是机会成本与顺序关系，不是表面材料。

### 写一个反事实版本

反事实不是马上改规则，而是帮助看清哪条关系在工作：

- 如果锁定高收益不再改变下一轮顺序，玩家还会停顿吗？
- 如果顺序代价存在，但选择时不可见，会发生什么？
- 如果所有人下一轮同时选择，当前高收益还有同样的意义吗？

你不必把三个版本都做出来。只挑一个最能区分解释的变化，并先写行为预测。

## 没有完整现场记录时，怎样诚实地补课

很多人第一次尝试“边玩边学”，是在游戏已经收好以后才想起来做记录。你可能只记得一个选择、一个笑声或一句大意。这仍然可以成为学习起点，但不能把后来拼出的故事伪装成现场事实。

先给资料标身份：

- **现场记录**：游玩时或紧接着写下，能指向明确动作、原话和桌面状态。
- **事后回忆**：隔了一段时间以后想起，顺序、用词或状态可能已经模糊。
- **规则重建**：根据规则书或组件恢复当时有哪些合法关系，不代表玩家真的注意到它们。
- **同桌者补充**：另一名参与者的回忆；它是独立视角，不自动比你的回忆更正确。

如果只剩事后回忆，可以这样写：

> 我大约记得 A 先看了高号骨牌，后来提到下一轮顺序；准确先后和原话未知。根据官方规则，高号位置会影响下一轮选择顺序。我的暂时解释是两个信息可能一起进入判断，但现有回忆不足以确认。

不要给模糊记忆加引号。只有确信是逐字记录时才使用引号；否则写“约”“大意是”或“我记得”。也不要因为规则允许某项行动，就补写玩家一定看见、考虑或理解了它。规则事实回答“系统允许什么”，现场记录才回答“这一次发生了什么”。

### 最小补救动作

1. 画出你仍能确认的开始状态和结束状态。
2. 把确定动作、模糊回忆和规则重建分成三栏。
3. 请同桌者各自写一份，再比较一致与冲突，不先讨论出“统一答案”。
4. 把冲突留在未知栏，例如“先看顺序还是先看王国，回忆不一致”。
5. 下一局提前准备一张小纸，只记录这个冲突需要的三个时点。

如果什么都无法确认，也可以只保存一个候选问题：“下一次出现相似选择时，我要看玩家先检查哪一处信息。”这比写一份流畅但不可核对的复盘更有价值。

### 两人互审：把推断找出来

完成记录后，可以请一名同伴只做三件事：给摄像机能拍到的句子画实线，给关于原因或感受的句子画波浪线，给无法从现有资料判断的句子加问号。你们只讨论标签，不争论游戏好不好。

若同一句同时包含事实和推断，就把它拆开。例如“玩家因为害怕下轮晚选而停顿”应拆成“玩家停顿数秒”“玩家随后提到下轮最后选择”“害怕是观察者推测”。拆开以后，事实没有减少，解释的来路反而更清楚。

儿童可以使用“我看见、我猜、我还不知道”三色纸；成人或团队可以再加版本、时点和资料身份。两种做法遵守同一证据边界，只是记录精度不同。

- 与这项解释相符的行为：______
- 可见后果：______
- 体验词来自玩家自述，还是观察者推测：______

把它合成一句：

> 当______规则把______和______连接起来时，我们看见玩家______；这与______解释相符，但还不能排除______。

### E. 不确定性

- 另一种解释 1：______
- 另一种解释 2：______
- 这一次仍不知道：______
- 不能推广到：______

### F. 下一局

- 只观察这一个问题：______
- 支持信号：______
- 反驳或削弱信号：______
- 需要保持不变：______
- 若问题根本没出现，我会记录：______

## 十五分钟练习

### 0–2 分钟：回想

想起最近一局里你最清楚的一个停顿或改变计划的时刻。若想不起，就用本文的构造示范。

### 2–5 分钟：画边界

写人、开始、结束和焦点。删掉“整个游戏”“一直”“大家”“必然”等大词。

### 5–8 分钟：写三条行动

只写手、眼、组件、桌面变化和原话。看到“觉得、想要、因为、无聊、聪明”时先把它移到解释区。

### 8–11 分钟：画关系链

填写：

> 一条规则或限制 → 一项选择压力 → 一个看见的行动 → 一个后果 → 一个暂时体验解释

### 11–13 分钟：写两个“也可能”

至少写两种其他原因。若写不出来，问：玩家是否没看见信息？是否在遵守社交习惯？是否受空间、主题、领先位置、教学或个人偏好影响？

### 13–15 分钟：留一个问题

下一局只带一个能被看见的问题。它必须允许答案是“没有发生”。

## 给不同背景学习者的脚手架

### 如果你是小学生或第一次分析

只用三种标签：

- **我看见**：手和组件发生了什么。
- **我猜**：为什么可能这样。
- **下次看**：下一局要注意什么。

每栏写一句就算完成。可以请同伴帮忙记录，但不要让同伴替玩家解释心里在想什么。

### 如果你很少玩现代桌游

分析你熟悉的象棋、扑克牌、儿童游戏或聚会游戏也可以。重要的不是游戏复杂，而是时刻具体。例如“对方走完这一步后，我第一次碰了哪枚棋子”和“我为什么改走另一条路”已经足够。

### 如果你是教师或带领者

先让学习者口头说“我看见”，再允许说“我觉得”。不要以术语多少评分。可以把同一记录分给两组，让他们比较不同解释，并圈出需要更多证据的句子。

### 如果你已经是设计师

多记录版本、参与者范围、设计者介入和反事实预测。真正的难度不是写出漂亮因果链，而是主动寻找能削弱它的信号，并在证据不足时保留未知。

## 常见误用

### 把胜负结果当成原因

“我输了，所以这个选择不好”只描述结果。要回到当时信息：选择有哪些、代价何时可见、哪次状态变化让结果出现。

### 把玩家建议当成诊断

“应该把这张牌改成 3 点”是一个方案，不是原因证据。先记录建议出现前的具体问题，再决定是否制作该版本。

### 把沉默当成没有思考

玩家不说话，可能仍在比较；也可能没看见信息、不想拖慢桌面或根本不关心。记录视线、拿取和时点，必要时在决定后用中性问题询问。

### 用事后解释覆盖当时信息

玩家看见结局后很容易讲出连贯理由。事后自述有价值，但要和当时可见信息及行动分开保存。

### 先选框架，再硬塞游戏

MDA、5PM、形式要素和其他框架都是镜头。先有问题，再选能帮助区分规则、行为或体验的少量概念。框架名称不是答案。

### 把一次时刻写成设计师意图

除非设计师有可核验的一手说明，否则“作者想让玩家……”应改为“这个关系可能支持……”。即使有作者说明，也只能写作者报告的意图，不能由此证明玩家实际体验。

### 一边观察，一边指导正确策略

当你提示玩家“要看下一轮顺序”，后续行为已经受到提示影响。可以教学，但要记录提示时点；若问题是玩家能否自己注意，就在下一场不提示的适当测试中再看。

## 完成这份练习的信号

- 你的时刻有明确的人、开始、结束和焦点。
- 事实栏只包含可见行动、可听原话、规则或桌面状态。
- 体验词注明来自玩家自述还是观察者推测。
- 你没有使用结局以后才知道的信息代替当时信息。
- 系统推断至少连接一条规则、一项选择压力、一个行为和一个后果。
- 你写出至少两种替代解释。
- 你明确列出一次游玩仍不能知道什么。
- 下一局只追一个可观察问题，并允许预测被削弱。
- 迁移到自己项目的是关系，不是原游戏的美术、名称或表面组件。
- 你没有把构造示范、单个玩家或单次游玩写成普遍规律。

## 来源与形成方式

本单元是本站原创完整中文学习内容，不是外部规则书、论文或课程文章的全文翻译。正文中的《Kingdomino》片段是根据官方规则构造的虚构教学记录，不是实际参与者数据。

- [Blue Orange Games《Kingdomino》官方产品页](https://www.blueorangegames.com/games/king-domino)：用于核验 8 岁以上、2–4 人、约 15 分钟，以及选取顺序和王冠计分的简要说明。产品说明不是玩家效果研究。
- [Blue Orange Games《Kingdomino》第二版英文规则](https://blueorangegames.com/webroot/img/games/rules/cfa0f38157341a002eab1100aab478ea-Kingdomino-Rules-US-2nd-Edition.pdf)：用于核验四人选择顺序、骨牌号码、下一轮顺序、摆放与计分关系。本单元没有翻译完整规则，也没有复载图片、版面或完整骨牌内容。
- [Ian Schreiber, Game Design Concepts Level 3](https://gamedesignconcepts.wordpress.com/2009/07/06/level-3-formal-elements-of-games/)：作者课程讲义支持把分析与评分、找错区分开，先描述形式要素，再看它们运行时的结果，最后提出设计解释。本站把它收缩成适合初学者的“先拍照，再解释”。
- [Ian Schreiber, Game Design Concepts Level 19](https://gamedesignconcepts.wordpress.com/2009/08/31/level-19-game-criticism-and-analysis/)：支持设计者通过游玩他人游戏，追踪主要决定、机制、体验及其可能关系。原课作业范围较大，本单元有意把第一步缩成一个时刻。
- [Hunicke、LeBlanc 与 Zubek, MDA](https://www.cs.northwestern.edu/~hunicke/MDA.pdf)：用于提醒读者分开设计者提供的机制、运行中形成的动态和体验语言。MDA 在这里是关系镜头，不提供因果证明或质量分。
- [Mora-Zamora、Brenes-Villalobos 与 Durán, 5-Part Model](https://www.clei.org/cleiej/index.php/cleiej/article/view/473)：用于检查一项机制中的呈现、操控物、资源、决定和目标。论文以电子游戏案例为主，并把进一步真实环境测试留给未来工作，因此本文不把它写成已验证的桌游玩家模型。
- 项目研究《从设计师角度分析游戏的资源入口 01》《研究全文笔记 02》和本站既有“事实—推断—未知”内容契约。

这些来源支持分析游戏的价值、规则—运行—体验的分层和形式要素检查，但没有证明本文的构造玩家会真实出现，也没有规定所有分析必须使用七步。本单元的时刻边界、摄像机记录、信息快照、四层表、单问题观察、反驳信号、一页模板、十五分钟练习和迁移方法均为本站教学综合。
