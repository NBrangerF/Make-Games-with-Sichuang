# The Crew：为什么赢下一墩，反而会让全队失败？

在《The Crew: The Quest for Planet Nine》中，大牌既能拿走目标，也能把目标从需要它的队友面前抢走。设计合作游戏时，不能只把个人分数相加；还要检查胜利由谁取得、别人能知道什么，以及成功发生的次序。

本文采用 Thames & Kosmos 英文基础规则，产品691868、文件内码691868-02-060320，不使用《Mission Deep Sea》。三个独立例子都是本站构造的合法发牌与行动路线，不是规则书例题或真人试玩。均为四人，顺时针甲→乙→丙→丁；不开求救信号，无额外沟通限制。每例从发牌后开始，甲持火箭4，先选任务并首攻。小任务牌不计入40张出牌；蓝、绿、黄、粉各有1—9，另有火箭1—4。[规则第2、8—10页](https://www.thamesandkosmos.com/manuals/full/691868_Crew_Manual.pdf)

下表向读者展示全手牌以便复算；游戏中的队员只能看自己手牌、公开任务及合法公开的信息，不能照着全知表讨论。已经收走的牌墩也不是随时可翻的公共档案：规则只允许查看最近一墩。表内“蓝8、9”表示蓝8和蓝9，各表每行恰好十张。

## 角度一：合作目标改变的是大牌的用途

采用真实任务2：两张任务牌，没有顺序标记。此次抽出蓝2与绿3，甲先取蓝2，乙取绿3。[日志PDF第3页左栏任务2，印刷第4页](https://cdn.1j1ju.com/medias/dd/5a/3a-the-crew-the-quest-for-planet-nine-log-book.pdf)

| 队员 | 完整初始手牌 |
| --- | --- |
| 甲 | 火箭4；蓝8、9；绿2；黄1、4、7；粉2、5、8 |
| 乙 | 火箭1；蓝2、5；绿4、7；黄2、5；粉3、6、9 |
| 丙 | 火箭2；蓝1、4；绿3、5、6；黄3、6；粉1、4 |
| 丁 | 火箭3；蓝3、6、7；绿1、8、9；黄8、9；粉7 |

第一墩依次出甲绿2、乙绿7、丙绿3。现在轮到丁，他有三张绿牌，必须跟绿，不能打火箭3；但没有必须压过绿7的义务。[跟牌与火箭见规则第3—4页](https://www.thamesandkosmos.com/manuals/full/691868_Crew_Manual.pdf)

- 丁出绿1：乙的绿7最大，乙收下四张牌，包括自己任务要求的绿3；乙翻面该任务。
- 从同一选择点改出绿9：丁收下绿3，拿到它的却不是任务持有人乙，整次任务尝试立即失败。不能再打几墩补救。[任务结算见规则第10页](https://www.thamesandkosmos.com/manuals/full/691868_Crew_Manual.pdf)

继续绿1的分支。乙赢了上一墩，所以由乙首攻：乙蓝2→丙蓝4→丁蓝6→甲蓝9。四人都有蓝牌，出牌合法；甲拿到蓝2，第二张任务完成，全队成功，立即结束。共收走8张，四人各余8张，合计32张，不需要把它们打完。

这里，丁放弃一次取墩帮助乙完成任务，乙再把蓝2送进甲能赢的墩。两人的作用不能用“各赢几墩”排序。任务把牌的价值连接到特定接收者，大牌保留在谁手里，也就改变了下一步协作。

这条路线证明的是所列行动可以成功，不能证明队员在隐蔽信息下必然找到它，也不能推出丁永远应该留大牌。任务归属、剩余花色或先手改变后，同一张绿9可能正是救场的牌。

## 角度二：公开一张牌，同时规定它能说什么

另开一次任务2，甲先取绿2，乙取黄4。完整发牌如下，乙尚未使用沟通：

| 队员 | 完整初始手牌 |
| --- | --- |
| 甲 | 火箭4；蓝2、5；绿6、9；黄5、9；粉1、4、7 |
| 乙 | 火箭1、2；蓝1、4；绿1、4；黄1、7；粉3、6 |
| 丙 | 蓝3、6；绿2、5、8；黄2、4；粉2、5、8 |
| 丁 | 火箭3；蓝7、8、9；绿3、7；黄3、6、8；粉9 |

任务分好、第一墩尚未开始时，乙把黄7亮在面前，绿色沟通标记放顶部，表示它是自己最大的黄牌；再拿提示牌入手。黄7仍是可出的第十张牌，提示牌不是额外的出牌。乙此时还持黄1，不能把标记放中间宣称“唯一”。[规则第5—7页的沟通文字与组件图](https://www.thamesandkosmos.com/manuals/full/691868_Crew_Manual.pdf)

沿下面路线逐墩结算；箭头顺序就是出牌顺序：

| 墩 | 出牌与结算 |
| --- | --- |
| 1 | 甲黄9→乙黄1→丙黄2→丁黄3。甲收牌，没有目标牌；乙剩9张可出牌，含桌上的黄7。 |
| 2 | 甲黄5→乙黄7→丙黄4→丁黄6。乙收下黄4，完成自己的任务；黄7打出，提示牌移出手中，沟通标记翻红。 |
| 3 | 乙绿1→丙绿2→丁绿3→甲绿9。甲完成绿2，全队成功。每人余7张，共28张，另有12张已收走。 |

第一墩之后，黄7成为乙唯一的黄牌，顶部标记仍不能搬到中间。第二墩打出它以后，乙也不能再沟通另一张牌：沟通额度是每人每次任务尝试一次，只能在一墩开始前使用，第一墩前也可以。标记保留的是那次声明，没有持续更新整副手牌。[规则第5、7页](https://www.thamesandkosmos.com/manuals/full/691868_Crew_Manual.pdf)

这个信号确实排除了“乙还有黄8或黄9”，却没有承诺黄7将赢。第二墩的丁仍有黄8；若改打黄8，黄4会落到丁面前，任务失败。乙不能通过标记传达一整套未来出牌指令，其他人也不能从一次声明读出未公开的所有牌。

对初学设计者，这里值得分别检查“允许公开什么”“何时公开”“信息是否更新”。桌面上的黄7降低了记忆负担，提示牌提醒它仍待出，红面则记录额度已用。这些物件承担不同工作。是否真的让某组新手更轻松，需要观察他们使用组件时的错误，本文没有测量这种效果。

## 角度三：先完成的目标，不一定出现在第一墩

第三次采用真实任务3：两张任务牌，附数字1、2。这次按抽出顺序将粉2配1、蓝3配2；甲先选粉2及其标记，乙取蓝3及其标记。任务1必须先于任务2完成；这里的数字不是墩数。[日志PDF第3页左栏任务3，印刷第4页](https://cdn.1j1ju.com/medias/dd/5a/3a-the-crew-the-quest-for-planet-nine-log-book.pdf)；[规则第14—16页](https://www.thamesandkosmos.com/manuals/full/691868_Crew_Manual.pdf)

| 队员 | 完整初始手牌 |
| --- | --- |
| 甲 | 火箭4；蓝1、8；绿1、4、7；黄1、4；粉6、9 |
| 乙 | 火箭1；蓝2、9；绿2、5；黄2、5；粉1、4、7 |
| 丙 | 火箭2；蓝3、6；绿3、6；黄3、6；粉2、5、8 |
| 丁 | 火箭3；蓝4、5、7；绿8、9；黄7、8、9；粉3 |

甲先出火箭4，乙、丙、丁依次跟火箭1、2、3。甲赢下第一墩，没有完成任何目标，但也没有违反次序。四枚火箭全部离场，余36张。

甲继续首攻粉9，乙粉1、丙粉2、丁粉3跟出，甲取得标记1的粉2。第三墩甲出蓝1，乙蓝9、丙蓝3、丁蓝4跟出，乙取得标记2的蓝3。任务按1→2完成，全队成功；桌外已收12张，四人各余7张。

现在回到第一墩结束时，保持发牌不变，只把第二墩换成甲蓝1→乙蓝9→丙蓝3→丁蓝4。乙虽然是蓝3的正确接收者，标记1的粉2却尚未完成，因此立即失败。不能声称“反正第三墩能补粉2”，先后条件检查的是发生过的过程。

这说明任务除了指定终点，还能规定抵达路线。没有目标的第一墩仍可能改变后续条件：本例清掉了四枚火箭，并保留甲的先手。我们没有据此证明开火箭4最优。另须注意，本例两张任务属于不同人，才必然要由不同墩完成；不能扩写成所有带顺序标记的任务都必须分墩，规则另有同一人同墩完成连续标记的情况。

## 作者亲述与本站分析

Thomas Sing 在 IELLO 于2021年3月1日转载的访谈中回忆：他先想到预先指定谁赢哪张牌，次日拿去测试；当晚沟通尚未完善，下一周才带来后来采用的沟通规则。太空主题是数周后才加入的。[访谈“Acte 1 : de l’idée au prototype”](https://iello.fr/thomas-sing-nous-parle-de-the-crew/)

以上是作者对开发过程的回忆。本文从中得到的练习建议是：先测试“接收者改变后，出牌是否产生合作需要”，再单独测试信息规则如何影响决定。它不是作者提供的通用设计方法，也不能把他对早期原型的评价当作本文三个例子已通过玩家验证。

## 带答案的自查

1. 角度一中，丁为何不能用火箭3，又为何可以出绿1？**丁仍有绿牌，必须跟绿；跟牌不等于必须赢墩。**
2. 角度一结束时，为什么还有32张没打也算成功？**两张任务已经由各自持有人完成；成功不要求清空手牌。**
3. 角度二第一墩后，能把黄7的标记移到中间吗？**不能；黄7虽成唯一黄牌，原沟通标记的位置不能更新。**
4. “乙最大的黄牌是7”能保证第二墩乙赢吗？**不能，丁仍有黄8；本路线中丁选择了黄6。**
5. 角度三第一墩没完成标记1，为什么不失败？**数字规定任务之间的完成顺序，不规定在哪一墩完成。**
