[进入网站](https://luozhuo-tabletop-design.vercel.app/#course/reading/all/zh-CN) · [去玩猜拳](https://luozhuo-tabletop-design.vercel.app/#play/zh-CN) · [English](README.md)

如果《蛇梯棋》每次掷两颗骰子，却只能选一颗移动，会怎样？如果输了石头剪刀布，仍然能抢到一个据点，你还会照原来的方式出手吗？

一条小规则，就可能改变一局游戏。**一桌点子**想邀请你亲手试试：玩一玩，读一个例子，用纸片做份草稿，再请别人来玩。

你可以跟着课程做出第一份作品，也可以带着眼前的问题，找一个有帮助的案例。课程、文章与桌游案例都提供中文和英文。

## 先玩一手，再改一条规则

<a href="https://luozhuo-tabletop-design.vercel.app/#play/zh-CN"><img src="public/media/rule-lab/icon.png" alt="石头剪刀布：一个学习游戏设计的游戏" width="150" align="right"></a>

**石头剪刀布，只是开始。**

在规则试验场里，先和电脑猜一拳，再选一个变化：加入资源，试一种角色能力，把手牌和据点放在一起。继续玩，看看哪些决定变容易了，哪些让你多想了一会儿。

回退功能出现后，还可以撤回一条规则。拿掉它再玩，往往比继续加规则更能看清它的作用。

## “刚才有点奇怪”，就是一个好起点

朋友停下来问了一句。最后几回合比想象中长。每个人总是选同一个动作。

从这些时刻出发，我们一起看选择、信息、资源和节奏，也学着安排试玩、理解反馈、修改说明。每个概念尽量回到桌上正在发生的事，读者不必先背一套术语。

文章采用原创解释与分析，并提供可以继续查阅的来源。例子和经验都有适用情境，值得放进自己的游戏里试一试。

## 带一个游戏、一个问题，或一支笔来

可以自己读，也可以和朋友比较一局熟悉的游戏，或把一个问题带进设计工作坊。课程里的许多练习，用几张纸和一支笔就能开始。
