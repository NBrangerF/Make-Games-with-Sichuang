## 1. 接受的设计方向

本轮不是换一套风格，而是在用户已经认可的 V5 基础上做“保留式升级”。接受的方向是：

> 当代设计博物馆 × 高级桌游出版物

设计旋钮冻结为：设计差异度 `7`、动效强度 `4`、视觉密度 `3`。五张接受概念图是：

- `design/concepts/playable-archive-v5-1-home-premium.png`
- `design/concepts/playable-archive-v5-1-resource-premium.png`
- `design/concepts/playable-archive-v5-1-reading-premium.png`
- `design/concepts/playable-archive-v5-1-methods-premium.png`
- `design/concepts/playable-archive-v5-1-tool-premium.png`

概念图提供构图、材质、层级和视觉语气，不替代现有中文内容、路由、资源入口、工具行为与无障碍合同。

## 2. 截图与浏览器方法

1. 首先尝试 Codex 内置浏览器。首次打开时本地预览尚未重新启动，页面保留为 Chromium `ERR_CONNECTION_REFUSED` 数据错误页；服务器恢复后，Browser Use 的 URL 安全策略拒绝从该错误页重新导航。
2. 因此本轮本地与响应式 QA 使用项目内 Playwright Chromium 后备。这个后备只承担浏览器导航、原生尺寸截图、响应式与互动证据，不改变设计判断。
3. 五张概念图与五张最新实现图在同一轮 `view_image` 中以原尺寸核验；首页概念与实现均使用 `1504×1046` 原生尺寸。
4. 最后一处文字对比与图片署名修正后，再次把首页概念、首页最新实现、方法概念、方法最新实现和 `320×800` 最新实现放进同一轮视觉核验。

## 4. 首屏文案差异

正式首屏文案为：

- `从一个问题开始`
- `桌游设计 / 学习资源站`
- `从学习、分析或正在解决的问题开始。核心内容可直接在站内阅读中文版本。`
- `开始学习桌游设计`
- `从设计师角度分析一款游戏`
- `按正在解决的设计问题找资料`
- `搜索全部资料`

与概念图相比，正式实现保留了“从一个问题开始”眉题。第一次精修曾移除它，但 `qa:resource-v2` 的产品门禁指出该句属于新手方向脚手架，因此恢复为轻量编辑眉题。正式实现没有采用概念图为了构图而生成的替代性图片标题或新增模块。

## 5. 本轮修复的实质不匹配

1. 首页标题曾在桌面端断成“桌游设计学 / 习资源站”。最终用语义化双 `span` 固定为两行完整词组。
2. 首页视觉标本曾同时显示标题、英文编号、独立四项许可清单和来源尾注，信息密度过高。最终删除额外板头与总表，把完整摄影者和许可放回每张图的图注。
3. 三个首页入口曾分别用蓝、红、黄表达栏目。最终统一为钴蓝，避免把危险色和提醒色误当分类色。
4. 完整译文状态“完整中文译文”曾因列宽断成两行。最终状态栏使用 `max-content + minmax(0, 1fr)`，桌面保持单行，移动端自然纵排。
5. 页脚曾直接显示 `playable-archive-v5-1` 开发构建字符串。最终隐藏该技术字段，构建信息仍可在“数据与隐私”页面查看。
6. 页脚“数据与隐私”触控高度曾低于 24px。最终最小高度为 44px。
7. 方法索引的非选中编号继承红色且说明对比不足。最终编号改为中性浅色，标题与说明提高深色背景对比。
8. 320px 图片署名首轮因单行省略而截断摄影者或许可。最终许可允许自然换行，四张图的完整署名均可见。

## 6. 有意差异

- 首页没有照抄概念图的对称 2×2 图片格；正式实现使用一张主图、两张分析图和一张横幅，更像策展图录，也让四种桌游结构有不同权重。
- 首页三个入口没有沿用概念图的红黄栏目块。设计手册明确规定红、黄、绿只承担语义状态。
- 资源阶段轨没有复制概念图的多色节点；阶段不是警告或成功状态，正式实现使用主色与中性线。
- 方法页没有复制概念中的立体书本、书脊和彩色索引条。正式实现提取“深色目录 + 白色编辑跨页”的结构，减少仿物材质和小年龄读者的竞争线索。
- 工具页保留真实 HTML 输入控件和当前业务结构，没有为了概念图对称而重排字段或虚构摘要。
- 经典桌游照片仅限内部学习构建。摄影许可明确不等于画面中商业桌游美术、商标和产品外观已经获得公开复用许可。

## 8. 最终签收

保真签收：最终实现忠实保留了接受概念的品牌气质、首页重心、编辑层级、页面角色、材质纪律和核心互动；没有剩余会改变设计方向或资源优先逻辑的实质性不匹配。

自主设计签收：本轮没有机械复制概念图。实现根据现有信息架构、跨年龄脚手架、站内中文阅读、语义色纪律、真实 HTML 控件与素材权利边界做了明确取舍；上述有意差异均属于设计判断，而非遗漏。
