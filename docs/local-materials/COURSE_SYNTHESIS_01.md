# 本地课程综合 01：从“玩过”到“做出可测试改动”

状态：review  
日期：2026-08-13  
材料：2019–2020 原创桌游解构与设计课程；2023 桌游设计·光华营地五课时

## 核心判断

两套课程共同采用“例子先于术语、改造先于发明、测试先于美化”的教学顺序。它们没有先给学生一份机制百科，而是让学生完成四次认知转换：

1. 从普通玩家变成有观察问题的玩家；
2. 从“好不好玩”变成“何时纠结、有哪些选择、后果是什么”；
3. 从识别机制变成改变一个变量并预测结果；
4. 从解释自己的想法变成制作短原型并让别人验证。

## 可迁移的六步新手路径

### 1. 带着问题玩

观察不是先给整款游戏打分，而是记录：每回合有哪些选择、信息来自哪里、哪一刻最纠结、何时等待、玩家怎样影响彼此。

### 2. 给已发生的行动命名

机制词汇在游玩后出现，用来压缩已经见过的行为。这样“轮抽”“同时行动”“手牌管理”不是孤立定义，而是可以指回桌面事件的标签。

### 3. 只改变一个变量

从飞行棋或石头剪刀布等熟悉系统开始，选择一个变化轴：选择、移动、信息、资源、互动、主题或胜利条件。写下保持不变的部分，防止练习无限膨胀。

### 4. 写出预测

改变机制不是终点。设计者要写：预计玩家会做什么不同决定、产生什么互动、感受怎样变化。它自然连接 MDA 的假设链。

### 5. 做短原型、测一个问题

课程使用 1–3 回合和 2–3 回合原型，说明“完整一局”不是第一轮的必要条件。测试问题要对应预测，而不是泛泛问喜欢不喜欢。

### 6. 分离反馈与改动

三层测试表把“收到的反馈”和“根据反馈做的修改”放在相邻栏。网站进一步增加观察、体验、问题、建议与设计决定的区分。

## 网站转译决定

新增“改造熟悉游戏”练习，字段包括：

- 基础游戏；
- 希望改变的玩家经历；
- 一个变化轴；
- 保持不变的核心；
- 规则改动；
- 对玩家行为/互动的预测；
- 最小原型范围；
- 一个测试问题。

练习不会使用原课件题库、原文说明或专有版式。它是基于两套课程结构与已有研究主张重新设计的原创产品内容。

## 与外部研究的交叉验证

- Kathleen Mercury 同样从游玩、机制、主题、原型和反馈构成连续课程；
- Game Design Concepts 用纸笔练习和受限任务降低进入门槛；
- MDA 支持把“规则改动”写成对动态与体验的预测；
- 最小原型实践文章支持由测试问题决定原型范围；
- 测试研究提醒线上媒介无法覆盖触感、空间和细微社交互动。

本地课程不是证明这些方法普遍有效的实验。它们提供经过多次教学使用的设计案例，外部研究则帮助限定解释范围。
