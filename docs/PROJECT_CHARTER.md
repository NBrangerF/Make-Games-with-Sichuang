# 项目章程

状态：draft  
日期：2026-08-13

## 愿景

为中文新手桌游设计师提供一条清晰、可信、能真正动手的学习路径。网站既介绍游戏设计理论，也保存设计师和玩家的实践智慧，并提供小型交互工具，帮助用户跨过“知道一些术语但做不出可测试原型”的断层。

## 核心用户

第一优先用户是第一次或前几次设计桌游的人。他们常见的任务不是“掌握完整理论”，而是：

- 把模糊想法改写成可验证的玩家体验目标；
- 选择够用的机制并搭出廉价原型；
- 知道下一次测试究竟要回答什么；
- 从反馈中区分症状、原因和玩家建议；
- 写出陌生人能独立使用的规则；
- 判断何时继续、重构、暂停或进入投稿/出版准备。

第二优先用户包括教师、工作坊主持人和已有作品但需要查阅专项资料的设计师。

## 第一版价值主张

用户进入网站后，可以在 15 分钟内：

1. 定位自己所处的设计阶段；
2. 获得该阶段最重要的一个问题、一份短指南和一个可操作模板；
3. 找到经过说明和分级的延伸资料；
4. 生成或保存下一次迭代所需的设计记录。

## 内容边界

第一版聚焦现代桌面游戏与卡牌游戏的一般设计流程。桌面角色扮演、教育游戏、兵棋、集换式卡牌、出版/众筹各保留入口，但不在首版展开为完整专业课程。

## 明确不做

- 不把 BoardGameGeek 的机制分类简单翻译成百科全书；
- 不声称存在唯一正确的线性设计流程；
- 不把销量、评分或获奖等同于设计质量；
- 不未经许可转载书籍、付费课程或博客全文；
- 不在首版承诺 AI 自动“平衡”或自动生成完整好游戏。

## 成功指标（首版）

- 5 名新手能在无口头指导下找到符合自身阶段的内容；
- 至少 4 名用户完成一次“体验目标 → 假设 → 原型 → 测试记录”闭环；
- 80% 的核心资源条目具有作者、来源类型、适用阶段、摘要和访问状态；
- 关键流程页达到基本移动端与无障碍检查要求；
- 交互工具的输出可导出为本地文件，不强制登录。
