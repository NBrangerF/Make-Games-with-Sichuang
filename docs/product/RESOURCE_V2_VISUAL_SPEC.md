# 资源入口 V2 视觉规格

日期：2026-08-22  
状态：已实现；`resource-v2-05` 导航减法与工具入流桌面端、移动端核验通过  
对应主方案：[RESOURCE_SITE_V2_MASTER_PLAN.md](RESOURCE_SITE_V2_MASTER_PLAN.md)  
视觉基准：[resource-v2-home-concept.png](../../design/concepts/resource-v2-home-concept.png)

## 1. 这一版只解决什么

默认资源页只帮助读者完成一个决定：今天要从学习、分析，还是一个正在解决的问题开始。

它不在首屏同时解释设计阶段、读者身份、学习路线、筛选器、结果数量和资源条目。上述资产继续保留，但必须等到读者明确选择后再出现。

## 2. 冻结参数

- `DESIGN_VARIANCE = 3`
- `MOTION_INTENSITY = 1`
- `VISUAL_DENSITY = 3`
- 视觉语气：公共图书馆、认真编辑的中文教材、低认知负担
- 技术边界：保留 React、原生 CSS、既有深链、键盘操作和无障碍语义

## 3. 首页信息结构

页面从上到下只有：

1. 既有主导航和“仅限内部学习”状态
2. 眉题“从一个问题开始”
3. 标题“桌游设计学习资源站”
4. 一句入口说明
5. 三条开放式选择行
6. 次级文字入口“搜索全部资料”
7. 译文来源与使用范围说明

三条主入口的固定文案：

| 编号 | 标题 | 解释 |
| --- | --- | --- |
| 01 | 开始学习桌游设计 | 按适合自己的方式，走进完整的基础学习内容。 |
| 02 | 从设计师角度分析一款游戏 | 用清楚的问题拆解体验、决定、互动与系统。 |
| 03 | 按正在解决的设计问题找资料 | 从原型、测试、规则、平衡等具体困惑进入。 |

## 4. 视觉规则

### 4.1 保留

- 背景 `#fbfaf7`
- 正文 `#171717`
- 主要操作 `#0b48c6`
- 极少量批注 `#b9382f`
- 宋体感标题和清晰的中文无衬线正文
- 细分隔线、可见焦点、44 像素以上触控目标

### 4.2 删除

- 默认页中的六阶段网格
- 读者身份帮助面板
- 当前阶段的做法列表
- 当前入口的双栏说明
- 三份资料路线和下方重复资源列表
- 默认展开的搜索、筛选与结果统计
- 卡片墙、胶囊标签、嵌套边框、阴影和装饰图标

### 4.3 交互

- 整条选择行都是一个链接或按钮，标题是主要可见操作名。
- 悬停只改变文字颜色或下划线，不移动元素。
- 键盘焦点使用现有蓝色虚线焦点环。
- 页面切换不依赖动画；尊重 `prefers-reduced-motion`。
- 深链必须可以刷新、前进、后退，并恢复到相同入口。

## 5. 后续两层

### 5.1 学习方式页

标题下使用同样的开放列表，只显示四项：

1. 系统性学习
2. 看设计师怎样思考
3. 边玩边学
4. 从一个小练习开始

默认不同时展示九单元课程目录。选择“系统性学习”后，先显示下一单元，再提供完整目录文字入口。

### 5.2 游戏分析页

标题下最多显示五个普通问题：

1. 为什么会产生这种体验？
2. 玩家真正做了什么决定？
3. 玩家之间怎样互相影响？
4. 游戏怎样随时间和状态运行？
5. 玩家怎样看见、学会并执行？

“进阶形式化分析”是列表之后的次级文字入口，不与五个普通问题争夺首屏注意力。

## 6. 响应式规则

- 大屏内容宽度不超过 1040 像素。
- 768 像素以下缩小标题并压缩页边距，三条入口仍保持纵向顺序。
- 640 像素以下主导航固定为两个等宽目标，不横向滚动，也不变成需要理解的新菜单系统。
- 选择行在窄屏改成“编号、标题与解释、箭头”两列，解释不隐藏。
- 不以隐藏正文的方式制造移动端简洁。

## 7. 验收

- 首次进入 `#resources` 时，主区只出现三条主入口与搜索入口。
- 首屏没有阶段选择、受众选择、筛选器、结果统计或资源列表。
- 所有入口有可读标题、解释、可见焦点和稳定深链。
- 浏览器 1440、768、390 像素宽度没有横向溢出。
- 用户无需阅读帮助文案就能描述三条入口的差别。
- 可见界面不使用英文产品术语，不出现长破折号。

## 8. 视觉保真记录

内容包 03 使用同一 `1440×1000` 桌面视口和 `390×844` 移动视口，与已接受视觉基准逐项比较。这一包是内容层扩展，不是视觉重构；没有新增首页入口、一级入口、导航项、筛选器或工具。

| 项目 | 基准 | 当前实现 |
| --- | --- | --- |
| 首屏决定数量 | 3 | 通过，真实浏览器计数仍为 3 |
| 主区结构 | 单一开放页面流 | 通过，阶段、受众、筛选、统计和资源列表计数为 0 |
| 学习方式 | 4 个开放式选择 | 通过，仍为 4，没有增加新的一级入口 |
| 内容增长位置 | 只在读者选择学习方式后出现 | 通过，完整系统单元从 5 增至 7；新的“边玩边学”脚手架只出现在既有二级入口内，首页不受影响 |
| 系统学习清单 | 单列编号、标题与一句产出 | 通过，单元 05、06 沿用开放列表与细分隔线，没有改成卡片或仪表盘 |
| 边玩边学入口 | 既有 4 种学习方式之一 | 通过，二级页只增加一个主操作“开始第一份完整记录”，没有并排堆叠功能 |
| 完整阅读页 | 编辑型中文长文流 | 通过，标题、导语、正文和来源说明继续采用单栏层级，没有加入浮动工具或外部阅读按钮 |
| 来源译文分组 | 与本站九单元课程分开 | 通过，3 篇来源译文仍位于独立二级清单 |
| 设计师案例 | 一列决定问题，不做卡片墙 | 通过，5 篇案例未增加筛选、标签或排名 |
| 卡片与面板 | 首页为 0 | 通过，入口只使用分隔线和开放列表 |
| 强调色 | 蓝色操作、少量红色编号 | 通过，与既有品牌色一致 |
| 译文范围说明 | 页尾与正文状态区低调呈现 | 通过，论文页明确 Codex 主译、来源、许可与内部范围 |
| 外部跳转 | 阅读过程中不离站 | 通过，新增单元 05、06 与“边玩边学 01”正文均有 0 个可点击外链 |
| 移动端顺序 | 不隐藏正文，入口保持纵向 | 通过，`390×844` 首页与“边玩边学 01”均无横向溢出 |

以上共十四个对照点中，首页结构、入口数量、开放列表、颜色、排版层级与移动端行为均继续服从原视觉基准；内容数量只在读者已经作出选择之后增长。

### 8.1 文案差异

首页三条主入口及其说明不变，四种学习方式的名称也不变。内容包 03 只在既有二级入口后增加以下文案：

| 位置 | 内容包 02 | 内容包 03 | 作用 |
| --- | --- | --- | --- |
| 系统性学习可读清单 | 单元 00—04 | 增加“单问题测试”“从证据到下一版” | 让原型之后的测试与迭代形成连续路径 |
| 边玩边学二级页 | 只有学习方式入口 | 增加单一主操作“开始第一份完整记录” | 给不同背景读者一个明确的下一步 |
| 边玩边学正文 | 无完整示范 | 增加“边玩边学 01：只分析一局里的一个时刻” | 把观察、事实与推断拆成可照做的中文脚手架 |
| 完整阅读返回操作 | 依内容类型返回对应清单 | 新正文使用“返回边玩边学” | 返回到原二级入口，不把读者误送进系统课程 |

核心路径因此保持短而单向：`#resources` 首页 → “开始学习桌游设计” → “边玩边学” → “开始第一份完整记录” → `#resources/learn/learn-by-playing-one-moment`。浏览器自动化同时验证完整正文深链刷新后仍可恢复，返回操作回到 `#resources/learn/learn-by-playing`。

### 8.2 有意偏离

- 二级系统学习页从 5 个可读单元增长到 7 个，完整正文页也会因为可直接读完的内容而增长页面长度。这是资源完整度带来的有意偏离，不用折叠正文、分页工具或隐藏内容制造表面简洁。
- “边玩边学 01”正文在标题前保留本站原创状态、事实与推断边界说明。这比概念图的首页更具信息密度，但只出现在读者主动进入的三级阅读页。
- 实现沿用既有全站导航、页尾、本地预览状态与“数据与隐私”入口；概念图用于冻结资源首页的主区构图，不替代这些已存在的全站设施。
- 移动端允许大标题自然换行，并保持完整说明文字；这是对 `390×844` 的响应式适配，不以缩小到难读字号或删文案追求与桌面逐像素一致。

## 9. `resource-v2-05` 导航减法与工具入流

本轮同时查看接受的概念图与最新真实浏览器截图，并记录以下保真点：

| 对照点 | 当前实现 |
| --- | --- |
| 米白纸张与开放页面流 | 保留；首页、方法页和工具页都不使用卡片墙或仪表盘外壳 |
| 顶栏留白和清楚层级 | 保留；可见入口减为居中的 `找资料 / 方法与概念` 两项 |
| 宋体感大标题 | 保留；资源首页、方法入口与工具任务都以标题建立第一层级 |
| 红色斜体编号 | 保留；只作为眉题、步骤与编辑批注，不承担大面积状态编码 |
| 蓝色操作与箭头 | 保留；用于当前导航、链接、返回和开放列表方向 |
| 细分隔线、无首屏卡片 | 保留；三条资源入口、三条方法入口继续是一列开放选择 |
| 移动端纵向阅读 | 保留；`390×844` 与 `320×760` 均无横向溢出，说明文字没有隐藏 |

### 9.1 首屏文案差异

| 位置 | 接受概念图 | `resource-v2-05` | 理由 |
| --- | --- | --- | --- |
| 顶栏 | 找资料、设计路径、中文知识、辅助工具 | 找资料、方法与概念 | 暂时隐藏低价值一级入口，并把内容名称改成读者能理解的范围 |
| 资源首页主区 | 标题、导语、三个任务入口 | 完全不变 | 资源第一的首页契约已经成立，不再改写 |
| 方法首页 | 概念图未单独定义 | 解决具体任务、理解分析方法、查设计词 | 先给任务脚手架，再加载内容目录 |

### 9.2 有意偏离

- `设计路径` 和独立“辅助工具”从可见顶栏移除，但 `#path` 与 `#tools/<id>` 深链继续兼容。
- 工作单只在读者选定具体资源、完整单元、学习方式或分析问题后出现；工具页不再显示 19 个平行标签。
- 方法详情保留 `专题指南 / 理论框架 / 概念词表` 三个局部标签，旧“资源怎么读”仅保留深链兼容。
- 页尾、内部学习状态和数据隐私入口继续存在；概念图只冻结主区构图，不删除全站设施。

### 9.3 核心流程

- 资源与工具：`#resources` → `#resources/problems` → `#resources/first-prototype` → `#tools/prototype-scope` → 返回原资料组。
- 学习与工具：`#resources/learn/systematic-unit-04-minimum-prototype` → `#tools/prototype-scope` → 返回原学习单元。
- 方法入口：`#method` → “理解一种分析方法” → `#method/frameworks`。
