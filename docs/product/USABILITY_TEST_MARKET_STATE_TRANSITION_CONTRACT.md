# 可用性测试：市场状态转移契约

## 目标

验证中文新手能否在真实桌面位置读取市场、执行一笔批量交易、更新价格、补货并交接，而不是验证市场是否“平衡”。

## 参与者与材料

- 3–5 位未参与设计的玩家；至少覆盖主要玩家人数。
- 一张含 5–7 个槽位的纸面市场、两种货物、价格标记、库存与资金。
- 一张交易顺序卡和一张空白事件记录表。
- 若参与者提出需要，允许放大字号、口述、托盘或等价标记；记录协助，不把它算作失败。

## 任务

1. 从自己的座位指出当前能买的商品、价格与最大可买量。
2. 买入 3 件同类货物并说出每件/整批按什么价格结算。
3. 更新库存、资金与价格，说明价格是在交易前、逐件还是整批后变化。
4. 按规则补货，并说出下一位玩家现在有哪些合法选择。
5. 处理一个短缺、一个滞销和一个容量不足情境。
6. 比较两个仅有“补货时点”不同的版本，说出策略变化。

## 观察字段

- 第一次正确指出当前价所需时间与信息来源。
- 是否混淆当前价、成交价和交易后价。
- 是否漏掉容量检查、价格移动、补货或交接。
- 是否能说明货物来源与资金去向。
- 从远座读取槽位、数量、价格和滞销年龄的困难。
- 需要何种协助，以及协助是否改变隐藏信息或行动时机。
- 下一位玩家能否复述其合法选择。

## 通过标准

- 至少 4/5 参与者无需设计师解释完成一笔完整交易与交接。
- 所有人都能区分当前价、成交价与交易后价；若规则让三者相同，也能解释原因。
- 关键步骤遗漏不会靠其他玩家默默代做而被掩盖。
- 至少一种替代呈现方式不改变信息、价格或行动时机。
- 设计师能用记录表重放一次状态变化。

## 停止与回退

若两位参与者在同一步出现同类错误，停止继续测数值，先改规则文字或组件映射。若真实座位无法识别关键价格，不以口头提醒修补，回到信息呈现。若批量价格无法解释，先明确统一价/边际价与移动时点，再继续平衡测试。

## 不可声称

本测试不能证明最佳补货量、价格步幅、市场规模、长期均衡、策略深度、所有玩家的无障碍性或商业可行性。
