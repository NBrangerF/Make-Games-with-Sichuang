# 新手可用性测试：指南到精选资源交接

状态：ready / unrun  
日期：2026-08-21  
对象：桌游设计经验 0–1 个项目的新手

## 研究问题

当参与者已经在六阶段指南中理解了当前任务后，他们能否不回到导航、不面对 574 条全量列表，直接进入一组与当前阶段相关的精选资源？参与者能否理解这是任务入口而不是必读排名？

本轮不用点击成功证明外部资源有教学效果。

## 任务

### H1：从一个模糊点子找到继续阅读

场景：你只有一个题材，正在读“把题材变成可测试的体验意图”。请找到一组能帮你把阅读变成动作的资料。

成功信号：不使用顶部导航，找到“继续阅读本阶段精选资源”；进入“选一条能产出行动的学习主线”；能指出入口的证据边界。

### H2：从核心系统到对应阅读入口

场景：你的规则很多，想理解一个决定怎样形成可重复的循环。

成功信号：从“核心系统”指南进入“把体验意图接成可重复的核心循环”；页面不先呈现全量目录。

### H3：刷新与分享后保持目的地

场景：你想把当前的精选入口发给同伴。复制当前地址，刷新，再在新标签打开。

成功信号：地址为 `#resources/<entry-id>`；三次都保持同一活动入口和资源数量；不携带本地项目或工具草稿。

### H4：切换入口后解释“不是排名”

场景：从当前入口切换到“准备第一次外部测试”，并解释为什么资源集合变了。

成功信号：地址更新为 `#resources/first-playtest`；参与者用“当前问题/任务”而不是“更好/更差”解释变化。

## 记录字段

- `task_id`、阶段、设备、viewport；
- 第一次寻找动作、首次偏离、恢复方式和主持提示次数；
- 对“精选”、“证据边界”和“不是排名”的原话；
- 点击前预期去向与点击后实际入口；
- 刷新/新标签后的活动入口、资源数量和错误；
- 严重度、修订假设与重测任务。

## 形成性门槛

- H1–H4 每项至少 3 名新手无主持帮助完成；
- H1/H2 不出现回到顶部导航或“查看全部”后才找到目标的严重偏离；
- H3 没有刷新丢失、错误入口或全量目录意外加载；
- H4 没有参与者把入口顺序说成资源质量排名；
- 键盘用户能聚焦、激活交接链接，并在新页找到活动入口。
