# 可用性测试：资源生产链契约

## 目标

验证中文新手能否区分存量、生产能力和一次性收入，并独立执行生产、转换、维护、腐坏和交接；不验证经济已经平衡。

## 参与者与材料

- 3–5 位未参与设计的玩家，覆盖主要人数。
- 两种原料、一种中间品、一种成品、生产轨、容量格、维护卡与三轮账本。
- 至少一个批量转换、一个自动转换、一个维护缺口和一个腐坏情境。

## 任务

1. 指出当前库存、每轮生产和一次性奖励各是多少。
2. 执行“生产 3 原料”，说明资源从哪里来、放在哪里。
3. 执行两次“2 原料→1 成品”，处理批量上限与余数。
4. 支付按设施数量计算的维护；在不足时走借贷或失败路径。
5. 处理超容量与回合末腐坏，并说出哪些物件离开系统。
6. 从最远座位复述另一位玩家的下一轮生产能力和关键存量。
7. 比较两个只在“维护时点”上不同的版本，说明策略差异。

## 观察字段

- 是否混淆库存、产量与收入。
- 是否漏掉输入消耗、输出放置、余数、过付、自动转换或次数限制。
- 是否能还原一单位资源的完整去向。
- 是否预见下一次维护与腐坏。
- 组件移位、面额换算、远座图标、跨卡触发与口头协助负担。
- 协助是否改变隐藏信息、选择或行动时机。

## 通过标准

- 至少 4/5 参与者无需设计师解释完成生产—转换—维护—交接。
- 所有人都能正确区分存量、生产能力和一次性收入。
- 账本能重放每次流入、转换、流出和后态。
- 关键遗漏不会靠熟练玩家默默代做而被掩盖。
- 至少一种替代标记或口述方式不改变信息与时机。

## 停止与回退

若两位参与者在同一步出现同类错误，先修规则或组件映射，不继续调数值。若无法从真实座位区分库存与产量，回到资源身份卡。若维护缺口需要临时裁决，先补失败路径再继续测试。

## 不可声称

本测试不能证明最佳资源数、转换率、容量、维护成本、腐坏频率、增长曲线、策略深度、所有玩家的无障碍性或商业可行性。
