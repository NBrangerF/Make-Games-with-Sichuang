## 阅读入口和数据

`#learn`、`#course` 与旧的 `#resources/learn/systematic` 进入主线。章节是 `#course/reading/<id>/<language>`，目录为 `#course/reading/all/<language>`。28章均可直接访问；中英文切换保留章节，前后章按单一目录生成；没有报名、填表、必交练习或完成门。

`#resources` 和 `#resources/read/all/<language>` 进入原创文章库，可筛选全部41篇、28章主线、13篇选读，也可按标题和摘要搜索。主线卡进入课程阅读，选读卡进入文章阅读；两者共用 `content/original-articles/<id>/zh-CN.md` 和 `en.md`。顶栏提供系统学习、案例研究、按问题阅读、可选设计工作台；阅读入口保留语言。正式工作台仍是中文。

2026-09-08 发布前整理：目录按七个部分从上到下排列，显示部分编号与章节范围；手机首屏提供开始入口，章节内可展开紧凑目录。文章检索同时覆盖中英文标题与摘要，`q`、`scope` 写入阅读 URL。进入章节或选读时使用受限的 `from` 保留文章列表/原章节；返回列表恢复筛选与本次会话中的滚动位置。切换语言保留当前文章及相应语言的返回入口；选读的继续阅读指向实际进入它的章节。

`#privacy` 与 `#privacy/en` 提供对应语言的隐私说明和可取消的数据清除确认。页面的文档语言、导航和隐私入口与阅读语言一致；旧工作台在英文导航中明确标为中文。阅读、搜索与语言切换不写项目数据，旧项目的读取也不再立即落盘；用户显式修改项目后才保存。空存储、现行草稿、旧版草稿与损坏数据分别检查。

2026-09-08 阅读与案例升级：阅读区域使用暖象牙纸面、深墨绿、朱红强调、衬线标题与灰绿练习区；首页使用单独生成的过河原型插画。桌面章节采用小节导航、正文、相关工具三个区域，手机按正常阅读顺序排列，目录默认折叠。键盘焦点保留在可操作元素上；宽表格保留可聚焦的局部滚动区域和列标题语义。41篇正文版本未变。

## 章节工具与真实案例

28章各在一个相关小节后提供可选练习，覆盖观察、意图、动作循环、选择、资源、主题、参与障碍、测试与复盘9类。每章的三个字段都有对应的中英文过河示范，共168个示范字符串，使用独立变体时不混入基本版。`content/reading-support.json` 保存位置、说明、正式工具和案例关系，`content/reading-examples.json` 保存逐章示范。侧栏共连接14种已有正式工具，返回保留章节和语言。

练习默认不写入本机；点击保存才使用独立的 `reading-note-v1-<chapterId>` 记录。下载为 Markdown；载入示范及修改后的示范保留来源标识，不写成工作台的真实试玩证据。语言切换不自动翻译读者填写的文字。清空仅作用于该章，且需要第二次点击确认。

`#resources/cases/all/<language>` 提供独立案例目录：Carcassonne、Pandemic、Dominion、6 nimmt!、Hanabi、Wingspan，共6篇双语原创分析。整局、机制、主题各两篇，可搜索和筛选，并返回来源章节。全部案例列明使用的官方规则版本和定位，构造的局面与分析者推断明确标识。Dominion 提供牌库厚度与抽牌概率比较；6 nimmt! 提供同时选牌、依次结算的两种结果演示。其余案例用关系图与文字局面说明。

本轮实现与核查见内部目录“阅读工具与案例升级”。六案例属于资源库扩展的一部分；48主题、首批24主题和6份跨机制比较仍未完成，不能把本次交付称作完整资源库扩展。此次不执行部署。

`content/reading-path.json` 保存七部分、顺序、前置关系及13篇选读的位置。`content/original-articles/catalog.json` 只保存 id、contentVersion、两语title/summary，不含书名、作者、内部证据字段。原书导读已从课程和原创文章流程移除；说明与例子本身承担教学，不要求读者查阅原资料。旧的课程专用 `reading-resource-guide` 文件已移到内部备份。
