# 资源库入口级分片可行性

日期：2026-08-21  
状态：implemented / production build verified / rendered timing pending

## 要回答的问题

当前 `resource-catalog` 为 803.83 kB（gzip 213.93）。用户进入资源库时，默认只看第一个策展入口的 7 条资源，却会下载 574 条资源、574 份审阅、34 个入口和整份评价量表。

拆分前需先确认：34 个入口是否大量重复引用同一批资源。如果重复率很高，每入口一包会用缓存、构建和维护成本换取表面上的小 chunk。

## 测量结果

| 指标 | 结果 |
|---|---:|
| 策展入口 | 34 |
| 总引用次数 | 270 |
| 唯一资源 | 248 / 574（43.2%） |
| 平均每入口 | 7.9 条 |
| 跨入口重用率 | 8.1% |
| 只出现 1 次 | 231 条 |
| 出现 2 次 | 13 条 |
| 出现 3 次 | 3 条 |
| 出现 4 次 | 1 条 |

如果每个入口包含入口元数据、该入口的完整资源与逐条审阅，未压缩 JSON 的估算分布为：

| 入口包 | 原始 JSON |
|---|---:|
| 最小 | 9,461 bytes |
| 中位数 | 11,808 bytes |
| P90 | 12,759 bytes |
| 最大 | 13,303 bytes |
| 34 包总和 | 403,414 bytes |

248 条唯一策展资源与审阅去重后的原始 JSON 约为 337,686 bytes；每入口包总和比去重集增加约 65.7 kB。由于 231/248 条资源只出现一次，重复代价可控。

## 决定

下一轮可以实施“入口轻包 → 全目录重包”，但必须满足以下边界：

1. 34 个入口包全部从权威 `resources.json`、`resource-assessments.json` 和 `resource-entry-points.json` 机械生成，不引入第二套手工内容。
2. 打开资源库时只加载入口索引与当前入口包；切换入口只加载新入口包。
3. “查看全部”才加载完整 `resource-catalog`。“资源怎么读”工作台仍需完整审阅和量表，保持完整目录边界。
4. 入口内搜索与筛选仍只作用于当前策展集，语义不变；只有用户明确进入“全部资源”后才搜索 574 条。
5. 加载失败必须保留入口标题、问题与产出说明，并只重试失败的入口包。
6. 生成校验必须逐条比较顺序、ID、资源字段和审阅字段；删除或更新权威资源后，过期入口包必须让 `content:check` 失败。

## 实施顺序

1. 新增可复现生成器和 34 个入口 JSON 生成物。
2. 新增入口索引/入口包 loader，用 `import.meta.glob` 产生独立 chunk 并按 ID 去重请求。
3. 将资源页改为受控的入口选择；仅“查看全部”升级到完整目录。
4. 更新浏览器 QA：进入资源库后完整目录尚未请求，切换入口仍未请求，点击“查看全部”后才请求。
5. 记录默认入口、最大入口、第二个入口及全目录的实际构建大小。

## 暂不采用

- 不把 248 条策展资源做成一个 337 kB 的统一“轻包”：它仍远大于单入口所需的约 12 kB。
- 不做每资源一个 chunk：请求数和 manifest 成本会失控。
- 不删除完整目录、全局筛选或资源审阅工作台。
- 不为消除构建警告而调高 chunk 阈值。

## 证据边界

上述 byte 是对当前 JSON 数据的 Node `Buffer.byteLength(JSON.stringify(...))` 测量，不包含模块包装、压缩、HTTP 头、缓存或运行时解析成本。它足以支持下一步工程实验，不是真实性能验收。

## 实施后增量

2026-08-21 已按上述决定完成实施。生产构建中，资源库默认入口依赖：入口运行时 6.77 kB（gzip 1.54）、仅 `id/title` 的 34 入口导航索引 3.11 kB（gzip 1.83），以及默认 `first-prototype` 包 9.07 kB（gzip 3.53）；合计 18.95 kB（gzip 6.90）。相比原 803.83 kB（gzip 213.93）完整目录，默认资源专属载荷减少 97.6%，gzip 减少 96.8%。

34 个入口包的生产 chunk 范围为 9.07–12.86 kB（gzip 3.53–5.33）。完整目录仍为 803.83 kB（gzip 213.93），仅在用户明确“查看全部”或进入资源审阅时加载。主 JS 从前一里程的 503.42 kB 增至 506.47 kB（gzip 154.85），代价为 3.05 kB；manifest 和 34 路映射已放入 6.77 kB 动态运行时，没有进入首屏主包。
