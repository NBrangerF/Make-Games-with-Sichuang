# 资源优先与中文站内阅读重构 01

日期：2026-08-21  
状态：第一层已实现，全文译文库尚未开始  
范围：信息架构、站内阅读入口、权利边界与后续内容迁移

## 目标

网站首先是一个给桌游设计学习者使用的资源站。读者可能是小学生、青少年或成年人，因此第一屏不要求理解术语、不展示完整工具箱，也不要求先自己搜索。用户应先回答一个容易的问题：我现在处在设计的哪一步？

选择阶段后，网站再让用户选择正在处理的具体问题，并进入少量与该问题匹配的资料。工具、专题和概念都保留，但退到“阅读后继续行动”的辅助位置。

## 已落地的信息架构

主导航顺序调整为：

1. 找资料
2. 设计路径
3. 中文知识
4. 辅助工具

默认进入 `#resources`。资源页采用两层脚手架：

1. 六个设计阶段：体验意图、核心系统、最小原型、测试与反馈、规则与信息、呈现与发布。
2. 同一阶段内先显示 1-3 个最常见问题，其余具体问题放进“更多具体问题”。

34 个原有入口没有删除，也没有被重新排名。它们被映射到最容易理解的阶段位置，原有独立加载包、深链和完整目录仍可使用。

## 站内中文阅读契约

点击任一资源不再打开外部网站，而是进入可分享的站内地址：

`#resources/<阅读入口>/<资源 id>`

站内阅读页固定呈现：

- 中文导读
- 原始题名、作者、原文语言和核验日期
- 该资料能帮用户完成什么
- 本阶段读完要做的下一步
- 最适合的使用语境与不能承担的结论
- 来源记录与权利边界

概念页、框架页、核心指南和资源审阅页中原本会离站的来源入口，也统一改为进入该中文导读页。

## 翻译与权利边界

“所有资料中文化”不能等同于把网络博客、付费书籍或论文全文翻译后复制到本站。除非具有开放许可、版权方授权，或用户提供文本并确认可用范围，否则全文翻译和再发布会超出本站可安全使用的权利。

因此内容分成三个明确层级：

| 层级 | 可在本站提供的内容 | 当前状态 |
| --- | --- | --- |
| 中文原生资料 | 原始中文标题和本站导读 | 已可站内阅读 |
| 全部 574 份资料 | 中文导读、用途、限制、评价与来源记录 | 已可站内阅读 |
| 可站内提供全文译文 | 开放许可、获授权或用户确认可用的完整文本 | 尚未建立授权清单与译文库 |

目前“中文导读”不是逐段翻译。它是基于已完成审阅而写的原创中文学习说明。界面必须一直保留这个标签，不能把导读伪装成原文的完整中文版本。

## 下一批内容工作

1. 为 574 条资源建立中文题名字段，并由人工抽检而非自动覆盖原始题名。
2. 建立 `previewMode`、许可依据、译者、版本和更新时间字段。
3. 优先处理最常用的六个阶段入口，每个入口先补齐少量可独立阅读的中文学习卡。
4. 单独建立“可全文译”的许可清单。优先核验公开许可课程和用户拥有权利的本地材料。
5. 对长篇书籍、付费内容和未授权博客保持导读、引用和来源记录，不收录全文。

## 当前验收

- 资源页默认且优先呈现阶段选择。
- 阶段内先展示有限的常见问题，更多问题可展开。
- 资源条目进入站内中文导读，而非离站链接。
- 原有资源入口保持独立动态加载，完整目录仅在用户主动选择后加载。
- TypeScript 和资源入口加载守卫通过。
