# 新手可用性测试：分享方法内容

状态：ready / unrun  
日期：2026-08-21  
对象：桌游设计经验 0–1 个项目的新手

## 研究问题

参与者能否把“方法”理解为可按问题选择、可追溯分享的内容，而不是必须从第一张框架开始的课程或质量排名？

本轮只验证定位、恢复和边界理解，不用到达或分享成功证明读者已学会理论。

## 任务

### M1：分享一篇专题指南

场景：你想把“把盲测拆成四个可观察任务”发给共同设计者。

成功信号：进入专题指南并选中目标；复制地址为 `#method/guides/special-blind-rules-test`；新标签和刷新后仍显示同一专题。

### M2：分享一个概念的本站定义

场景：同伴把“原型精度”理解为粗糙到精美的单轴。请找到本站定义并分享。

成功信号：搜索“保真度”后显示“原型精度”；地址为 `#method/glossary/prototype-fidelity`；能说出“不是统一的粗糙—精美单轴”。

### M3：分享一份资源审阅，不只分享外链

场景：你要说明 AutoBG 资料适合和不适合支持什么判断。

成功信号：在“资源怎么读”找到 AutoBG；分享本站资源审阅地址，而不只复制原始论文；能区分“最适合”与“不要用来”。

### M4：用后退恢复上一个方法目的地

场景：从专题指南切换到概念词表，再用浏览器后退。

成功信号：分区标题、选中条目、页面标题和 URL 一起恢复；不回到设计路径或第一张框架。

### M5：说明 URL 没有保存什么

场景：在概念词表输入搜索词并切换阶段，然后分享地址。

成功信号：地址保存当前概念，但不保存搜索词或阶段筛选；参与者不认为链接会分享本地项目、工具草稿或阅读历史。

## 记录

- `task_id`、设备、viewport、参与者别名；
- 首次选择、首次偏离、恢复动作与主持提示次数；
- 分享前预期的链接内容，以及新标签中实际恢复内容；
- 对“方法”、“最适合”、“不要用来”与隐私边界的原话；
- 严重度、修订假设和重测任务。

## 形成性门槛

- M1–M5 每项至少 3 名新手无主持帮助完成；
- M1–M4 没有刷新丢失、错误分区或无法从后退恢复的严重问题；
- M2/M3 没有把概念定义或资源审阅当作普遍结论/质量排名；
- M5 没有人认为分享链接携带本地项目或搜索历史；
- 键盘用户能聚焦与切换标签/条目，选中态可被辅助技术识别。
