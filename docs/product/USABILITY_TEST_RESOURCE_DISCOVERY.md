# 新手可用性测试：资源发现

状态：ready  
日期：2026-08-18  
对象：桌游设计经验 0–1 个项目的新手

## 研究目标

验证用户能否在不理解本站数据模型的前提下：

1. 从当前任务进入少量资源；
2. 判断一条资源适合怎样使用；
3. 组合筛选而不把它们理解成质量排名；
4. 识别仅摘要/元数据与全文审阅的差别；
5. 从零结果恢复。

本轮不评估参与者能否读懂外部英文正文，也不以点击数证明资源有教学效果。

## 任务

### R1：从点子进入第一份原型

场景：你只有题材和一些零散规则，希望今天做出能测试的东西。找到一组适合开始阅读的资料，并说出它们不能保证什么。

成功信号：选择“第一次把点子做上桌”；看到 7 条而不是全部列表；能复述入口证据边界。

### R2：寻找中文新手资料

场景：你希望先看中文，并且资源适合第一次做游戏的人。

成功信号：切换到全部资源后选择“新手”和“中文”；能说明筛选不是质量分，也不保证中国大陆地区适用性。

### R3：按用途找反例

场景：你已经有一个关于互动的判断，希望比较不同观点，而不是只找操作步骤。

成功信号：使用“比较观点”并结合搜索或阶段；打开前能阅读“最适合”和“不要用来”。

### R4：识别阅读深度

场景：找到一条本站只取得摘要或元数据的来源。你可以从本站说明推出什么，不能推出什么？

成功信号：使用“仅摘要/元数据”访问筛选或阅读深度；不声称本站读过全文。

### R5：从零结果恢复

场景：组合条件后没有结果，请继续寻找可用资料。

成功信号：理解零结果是条件交集为空；使用“查看全部资源”恢复，而不是认为网站没有相关内容。

### R6：移动端切换入口

场景：在 375px 宽度切换九个阅读入口，再筛选语言。

成功信号：入口轨道内部可横向滚动；页面本体无水平溢出；筛选控件可读、可聚焦。

## 记录

- task_id、参与者、设备、viewport；
- 首次选择的入口/筛选与理由；
- first_deviation、recovery、主持提示次数；
- 对“最适合”“不要用来”“阅读深度”“核验日期”的原话；
- 是否把入口、层级或访问方式误解成质量排名；
- 是否能从零结果恢复；
- 严重度、修订假设与重测任务。

## 下一轮门槛

- R1–R5 每项至少 3 名新手无主持帮助完成；
- 没有人把入口顺序或层级筛选当成质量排名；
- `metadata_only` 不再被误读为全文审阅；
- 零结果状态没有造成任务终止；
- 375px 页面无外层溢出，入口和阶段轨道分别只在自身容器滚动。
