# 体验意图卡产品规格

状态：implemented / browser-and-participant-validation-pending  
日期：2026-08-21  
正式工具序号：16

## 产品任务

把“我想做一款海上贸易游戏”“我想让玩家紧张”“我喜欢这个机制”这类起点，转成一条包含玩家语境、重复决定、代价、可见反馈、行为预测、反驳信号和本轮边界的假设。产出必须能直接成为核心系统与第一份原型的测试问题。

## 视觉规格

桌面概念稿：[`design/concepts/experience-intent-card-desktop.png`](../../design/concepts/experience-intent-card-desktop.png)，1536×1024，SHA-256 `c4da721bb8ee257edf2fad8cb046c546e95578404dad2aaf65c40f3ec1019881`。

从概念稿锁定的设计系统：

- 暖白纸张与极淡点纹延续全站背景；
- 深钴蓝表示当前步骤、焦点和摘要结构；砖红只承担手写边注与证据边界；
- 标题与字段标签使用宋体语气，输入和按钮使用清楚的产品字体；
- 五步为单条横向轨道，编辑区是开放纸面，摘要是窄的活页纸，不改成卡片网格；
- 桌面为宽编辑器/窄摘要；1000px 以下摘要下移；720px 以下字段单列、步骤只在自身容器横向滚动；
- 低圆角、细边线、几乎无阴影；可见焦点使用钴蓝轮廓。

概念稿出现但有意不实现：右上书本/设置图标和“复制为文本”。它们不在既有导航或任务范围内；工具保留现有顶部导航、工具横向标签和 JSON 导出。概念中的逐字计数也暂不实现，因为没有研究阈值支持统一字符上限。

## 五步字段

### 01 玩家与语境

- 项目；
- 当前版本；
- 最初的题材、机制、触感或问题；
- 目标玩家与游玩语境。

这里描述当前设计对象，不从人口属性生成固定喜好。

### 02 重复决定

- 玩家反复比较/选择什么；
- 不同选择改变什么。

不要求二元选择，也不允许只写机制名。

### 03 压力与反馈

- 为什么决定有代价；
- 系统怎样让后果可见。

“紧张”“沉浸”不是反馈。需要可读取、比较、执行或影响下一决定的状态。

### 04 预测与反例

- 预计看见的桌面行为；
- 什么现象会反驳预测。

反例不自动等于玩家不会玩或设计失败，而是检查当前规则关系、信息、代价和语境。

### 05 本轮边界

- 本轮明确不验证什么；
- 第一条测试问题。

问题不使用“好玩吗”“够策略吗”，只观察当前预测。

## 编译假设

只有玩家、重复决定、压力、可见反馈和预测均存在时，摘要才编译：

```text
在[玩家语境]中，玩家反复[重复决定]；因为[压力]，
系统通过[可见反馈]显示后果。我预计[行为预测]。
```

反驳信号、非目标和测试问题保持独立，防止一句顺滑文案掩盖检验边界。

## 保存与导出

浏览器键：`tabletop-workshop-experience-intent-v1`。

```yaml
schema_version: 1
method: experience-intent-card
local_first: true
no_fun_score: true
no_player_profile_inference: true
no_mechanic_recommendation: true
evidence_boundary: string
draft: object
current_hypothesis: string
saved_records: [object]
exported_at: datetime
```

草稿随字段改变自动保存。只有 12 个字段齐全才能增加带 UUID 和时间的记录。清空需要二次确认，只清草稿，不删除历史记录。完整项目包新增 `experience_intent_records`，项目记录类别从 15 增至 16；记录数仍不是进度或质量。

## 路由与加载

- `guide-experience-intent.toolIds[0] = experience-intent`；
- 指南 CTA：“打开体验意图卡”；
- 工具箱第一项：“体验意图卡”；
- 模块使用 React `lazy()`，只在用户打开工具时加载独立 chunk；
- 加载失败/等待时显示与工具同名的文本状态，不用空白占位。

## 机器守卫

`pnpm qa:experience-intent` 检查 20 项结构契约：稳定 ID、内容验证允许值、指南直达、独立 chunk、项目导出、五步、字段、拒绝声明、证据边界、分步校验、二次清空、桌面/移动布局和项目合同。

它不能验证字段是否易懂、假设是否有设计价值、视觉是否匹配概念或真实玩家是否出现预测行为。

## 完成边界

本轮可声明：代码、数据路由、本地保存、导出契约、项目汇总、响应式 CSS 与构建成立。

本轮不可声明：浏览器核心交互、概念 10/10 保真、375px 真实布局、键盘/屏幕阅读器体验或新手可用性已经通过。浏览器环境阻塞没有变化，真人形成性测试尚未执行。
