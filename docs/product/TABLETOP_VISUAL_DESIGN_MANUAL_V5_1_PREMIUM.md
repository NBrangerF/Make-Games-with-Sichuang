- 画布使用接近纯白的冷中性，不延续偏黄手工纸。

- 主要结构以精确网格、1px 线和基线对齐建立。
- 照片像馆藏图版一样被装裱，图注在图片下方，不把文字压在图片上。
- 首页、资源目录、阅读、方法和工具保持不同页面角色。
- 红、黄、绿只在确有危险、提醒、完成等语义时出现。

- 首页概念图中的红色、黄色入口编号不能作为类别身份色。生产实现使用钴蓝和中性色；红黄绿只表达语义状态。

## 2. Design Read

### 2.1 核心定义

产品类型：完整中文桌游设计资源馆、方法专题与上下文工作单。  
主要读者：从小学生、青少年到成人学习者、教师和有经验设计师。  
目标气质：权威但不冷，鲜明但不喧闹，可探索但不玩具化。  
视觉比喻：当代设计博物馆的专题展，与高级桌游出版物的内页结合。  
关键体验：看见证据、理解关系、找到资源、带走一个可执行动作。

### 2.2 应该像

- 一场被认真策展的桌游设计专题展。
- 一本版式精确、有图版与注释的设计出版物。
- 一个能够继续操作和记录的设计工作台。
- 面向全年龄，但不将任何读者幼儿化。

### 2.3 不应该像

- 桌游商店或某款游戏的官方网站。
- 儿童课堂手账、贴纸册或闯关学习产品。
- SaaS 仪表盘、AI 工具门户或卡片组件展厅。
- 只有白色、细灰字和巨大空白的通用博物馆模板。
- 黑金渐变、极细字体和奢侈品式“假高级”。

### 2.4 五秒承诺

第一次看到首页五秒后，读者应知道：

1. 这里学习桌游设计。
2. 可以从学习、分析游戏或正在解决的问题开始。
3. 经典游戏照片是观察材料，不是广告、售卖或官方合作。

## 3. 七条设计原则

### 3.1 资源优先

任何视觉元素都必须帮助读者进入资源、理解资源或使用资源。照片、标题和色面不能把资源入口推到首屏之外。

### 3.2 策展，而非装饰

每张图片和每个图形都回答一个具体观察问题。无法说清“它帮助读者看懂什么”的图像不进入页面。

### 3.3 一页一个大胆动作

一页只能有一个主要构图事件：大标题、图版组、深色方法跨页或工具工作区之一。其余区域以精确网格和克制层级支持它。

### 3.4 明确先于隐喻

操作文字先写任务和产出，再允许出现“馆藏、索引、工作台”等视觉隐喻。读者不需要理解博物馆或桌游术语才能导航。

### 3.5 同一路径，不同深度

儿童和成人使用相同 canonical 内容与入口。差异通过“先做一步、看一个例子、理解原理、查完整来源”逐层展开，不通过年龄模式或删减版实现。

### 3.6 少而精确

高级感来自比例、对齐、字体、图版和节奏，不来自更多特效。一个视口只有一个编辑强调色、一个必要语义色、一个主要深度层。

### 3.7 证据可追溯

经典桌游照片作为研究标本出现；作者、许可、来源、改动与中文观察可追溯。照片不成为品牌、按钮或系统状态。

## 4. 设计旋钮：7 / 4 / 3

V5.1 的 canonical dials 固定为：

- Design Variance：7
- Motion Intensity：4
- Visual Density：3

这表示构图和页面角色保持鲜明；状态变化可感知但不过度游戏化；一个视口内的信息被分成少量清楚组，而不是极度稀疏。

### 4.1 页面预算

| 模板 | Variance | Motion | Density |
| --- | ---: | ---: | ---: |
| 首页 | 7 | 3 | 3 |
| 学习 / 分析 / 问题入口 | 6 | 3 | 3 |
| 资源目录 | 6 | 2 | 3 |
| 主题详情 | 6 | 2 | 3 |
| 完整阅读 | 5 | 1 | 2 |
| 方法与概念 | 7 | 3 | 3 |
| 配套工具 | 6 | 4 | 3 |
| 系统页 | 4 | 1 | 2 |

任何模板不得超过 7 / 4 / 3。

### 4.2 单视口预算

每个视口最多允许：

- 一个主视觉场。
- 一个编辑强调色：钴蓝。
- 一个与当前信息必要相关的红、黄或绿语义色。
- 一种显著轮廓。
- 一种材质或深度处理。
- 一种主要动效。
- 一个首要决定。

## 5. 页面角色

### 5.1 策展前厅：首页

任务：让读者迅速理解网站并选择入口。  
视觉：大标题、索引式入口、馆藏图版。  
不做：推荐墙、统计、滚动故事、图片轮播。

### 5.2 馆藏目录：资源

任务：按阶段和问题定位资源。  
视觉：阶段索引、连续资源行、精确元数据。  
不做：商品卡片、评分、标签云、彩色分类墙。

### 5.3 编辑专题：完整阅读

任务：持续阅读完整中文内容。  
视觉：章节轨、宽正文、克制图版与说明。  
不做：多栏噪声、漂浮工具、伪阅读百分比。

### 5.4 分析跨页：方法与概念

任务：理解一个方法能回答什么，并照着执行。  
视觉：深色索引与白色内容跨页、清晰比较与产出。  
不做：后台 dashboard、真实 3D 书本、方法卡片墙。

### 5.5 设计工作台：工具

任务：输入、判断、生成一份可带走的产出。  
视觉：步骤轨、主输入区、持续摘要。  
不做：小游戏、奖励动画、复杂控制面板。

### 5.6 安静档案页：系统

任务：说明隐私、错误、版本与边界。  
视觉：冷白画布、标准排版、必要状态色。  
不做：经典桌游图片或强视觉事件。

| 颜色 | 色值 | 允许语义 | 禁止 |
| --- | --- | --- | --- |

## 7. 字体与排版

### 7.1 字体家族

- UI 与大标题：Noto Sans CJK SC / Source Han Sans SC / PingFang SC / Microsoft YaHei / system-ui。
- 编辑标题：Noto Serif CJK SC / Source Han Serif SC / STSong / SimSun。
- 索引数字：Noto Serif / Source Serif 4 / Georgia，只用于短数字。

字体优先自托管并登记许可；不从第三方 CDN 加载。

### 7.2 角色

| 角色 | 桌面 | 移动 | 行高 | 字重 |
| --- | --- | --- | ---: | ---: |
| Hero Display | 64–82px | 42–54px | 1.04 | 800 Sans |
| Page H1 | 44–60px | 34–43px | 1.10 | 800 Sans |
| Editorial H1 | 46–64px | 35–44px | 1.16 | 700 Serif |
| H2 | 28–36px | 26–31px | 1.24 | 700 Sans |
| H3 | 21–26px | 20–23px | 1.34 | 700 Sans |
| 正文 | 17px | 16–17px | 1.70 | 400 Sans |
| 阅读正文 | 18px | 17px | 1.86 | 400 Sans |
| 操作标签 | 16px | 15–16px | 1.45 | 600 Sans |
| 图注 / 元数据 | 14px | 14px | 1.50 | 500 Sans |
| 眉题 | 14px | 14px | 1.40 | 700 Sans |
| 索引数字 | 24–32px | 22–28px | 1.00 | 500 Serif |

### 7.3 字体分工

- 首页和工具 H1 使用 Sans，表达清晰行动。
- 方法专题和少量策展型页面可以使用 Editorial H1。
- 完整阅读正文继续使用 Sans；长文一级标题可按内容类型选 Serif。
- 同一页面最多两个字体家族。
- Serif 不承担按钮、字段标签、错误和保存状态。

### 7.4 中文排版

- 阅读正文每行 30–42 个汉字，最大宽度 720px。
- 长中文标题自然换行，不通过缩至小字保持单行。
- 不对长中文标题使用夸张字距。
- 段落间距至少 0.9em。
- UI 主文案不使用全英文缩写；MDA 等必须同时给中文解释。
- 图注、作者、许可和元数据最低 14px，不能以小而浅冒充高级感。

## 8. 网格与空间

### 8.1 间距

使用 4 / 8 / 12 / 16 / 20 / 24 / 28 / 32 / 40 / 48 / 64 / 80 / 96px。

每个页面先建立 8px 基线，再用 24 / 32 / 48px 形成主要节奏。不得凭感觉混用 18、22、26、38 等随机间距。

### 8.2 最大宽度

| 模板 | 最大宽度 |
| --- | ---: |
| 首页 | 1400px |
| 资源目录 | 1320px |
| 资源详情 | 1120px |
| 阅读壳 | 1160px |
| 阅读正文 | 720px |
| 方法 | 1400px |
| 工具 | 1360px |
| 系统页 | 960px |

### 8.3 对齐

- 同一组件组的标题、边框、图注和操作基线误差不超过 1px。
- 图片网格列宽与图注宽度一致。
- 资源行各列使用稳定轨道，不让每行元数据随内容漂移。
- 视觉错位只用于首页构图，不能蔓延到表单、阅读和资源扫描。

### 8.4 留白

留白必须建立对象关系，而不是单纯放大页面高度。

每块大留白都应回答：

- 它把哪两个层级分开？
- 它让哪一项成为焦点？
- 移动端收拢后是否仍成立？

如果无法回答，应缩小留白或强化其相邻结构。

## 9. 深度、边框与表面

### 9.1 三层深度

| 层级 | 表达 | 使用 |
| --- | --- | --- |
| Level 0 | Canvas / Surface，无阴影。 | 页面、正文、资源行。 |
| Level 1 | 1px Rule 或 Alternate Surface。 | 目录、控件、轻分组。 |
| Level 2 | 极轻 mounted shadow。 | 首页馆藏图版、方法主跨页或 overlay；一屏最多一个区域。 |

### 9.2 边框

- 默认分隔与图版框：1px。
- 当前选中、输入焦点或重要状态：2px。
- 键盘焦点：3px outline + 3px offset。
- 深色当前轨：4px。
- 不使用 3px 装饰边、双重描边、切角、票根缺口或拼图边缘。

### 9.3 阴影

- 默认：none。
- Mounted：0 1px 2px rgba(8,29,45,0.08) + 0 10px 28px rgba(8,29,45,0.06)。
- Method Workbench：0 16px 40px rgba(8,29,45,0.12)，只允许一个。
- Overlay：0 18px 48px rgba(8,29,45,0.18)。
- 硬边偏移阴影在 V5.1 禁止。

### 9.4 材质

V5.1 不使用纸纹、网点、套印错位、胶带、木纹或毛毡。桌游物质感来自真实照片、精确装裱、页边、索引和实体比例，不来自模拟旧纸。

## 10. 照片装裱

### 10.1 图版结构

每个 Figure Plate 依次包含：

1. 图像。
2. 8–12px 冷白 mat。
3. 1px Rule 边框。
4. 8px 图注间距。
5. 观察标题。
6. 作者、文件名与许可摘要。

图注不覆盖图片，不在 hover 中出现。

### 10.2 首页图版

- 桌面最多四张，采用稳定 2×2 网格。
- 同一网格只使用一种图片比例；优先 1:1 或 4:5。
- 列与行间距 24px。
- 图片不旋转，不贴胶带，不叠压。
- 图版整体是首页唯一 Level 2 对象。
- 标题和入口与图版保持明确分栏，不能浮在照片上。

### 10.3 其它页面

- 一个普通视口最多一张解释性照片。
- 资源列表只有精选案例允许 80–112px 缩略图。
- 长文只有当读者需要观察时才插图。
- 方法页的图像必须成为案例证据，不能当气氛图。
- 工具页通常不使用第三方照片。

### 10.4 裁切与色彩

- 使用 object-fit 和登记过的 object-position 做非破坏性裁切。
- 不使用通用灰度、复古、双调或高饱和滤镜。
- 不把不同游戏合成虚构包装。
- 任何烘焙裁切、调色和压缩都进入资产登记。
- 图片不得成为按钮皮肤、输入背景或品牌标识。

## 11. 全站壳

### 11.1 顶栏

- #031A2B 实色底。
- 品牌左对齐；可见导航只有“找资料”和“方法与概念”。
- 当前导航使用 Primary 实色区、底线和 aria-current。
- “仅限内部学习”使用白色或 Muted Inverse 文字，不做胶囊徽章。
- 桌面最小 72px；移动两行最小 108px。
- 工具或兼容深链可以没有当前一级导航项。

### 11.2 页面头

标准顺序：

1. 返回入口。
2. 眉题 / 内容类型。
3. 唯一 H1。
4. 一句明确收益。
5. 可选状态 / 来源。
6. 主内容。

首页例外：可以把 H1、导语、索引入口与图版并置。

### 11.3 页尾

保留内部学习范围、隐私与必要版本信息。页尾不成为第二导航，不展示全部资源和工具。

## 12. 核心组件

不建立万能 Card。组件必须按内容语义命名。

| 组件 | 用途 | 必须包含 | 禁止 |
| --- | --- | --- | --- |
| SiteHeader | 全站导航 | 品牌、两个一级入口、内部状态。 | 第三个一级功能、圆角胶囊导航。 |
| PageIntro | 页面开场 | H1、收益、可选返回 / 眉题。 | 治理信息先于任务。 |
| IndexedEntry | 首页少量入口 | 索引、任务、产出、整行目标。 | 红黄绿类别色、伪步骤、硬阴影。 |
| GalleryGrid | 首页馆藏图版 | 2–4 张 FigurePlate、稳定网格。 | 随机旋转、拼贴叠压、轮播。 |
| FigurePlate | 解释性照片 | 图像、alt、观察标题、来源摘要。 | 文字压图、按钮皮肤。 |
| StageIndex | 设计阶段定位 | 阶段名、当前状态、不确定入口。 | 固定彩虹阶段色、横向滚动。 |
| ResourceRow | 资源记录 | 中文题名、收益、类型、完整度、来源、站内动作。 | 评分、胶囊堆、每行投影。 |
| ReadingRail | 章节定位 | 稳定锚点、当前章节。 | 百分比、嵌套滚动。 |
| ReadingCallout | 关键补充 | 标题、正文、单一语义色脊。 | 四色装饰、独立卡片墙。 |
| MethodSpread | 方法详情 | 适合、不适合、准备、步骤、产出。 | 真实 3D 书本、后台 dashboard。 |
| ToolWorkspace | 配套工具 | 步骤、输入、摘要、保存、产出、边界。 | 小游戏、徽章、奖励。 |
| SourceCaption | 图像 / 内容来源 | 作者、文件 / 原题、许可、改动。 | 只写“来自网络”。 |
| Disclosure | 进阶信息 | 原生 details / button、展开状态。 | hover 才可见。 |
| StateNotice | 错误、警告、完成 | 文字、图形、语义色、下一步。 | 只靠色彩。 |

### 12.1 IndexedEntry

- 高度至少 88px。
- 1px 边框，当前 / hover 可使用 4px Primary 左轨。
- 索引数字 24–32px，不大于入口标题。
- 所有入口使用 Primary 与中性色；红黄绿不区分类别。
- hover 最多 2px 位移，也可完全不位移，仅改变边线、箭头和背景。
- 焦点使用标准双层焦点环。
- 索引若无独立语义，从可访问名称中排除。

### 12.2 StageIndex

- 当前阶段使用 Primary 实色或 2px 边线、文字“当前阶段”和 aria-current。
- 未选阶段使用中性色，不给每个阶段固定颜色。
- 同时提供“我不知道自己在哪一步”入口。
- 桌面可横向六格；720px 以下改为两列或纵向，禁止横向关键滑轨。

### 12.3 ResourceRow

- 最小高度 80px。
- 普通记录使用 1px 下边线，无阴影。
- 类型通过文字和可选 8px Primary / 语义色脊表达；语义色只能反映真实状态。
- 题名和“它能帮你完成什么”优先于元数据。
- 精选案例图 80–112px；普通理论不强配图。
- hover 只强调站内阅读链接和箭头。
- 缺失状态写明缺正文、译文或来源中的哪一项。

### 12.4 ReadingCallout

只允许三种：

- 先做一步：Primary。
- 注意 / 边界：Warning 或 Danger，按真实语义。
- 已验证 / 可带走：Success。

Callout 使用 1px 边框和 6px 色脊，无投影，不连续堆叠。

### 12.5 MethodSpread

- 外层可以使用 Inverse Soft，内部正文为 Surface。
- 左侧索引低权重，右侧当前方法是主工作面。
- 只允许一个 mounted / workbench 深度。
- 适合回答使用 Primary 标题；不适合回答使用 Danger；准备清单使用中性色，只有必要提醒才用 Warning。
- 方法步骤写明输入、动作和产出。
- 移动端完全平面化，索引变 disclosure，正文先出现。

### 12.6 ToolWorkspace

- 桌面结构：步骤轨 208px / 主工作区 / 摘要 300px。
- 当前步骤 Primary；未完成步骤中性；保存 / 完成使用 Success；提醒使用 Warning。
- 输入最小高度 44px，始终有 label。
- 摘要反映当前输入，不成为第二套可编辑表单。
- 一次只有一个实心 Primary 主按钮。
- 保存状态使用 role=status；错误靠近字段并给下一步。

## 13. 页面执行规则

### 13.1 首页

首屏固定内容：

- 品牌与两个一级导航。
- H1“桌游设计学习资源站”。
- 一句说明中文站内阅读。
- 三个 IndexedEntry。
- 2–4 张 GalleryGrid 图版。
- 次级“搜索全部资料”。

桌面使用约 5:6 的文字 / 图版不对称分栏；图版面积约 42%–48%。入口不得因图版被压缩到难读。

移动端顺序：

1. H1 与导语。
2. 至少一张 FigurePlate。
3. 三个 IndexedEntry。
4. 其余图版或搜索。

不能删除全部图像，也不能让四张图先于主要入口占满多屏。

### 13.2 学习、分析与问题入口

- 学习入口以路径和产出组织。
- 分析入口先显示白话观察问题，再显示正式框架。
- 问题入口先选阶段，再选当前困境。
- 一组最多三个未分组选择；更多选择先分组或逐层展开。
- 页面主色一律 Primary，不为三个页面建立红黄绿身份。

### 13.3 资源目录

顺序：

1. PageIntro。
2. StageIndex。
3. 不确定阶段入口。
4. 当前问题选择。
5. 先从这里开始。
6. 换一种做法。
7. 当前上下文工具。
8. 全部资料与筛选。

资源目录使用冷白画布与连续行。筛选折叠时不显示标签墙。当前问题写成完整任务，不只写抽象名词。

### 13.4 主题与资料详情

顶部资料封套包括：

- 中文题名。
- 读完会得到什么。
- 内容规模。
- 中文完整度。
- 作者 / 来源。
- 站内完整阅读主行动。

经典桌游照片只有在直接帮助理解主题时出现一张，并使用 FigurePlate。

### 13.5 完整阅读

桌面 1180px 以上：

- ReadingRail 168–208px。
- 32–48px 间隔。
- 正文最大 720px。
- 可选单一上下文行动进入正文流或右侧空位，但不得压窄正文。

960px 以下：

- 章节轨变为标题后的 details。
- 来源治理信息进入可展开区域。
- 正文完整，不制造第二滚动容器。

每篇最多一个短封面动作：Primary 线、编号或一张图版。阅读页不因为“高级”而使用大面积空白、14px 正文或浅灰文字。

### 13.6 方法与概念

- 方法首页保留专题指南、理论框架、概念词表三个任务入口。
- 详情页采用深色窄索引 + 白色编辑跨页。
- 顶部回答适合、不适合和开始前准备。
- 正文包含步骤、案例证据和本轮产出。
- 相关方法最多七个，不能变成卡片墙。
- 实现必须保持平面、响应式和标准 DOM，不复制概念图中的 3D 书盒。

### 13.7 工具

- 真实工具名直接做 H1。
- 明确“做完会得到”“来自”“步骤数”“返回来源”。
- 桌面显示步骤、输入、摘要三分区。
- 移动顺序：当前步骤 → 输入 → 当前摘要 → 下一步。
- 高级选项默认折叠并解释何时需要。
- 完成状态展示成品、下一步与不能推断的边界。
- 不使用积分、徽章、庆祝动画或游戏胜利语言。

### 13.8 系统页

系统页只继承顶栏、排版、焦点和 Primary 链接。危险操作使用标准 Danger，不使用照片、图版或方法跨页。

## 14. 跨年龄 Scaffold

### 14.1 同一内容，四层进入

每个主题尽量提供：

1. 先做一步：读者可以立刻执行的动作。
2. 看一个例子：具体桌面或设计情境。
3. 理解原理：机制、框架和为什么。
4. 查完整来源：作者、全文、许可和进一步材料。

四层是内容深度，不是年龄、能力或等级。

### 14.2 入口写法

每个入口回答：

- 现在可以做什么。
- 做完得到什么。
- 需要准备什么。

推荐：分析玩家每回合真正做了哪些决定。  
避免：决策结构分析。

推荐：做一份只包含本轮测试内容的原型清单。  
避免：打开原型范围裁剪器。

### 14.3 不依赖背景知识

- 不认识经典桌游也能完成导航。
- 图片和游戏名只提供例子，不承担入口含义。
- MDA、DDE、5-Part Model 等首次出现时同时给中文白话解释。
- 图标、颜色、编号和博物馆隐喻都不是理解任务的前置条件。

### 14.4 儿童不被幼儿化

- 不使用吉祥物、卡通表情、星星奖励、锁定、关卡和“儿童版”。
- 大字号、短任务、清楚例子是全年龄标准。
- 不用“很简单”“小朋友也会”等评价性语言。

### 14.5 成人不被简化

- 完整理论、原题、作者、许可和方法边界始终可达。
- 不把高级信息藏在年龄模式。
- 摘要不能替代完整中文正文。
- 元数据可以折叠，但来源和全文入口稳定存在。

### 14.6 选择负担

- 一个决策组最多三个未分组选择。
- 六阶段只作为位置索引；读者选定阶段后再出现问题选择。
- 所有复杂入口提供一个“不确定，从这里开始”的恢复路径。
- 首屏只要求一个决定。

## 15. 响应式

### 15.1 断点

| 断点 | 变化 |
| --- | --- |
| 1280px | 方法和工具可以显示完整索引 / 摘要。 |
| 1180px | 阅读显示章节轨和正文。 |
| 960px | 首页、方法、工具主要双栏收拢。 |
| 720px | 所有关键布局单栏；阶段索引纵向或两列。 |
| 480px | 收紧页边距与标题；顶栏保持两个导航目标。 |

### 15.2 首页图版

- 960px 以上 2×2。
- 720–959px 可 2×2 或两张一行，但图注保持 14px。
- 480–719px 单列两张优先图版，其余放在入口之后。
- 480px 以下首屏附近至少保留一张图版；不能只剩文字，也不能先加载四张长图。

### 15.3 资源与阶段

- StageIndex 在 720px 以下改为两列或单列。
- 不横向滚动关键阶段和问题。
- ResourceRow 在窄屏顺序为：题名 → 收益 → 类型 / 来源 → 站内动作。
- 资料元数据可以换行，不缩成小于 14px。

### 15.4 阅读

- 960px 以下 ReadingRail 变 details。
- 表格可局部横滚，并显示“表格可左右移动查看”。
- 图片与图注保持同宽。
- 不产生固定高度的第二纵向滚动区。

### 15.5 工具

- 960px 以下摘要进入当前输入之后。
- 720px 以下步骤轨变为当前步骤标题和可展开总览。
- sticky 摘要不得遮挡键盘、焦点或下一步按钮。
- 320px 下字段、错误和按钮保持完整。

### 15.6 必测视口

- 320×568
- 390×844
- 768×1024
- 1024×768
- 1440×900

所有视口根级 scrollWidth 必须等于 clientWidth。

## 16. 交互与动效

### 16.1 时间

| 类型 | 时长 |
| --- | ---: |
| hover / focus | 120ms |
| 普通状态 | 160ms |
| 选择 | 180ms |
| disclosure | 200ms |
| overlay | 240ms |

非必要动效上限 240ms。

### 16.2 允许

- 边线、下划线、背景和箭头在 120–180ms 内变化。
- 入口在预留空间内移动最多 2px。
- disclosure 高度平稳展开。
- 保存状态从“正在保存”切换为“已保存到此设备”。
- 当前章节或阶段轨使用瞬时 / 短时 Primary 变化。

### 16.3 禁止

- scale 大于 1。
- 硬阴影压下、弹跳、翻牌、掷骰或棋子移动。
- 自动轮播、视差、滚动触发、循环或粒子。
- 页面进入品牌动画。
- 依赖动画解释状态。

### 16.4 Reduced Motion

prefers-reduced-motion: reduce 下：

- transform、smooth scroll 和高度动画关闭。
- disclosure 可瞬时展开。
- 状态继续通过文字、颜色和边线表达。

## 17. 无障碍硬门

- 每页一个 main 和一个 H1。
- 使用原生 nav、a、button、details、label、fieldset、table。
- 所有非行内交互至少 44×44px；主按钮优先 48px。
- 普通文字至少 4.5:1，大文字与非文字边界至少 3:1。
- 焦点环为 3px，offset 3px；浅底使用 Focus，深底使用 Focus Inverse。
- 正文链接默认下划线。
- 当前、错误、提醒、完成、保存不只使用颜色。
- 信息照片有中文 alt；重复或装饰照片空 alt。
- 200% 文本放大后无内容丢失。
- 400% 页面缩放满足 reflow。
- 粘性顶栏、目录和摘要不遮挡焦点。
- 键盘可完成入口、筛选、阅读目录、方法选择和工具流程。
- 概念图内生成文字永远不是无障碍内容。

## 18. 资产与来源

### 18.1 三个状态

- build-approved：来源、作者、许可、修改、alt 和使用范围完整。
- internal-reference-only：只用于研究和设计方向，不进入构建。
- original-derived-language：提取通用原则后用本站 CSS / SVG 重新绘制。

### 18.2 当前经典照片

实际构建资产仍以 VISUAL_ASSET_REGISTER_V4.md 为准。四张现代商业桌游摄影只批准当前内部构建；公开前重新审核被摄产品美术、商标和出版方权利。

### 18.3 呈现要求

- 不热链。
- CC BY 作者、许可链接和改动说明完整。
- 图注与来源记录可在站内直接查看。
- 图片不能暗示出版方背书。
- 概念图不得进入 public / dist。
- 新增图片必须先登记再实现。

## 19. 中文内容与状态

### 19.1 固定动词

| 意图 | 动词 |
| --- | --- |
| 完整正文 | 阅读 |
| 一组内容 | 查看 |
| 练习 | 开始 |
| 来源路径 | 返回 |
| 暂存 | 保存 |
| 本地文件 | 导出 |
| 细节 | 展开 / 收起 |

禁止孤立的“点击这里”“了解更多”“探索”“进入”。

### 19.2 状态文字

- 当前阶段：明确写“当前阶段”。
- 当前章节：明确写“当前章节”。
- 保存：写“已保存到此设备”。
- 完成：写“已完成”及产出。
- 错误：写发生位置、原因和下一步。
- 未完成：写缺少的输入，不用红色空框代替说明。

## 20. 反例

### 20.1 手工纸与课堂拼贴

禁止：

- 偏黄纸张、纸纹、网点和套印。
- 彩色胶带、随机旋转照片、便签和涂鸦箭头。
- 四色板件、厚边、切角和硬阴影同时出现。
- 页面像学校成果展示板。

### 20.2 彩虹类别

禁止：

- 用蓝红黄绿固定区分首页入口。
- 给六个设计阶段一套永久彩虹配色。
- 让资源类型、方法或章节各自拥有阵营色。
- 颜色承担没有文字的分类含义。

### 20.3 假高级

禁止：

- 黑金渐变、金属质感、极细衬线体和大面积黑底。
- 13px 以下图注和浅灰文字。
- 巨大空白但没有清楚对象关系。
- 为了安静移除全部图像和主色，重新变得 dull。
- 用英文、拉丁文或术语密度代替专业可信度。

### 20.4 通用博物馆模板

禁止：

- 只有白底、黑字、一张大图和“Explore”。
- 每页都使用相同画廊网格。
- 图注比任务更醒目。
- 首页像作品集，资源入口不在首屏。

### 20.5 桌游复制

禁止：

- 复制某款游戏的地图、卡框、字体、logo、角色或完整配色。
- 将经典照片做成品牌或按钮。
- 让网站看起来像出版社联名或官方资料站。
- 将多个游戏图片合成虚构盒面。

### 20.6 儿童化

禁止：

- 吉祥物、星星奖励、徽章、锁定、闯关和胜利动画。
- “小朋友也能”“很简单”“专家模式”等评价。
- 大号彩色数字暗示必须依次解锁。
- 用图标和照片替代清楚动词。

### 20.7 成人过密

禁止：

- 资源行同时堆作者、许可、难度、分钟、标签、评分和关键词。
- 方法页像 dashboard。
- 三个独立纵向滚动区。
- 默认展开全部理论、来源和高级字段。

### 20.8 拟物工作台

禁止：

- 真实 3D 书本、塑料托盘、木桌、毛毡和翻页动画。
- 表单控件被绘制成棋子、卡牌或转盘。
- 方法跨页因视觉造型而破坏响应式和 DOM 顺序。

## 21. 实现契约

### 21.1 Token

- tabletop-visual-tokens-v5-1.json 是 V5.1 数值唯一来源。
- CSS 变量由 JSON 生成并在 CI 比对。
- 不在多个选择器复制十六进制色值。
- Red / Yellow / Green 的 semanticRestriction 必须进入代码审查。

### 21.2 DOM

- 视觉网格不改变阅读和键盘顺序。
- 桌面三栏在 DOM 中仍按步骤 → 输入 → 摘要排列。
- 装饰编号、路线和边线使用伪元素或 aria-hidden。
- 组件覆盖 default、hover、focus、pressed、current、disabled、loading、empty、error 和 success 中适用状态。

### 21.3 图片

- 指定 width / height 或 aspect-ratio。
- 首页必要首图可 eager，其余 lazy。
- 四张首页 WebP 总体积目标不超过 600KB。
- 不加载外部图片 URL。
- FigurePlate 的图注与图片 ID 稳定关联。

### 21.4 功能不回归

必须保留：

- 首页三个入口。
- 阶段和问题筛选。
- 完整中文正文。
- section 锚点。
- 方法搜索与详情。
- 工具 from 返回来源。
- 草稿、导出、清除。
- 刷新、深链、前进后退。

### 22.5 响应式与无障碍

- 320 / 390 / 768 / 1024 / 1440px 根级横向溢出为 0。

- reduced motion 无 transform 和 smooth scroll。
- 颜色不是关键状态唯一信号。
- 焦点不被顶栏、目录或摘要遮挡。

### 22.6 Premium 完成度

- 视觉装置种类被控制，不像课堂拼贴。

- 图像像证据被装裱，不像商品或装饰。
- 全年龄清晰来自内容层级和可读性，不来自儿童化。

## 23. 治理

- 新增字体、纹理、阴影或图片处理。
- 新增页面角色或主要组件。
