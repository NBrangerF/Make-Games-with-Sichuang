# 六阶段最短资源学习路线 01

状态：review  
日期：2026-08-21

## 本阶段目标

资源入口已经能帮助不同背景的读者找到设计阶段，但进入一个入口后仍会同时看到 7 到 8 份资料。对第一次学习这个主题的人来说，“资料都相关”仍然不等于“知道怎样开始”。

本阶段为六个设计阶段的首要入口各编辑一条三份资料的最短路线。它不是推荐榜，也不取代完整清单。它只回答四个问题：先读哪份、为什么现在读、阅读时看什么、读完马上做什么。

## 六条路线

| 设计阶段 | 资源入口 | 最短路线目标 |
| --- | --- | --- |
| 体验意图 | 选一条能产出行动的学习主线 | 从练习开始，比较教学结构，再阅读不同设计师的判断 |
| 核心系统 | 把体验意图接成可重复的核心循环 | 写体验、隔离最小交互、画出循环 |
| 最小原型 | 第一次把点子做上桌 | 理解最小范围、快速制作、用中文案例检查取舍 |
| 测试与反馈 | 准备第一次外部测试 | 选择测试类型、准备观察、确认参与边界 |
| 规则与信息 | 让陌生人学会并查得到 | 搭规则结构、降低理解负担、比较独立阅读差异 |
| 呈现与发布 | 准备生产、投稿或发布 | 比较路线、建立组件规格、检查合同责任 |

权威内容位于 `content/resource-learning-paths.json`。每条路线严格包含三项，每项必须有：

- `guideTitle`：本站中文学习标题，不冒充原作正式译名；
- `purpose`：为什么此刻阅读；
- `focus`：阅读过程中优先寻找什么；
- `action`：读完以后立即产生的设计动作。

原始题名、作者、语言、审阅深度、核验日期和来源记录继续由资源台账提供。

## 页面行为

- 学习路线位于当前问题说明之后，完整资源列表之前。
- 三份资料使用有序列表和分隔线，不建立新的卡片墙。
- 点击任一项直接打开本站中文导读。
- 被选入路线的资料在完整列表中显示本站中文学习标题，并明确标记“已收入本阶段最短学习路线”。
- 站内导读复用同一份权威数据，将摘要、阅读重点和行动替换为当前路线的具体版本。
- 未进入路线的资料仍使用现有导读与审阅信息，不降低可见性。

## 策展边界

三份资料的顺序表达学习脚手架，不表达质量高低，也不声称适用于所有项目。编辑时采用以下约束：

1. 第一份帮助读者缩小当前问题。
2. 第二份提供方法或操作结构。
3. 第三份补充案例、边界或责任语境。
4. 优先使用已经完成文章级或全文审阅的资料。
5. 中文学习标题是本站编辑层，不改变原始题名。
6. 站内导读仍遵守现有版权边界，不复制未获授权的全文。

## 质量门

`pnpm qa:resource-learning-paths` 检查以下不变量：

- 六个设计阶段全部覆盖；
- 每条路线正好三份资料且不重复；
- 每份资料真实存在并属于对应入口；
- 中文标题、用途、阅读重点和行动完整；
- 新增可见文案不使用长破折号；
- 权威数据进入轻量发现分片；
- 列表、导读与窄屏布局都消费同一份数据；
- 守卫进入完整 `content:check`。

## 仍需真人验证

- 第一次使用者是否会先看三份路线，还是继续直接滚到完整清单？
- 三份的长度是否足以建立方向，又不会形成“官方唯一顺序”的误读？
- “阅读时看”和“读完就做”是否能产生可观察的设计材料？
- 有经验的设计者是否容易越过路线，继续使用完整清单与筛选？
- 中文学习标题是否清楚表达用途，同时没有被误认为原作正式译名？

当前只能确认结构、数据引用和交互成立，不能代替不同背景学习者的形成性测试。
