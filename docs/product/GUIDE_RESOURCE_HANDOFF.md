# 核心指南—精选资源交接契约

状态：implemented / static-verified / browser-pending  
日期：2026-08-21

## 问题

六阶段核心指南已经能帮新手理解当前问题、做练习和打开工具，但“继续阅读”只是一排单条外链。读者需要自己理解二十多条来源的用途，再去资源库重新找入口。这让“当前阶段”与已有的 34 个任务型阅读入口断开。

本契约只修复这一次交接，不新建书单、排名或推荐分。

## 六阶段映射

| 当前指南阶段 | 精选阅读入口 | 入口 ID |
| --- | --- | --- |
| 体验意图 | 选一条能产出行动的学习主线 | `choose-learning-spine` |
| 核心系统 | 把体验意图接成可重复的核心循环 | `core-loop-handoff` |
| 最小原型 | 把完整游戏裁成这一轮可回答的原型 | `prototype-scope-and-fidelity` |
| 测试与反馈 | 准备第一次外部测试 | `first-playtest` |
| 规则与信息 | 让陌生人学会并查得到 | `rules-and-teaching` |
| 呈现与发布 | 准备生产、投稿或发布 | `production-and-publishing` |

映射只维护在 `src/guide-resource-handoff.ts`；构建守卫会检查六个阶段全部覆盖，且每个 ID 确实存在于策展入口数据。

## 交互与 URL 契约

- 每篇核心指南的“继续阅读”首项是真实链接“继续阅读本阶段精选资源”。
- 链接可复制、在聚焦或指针预期时预取目标入口包，点击后写入 `#resources/<entry-id>`。
- 资源页的入口选择由 URL 控制；切换入口、刷新、复制链接或浏览器历史都保持同一目的地。
- 直接打开深链时，初次只请求对应入口包，不先加载默认入口或 574 条完整目录。
- 未知入口 ID 回退到默认入口，并用 `replaceState` 改写为有效深链，不制造错误历史节点。
- “查看全部”、搜索词和组合筛选仍是会话状态；本轮不把它们扩进 URL。

## 可访问性与呈现边界

链接使用现有指南来源样式和箭头图标，不引入新布局或视觉概念。它保留原生链接语义、键盘聚焦和可复制 `href`。程序化加载与失败恢复继续复用现有资源分片边界。
