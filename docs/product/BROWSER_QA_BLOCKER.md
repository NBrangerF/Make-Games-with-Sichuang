## 结论

应用内浏览器现已确认本轮 URL 导航与窄屏无溢出的有限范围；系统 Playwright 仍确认当前沙箱不允许所需 Chrome 子进程。不得把有限烟测扩写成十九项工具全套通过，也不得把 `pnpm qa` 脚本存在、类型检查、生产构建或旧截图写成最新完整浏览器证据。

## 可重试条件

满足任一条件后重试：

1. 允许 Vite 在 `127.0.0.1:5175` 监听；
2. 应用内浏览器暴露请求路由或可访问工作区静态服务器；
3. 沙箱允许 Playwright 启动 Chromium/Chrome 子进程；
4. 外部 CI 提供 Linux Chromium 与构建产物。

重试顺序：先运行 `pnpm build`，再运行 `pnpm qa`；若端口仍被禁而浏览器进程可启动，再实现并验证 `QA_DIST=1` 的虚拟 HTTP 路由模式。不要在浏览器无法启动时提交未经执行的 QA 运行模式。
