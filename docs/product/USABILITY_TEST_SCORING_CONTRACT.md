# 可用性测试：计分契约指南

日期：2026-08-20  
状态：计划；尚未执行  
对象：3–5 名有原型或能读懂简短规则的中文新手设计者

## 目标

验证参与者能否在不先改分值的情况下：

1. 分开结束、胜负与计分；
2. 从一次得分向前追到玩家决定与机会成本；
3. 区分计分来源和真实路径；
4. 描述计分速度、可见性与知道后的合法回应；
5. 分开系统结果、玩家理解、互动与体验证据。

不测：参与者设计水平、作品质量、最佳分值或工具满意度总分。

## 材料

- 一个 8–12 行的海上贸易原型摘要；
- 两条表面不同、但由同一收入引擎推进的计分栏；
- 一项即时公开分与一项秘密终局分；
- [计分契约一页模板](../guides/SCORING_CONTRACT.md)；
- 纸笔或可编辑副本。

## 任务

### T1 · 拆三条规则

提示：“请指出游戏何时结束、什么决定赢家、哪些东西怎样换成分数。”

成功动作：三项分别写出，并能说明是否重合。  
失败信号：只抄“最高分获胜”，遗漏停止/收尾或换算。

### T2 · 追踪一次得分

提示：“选择交货得分，向前追到玩家最后一次真实选择，再写它让玩家下一轮更可能做什么。”

成功动作：包含事前信息、至少一个替代、机会成本、即时反馈和下一行为。  
失败信号：只写数值，或把设计者知道的所有选项当成玩家实际考虑。

### T3 · 比较两条路径

提示：“这两栏是两条策略吗？请用承诺、切换成本和互动说明。”

成功动作：发现同一收入引擎可能同步推进两栏，并保留反例。  
失败信号：按计分栏数量直接数路径。

### T4 · 可见性与回应

提示：“若公开秘密合同分，玩家具体能做什么？若继续隐藏，又增加什么劳动或风险？”

成功动作：至少写一个合法回应和一个隐藏/公开代价。  
失败信号：只写“公开公平”“隐藏有悬念”。

### T5 · 分轨与单一改动

提示：“请各写一个系统、行为、互动和体验记录，再只选一项改动。”

成功动作：不以终局分差替代理解或乐趣；改动只选分值、时点、可见性或反馈之一，并写反驳信号。  
失败信号：同时重做目标、分值、牌库和最后一轮，或生成总分结论。

## 观察字段

```text
task / completion / assistance
first_interpretation
term_blocker
first_divergence
lookup_or_calculation_work
source_vs_path_explanation
visibility_response
evidence_tracks_kept_separate
single_change_and_counterevidence
participant_words
```

## 重点词汇

- “计分函数”是否比“计分规则”更难；
- “路径承诺”“切换成本”“可追踪但隐藏”是否需要例子；
- “实际进展 / 感知进展”是否会被误读为真分 / 假分；
- “系统轨 / 互动轨 / 体验轨”是否过多。

## 停止与边界

- 单次任务超过 15 分钟或参与者连续两次请求解释同一字段时停止；
- 允许查原型规则，但记录查找位置与恢复步骤；
- 不评价参与者算术、策略或设计能力；
- 不把 3–5 人形成性测试写成效果、完成率或偏好比例；
- 未执行前，网站不得声称计分契约改善了设计质量。
