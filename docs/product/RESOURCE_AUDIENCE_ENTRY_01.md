# 资源受众入口与分层阅读 01

状态：review  
日期：2026-08-21

## 本阶段解决的问题

资源站已经能按桌游设计阶段和具体问题组织资源，但读者未必知道自己处在哪个阶段。第一次设计桌游、已经有原型、习惯从案例学习、需要带课，以及准备发布的人，会用不同方式描述同一个学习需求。

本阶段不再扩充主导航，而是在阶段入口下面增加一个默认收起的备用脚手架。读者只有在无法判断阶段时，才需要打开“我不知道自己在哪一步”。

## 分流原则

- 主结构仍然是六个设计阶段，以及同一阶段中的不同问题路径。
- 备用入口只询问此刻的处境，不询问年龄、教育身份或自评能力。
- 处境入口不创造平行资源库，只把读者送到已有的权威资源入口。
- 同一份资源可以服务不同经验的人，页面用阅读提示提供支持，不把人锁进永久等级。
- 高级筛选仍然收起，供知道自己要找什么的人主动使用。

权威数据位于 `content/resource-audience-paths.json`。当前包含六种处境：第一次设计、从游玩学习、资料过多、已有可玩版本、带课或工作坊、准备投稿或发布。

## 页面层级

资源首页按以下顺序提供选择：

1. 选择设计阶段。
2. 选择当前要解决的问题。
3. 如果无法判断阶段，展开处境入口。
4. 如果已有明确检索目标，展开完整筛选。
5. 在资源列表中查看阅读支持、常见用途和适用语境。
6. 打开站内中文导读，按“先看这一句、怎么开始读、读完先做、适合谁、阅读时要留心”阅读。

## 阅读支持规则

阅读提示由 `content/resource-assessments.json` 的审阅元数据生成，不新增未经审阅的判断。

| 审阅字段 | 页面表达 |
| --- | --- |
| 包含 `beginner` | 第一次接触这个主题也可以 |
| 不含 `beginner`，包含 `intermediate` | 适合已经在做一个项目时阅读 |
| 仅含 `advanced` | 内容较深入，建议先看本站导读和相关概念 |
| `useModes` | 系统学习、诊断问题、比较观点、快速查询、阅读案例 |

这是一种阅读支持，不是质量评分，也不是对读者能力的评判。

## 响应式与可访问性

- 处境入口使用原生 `details` 和 `summary`，无脚本时仍能表达收起关系。
- 六个处境使用有名称的导航与原生按钮，支持键盘操作和焦点预取。
- 桌面端为两列线性入口，窄屏自动变为单列。
- 阅读用途不能只靠颜色表达，所有提示都有可读文字。

## 质量门

`pnpm qa:resource-audience-paths` 会检查：

- 数据字段、唯一 ID 和入口引用完整；
- 未使用年龄与教育阶段做分流；
- 数据随轻量发现目录加载，不进入初始主包；
- 备用入口、可访问名称与分层阅读顺序存在；
- 守卫已进入 `content:check`。

## 下一轮真实测试问题

- 不解释六阶段时，第一次设计者能否在 30 秒内选择一个入口？
- 已有原型的人会选择“已有一个能玩的版本”，还是误选“第一次设计”？
- 带课者进入学习主线后，是否能理解这不是唯一课程顺序？
- 深入资料的提示是在提供支持，还是让读者误以为自己不该阅读？
- 列表中的三枚以内提示是否足够，是否造成新的信息堆叠？

当前只完成结构和静态质量门。上述问题仍需要不同背景的真实读者完成形成性测试，不能由实现者自行宣称通过。
