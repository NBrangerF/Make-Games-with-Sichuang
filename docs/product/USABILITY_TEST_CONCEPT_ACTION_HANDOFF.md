# 新手可用性测试：从概念回到行动

状态：ready / sessions-0  
日期：2026-08-21

## 目标

检验新手能否把一个刚理解的概念带入专题或工具，再回到原词条；不检验记忆成绩、设计能力或工具是否提高作品质量。

## 参与者

- 首轮 3 名近一年没有系统桌游设计经验的中文用户；
- 不提前解释“专题指南”“工作单”或地址栏行为；
- 使用虚构项目，不填写真实参与者、健康、机构或未公开项目资料。

## 起始地址

`#method/glossary/prototype-fidelity`

主持人只说：“你正在查‘原型精度’，接下来想知道它在测试任务里怎么被使用。”

## 任务

### C1：从概念找到专题

请进入一篇会实际使用“原型精度”的专题，并告诉主持人你预期下一页会是什么。

记录：是否独立找到“在专题里看它怎么用”；是否把阶段标签误认成推荐等级；专题地址是否正确。

### C2：回到原概念

不使用顶部主导航，回到刚才的“原型精度”词条。

记录：浏览器后退是否成功；是否丢失任务语境；是否需要协助。

### C3：把概念带去工作单

从词条打开“原型范围裁剪器”，指出这个入口是建议、排名，还是一个可继续工作的选择。

记录：能否找到工作单区；工具落点与地址是否正确；是否理解非推荐边界。

### C4：从指南返回规范定义

打开“这轮应该怎么测试”，再从指南末尾的概念标签返回“原型精度”。

记录：概念标签是否被识别为链接；是否回到同一个规范词条；能否再次使用后退。

### C5：分享给另一位设计者

复制当前概念地址，并解释接收者会看到什么、不会看到什么。

正确边界：地址恢复词条，不保存搜索词、阶段筛选、项目、表单或参与者数据。

## 首轮通过门槛

每项分别判断，不合并成总分：

- 3/3 无主持指路完成 C1；
- 3/3 用浏览器后退完成 C2；
- 3/3 完成 C3，且无人把入口称为质量排名或唯一正确下一步；
- 至少 2/3 无提示完成 C4；
- 3/3 对 C5 的隐私范围没有关键误解。

任何 `task_help` 后的完成只算“协助完成”，不算独立成功。

## 失败后的单变量修订

- 找不到专题：只改分组标题或链接层级；
- 不理解工具入口：只改“工作单”说明或工具标签；
- 后退迷失：只改落点标题/返回上下文，不同时重排整页；
- 把关系当推荐：只强化非排名说明，不移除真实关系；
- 指南概念不可发现：只调整概念链接的可见交互态。

每次只修一个主要阻断，再用新参与者复测同一任务。

## 不能推出

通过 C1–C5 不能证明用户学会了原型理论、做出了正确原型、理解全部 287 个概念，或网站能改善设计质量。它只证明这条导航交接在给定任务与用户中可用。
