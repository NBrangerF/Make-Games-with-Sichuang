## 一句话结论

本轮没有增加首页功能，而是把既有二级入口补成更能直接学习的资源站：默认页仍只有三个主任务和一个次级搜索入口；系统路线现在有 5 个本站原创完整单元，完整来源译文有 3 篇，设计师决定案例有 5 篇，共 13 份内部权威学习正文。所有正文都能在站内直接阅读中文版本，阅读正文不会生成可点击的外部链接。

## 入口与 UI 的减法边界

本轮内容增加，但入口没有增加：

1. 首页继续只有学习、分析、按问题找资料三个主入口。
2. 学习方式页继续只有系统学习、设计师思考、边玩边学、小练习四个入口。
3. 系统学习页只扩充两组既有清单，未加入筛选、标签、进度、账户或推荐算法。
4. 设计师思考页从 3 篇扩为 5 篇，仍是一列问题标题加一句结果。
5. 设计问题路线继续使用阶段、问题、三份起步内容的两次决定。
6. 正文中的来源以站内来源记录呈现，不能点击跳离本站；外部图片只显示文字说明。
