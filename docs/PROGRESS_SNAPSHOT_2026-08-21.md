# 桌游设计资源网站：阶段进度快照

日期：2026-08-21  
状态：本地 MVP 已成型；公开发布与真人验证尚未完成  
用途：暂停扩张后的统一交接点，后续工作先以本文件和总目标审计为准

## 一句话结论

项目已经不再只是资料搜集，而是一套可运行的本地桌游设计学习与实践产品：研究库、六阶段设计路径、任务型阅读入口、方法知识库和十九项本地优先工具均已接入网站。当前瓶颈已经从“缺内容、缺功能”转为“没有公开试用地址、没有真实新手完成任务的证据、浏览器与辅助技术硬门尚未完整关闭”。

## 已形成的用户体验

1. 新手可从“现在卡在哪里”进入六阶段设计路径。
2. 核心指南会把用户交给少量、与当前任务匹配的精选资源，不必回资源库重新搜索。
3. 方法页支持框架、概念、专题指南和资源评价的规范深链。
4. 概念不再是死胡同：可以回到相关专题，也可以直接进入可执行工具。
5. 工具链覆盖体验意图、核心循环、原型范围、单问题测试计划、现场记录、证据复盘与版本连续性。
6. 项目数据默认保存在本地，并可导出；网站没有把本地课程原文或参与者材料自动公开。

## 当前验证证据

- 内容校验、TypeScript 与生产构建已通过。
- 最新生产构建包含 89 个模块；主 JavaScript 包约 494.94 kB，保持在当前 500 kB 预算内。
- URL、方法分区、方法深链、概念行动、指南—资源、资源入口、主包边界、无障碍语义和发布契约等静态守卫均已通过。
- 2026-08-21 使用应用内真实浏览器重新打开了设计路径、资源库、方法词条和工具页；四个入口标题与主体正常，控制台无 warning/error。
- 当前本地预览入口：`http://127.0.0.1:8017/#path`。若服务未运行，可在 `dist/` 下执行 `python3 -m http.server 8017 --bind 127.0.0.1`。

这些证据说明当前构建“能运行并具备主要结构”，但不等于真人可用性、跨浏览器兼容性或 WCAG 签收。

## 尚未完成的关键事项

### P0：公开试用与真实新手验证

- 尚未创建公开部署，外部用户无法稳定访问。
- 已准备中文测试战役、主持脚本、安全模板和任务协议，但真实参与者会话仍为 0。
- 章程要求的 5 名新手无指导定位、4 名用户完成完整闭环、至少两轮可用性测试尚未达成。

### P1：浏览器与无障碍硬门

- 仍需完成修后键盘路径、抽屉焦点约束与返回、375 px、Safari/Firefox、VoiceOver/NVDA、对比度和真实残障玩家任务。
- 静态语义守卫和一次应用内浏览器烟测不能替代上述测试。

### P1：需要用户决策的内容边界

- 57 份本地课程资料维持“内部参考”是当前正确状态。
- 公开转译前，需要用户选择 1–3 个高价值结构，并确认作者、机构及第三方材料权利。

### 后续增强，而非当前发布阻断

- 组合筛选状态和工具内部步骤还不能通过 URL 精确恢复。
- “设计辅助练习闭环”仍是离线低保真测试仪器，不应在真人 T1–T6 完成前扩成第二十项正式工具。
