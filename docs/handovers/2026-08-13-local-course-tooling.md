日期：2026-08-13

## 本轮结果

- 在用户本地资料中确认两组核心课程：2019–2020“原创桌游解构与设计课程”和 2023“桌游设计·光华营地”。
- 建立可重复、只读的本地资料清单脚本；仓库清单包含 50 个候选文件和 2 组完全重复工作表，不包含绝对路径或原件正文。
- 主动排除合同、报价、对账、联系方式、实名学生作品、数据采集表与个人填写件。
- 深读课程大纲、Class 1–4、五课时 PPTX 和 12 份工作表，形成六步新手教学路径与五条风险修订。
- 将“只改变一个变量并预测行为”实现为网站工具，支持本地保存和 JSON 导出。
- 写成 Round 01 可用性测试方案与单场 JSON 记录模板。

## 关键文件

1. `scripts/index-local-materials.mjs`：重建资料清单。
2. `docs/local-materials/manifest.json`：机器可读文件级台账。
3. `docs/local-materials/INDEX.md`：范围、许可边界与课程内容索引。
4. `docs/local-materials/COURSE_SYNTHESIS_01.md`：六步路径和网站转译。
5. `docs/product/USABILITY_TEST_ROUND_01.md`：T1–T4 测试脚本。
6. `docs/product/usability-session-template.json`：单场记录模板。
7. `src/App.tsx`：`RedesignLab` 与 `ToolsView`。
8. `scripts/qa-site.cjs`：桌面、移动、保存和导出回归。

## 可复现命令

```bash
pnpm local-materials:index
pnpm content:check
pnpm check
pnpm build
pnpm qa
```

清单脚本读取原位置计算元数据和哈希，因此重建时需要两组本地目录仍可访问；它不会改动或复制原件。

## 边界

- 本地课程是教学案例，不是方法普遍有效的因果证据。
- 公开网站只能使用原创综合；权利复核前不得发布课件、截图、工作表正文或可逆向还原的长段改写。
- “主题必须冲突”“低精度永远更好”“总分代表质量”等旧课程表达已经在综合中加上限制，不应直接写入指南。
- 当前只完成内部自动化与产品走查，还没有真实新手参与者数据。
