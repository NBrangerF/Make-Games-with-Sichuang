# Phase 1 玩家经验与设计案例贡献协议交接

日期：2026-08-19  
状态：研究、离线协议、机器守卫与构建完成；贡献者走读、专业审查和在线征集未开始

## 本轮目标

上一轮确认中文残障玩家第一人称材料稀少，但“开始征集”会立刻引入真实身份、健康/障碍资料、儿童安全、版权、署名、补偿和撤回义务。本轮先建立一条不会自动收集或公开资料的离线协议，为未来玩家经验、设计日志、课程反思、资源纠错、无障碍任务记录和生产案例准备治理基础。

## 范围决定

审计发现 `docs/product/MVP_SPEC.md` 明确把“用户公开投稿与审核后台”列为非本轮范围。因此：

- 没有新增在线表单、上传、账号、联系人数据库或审核后台；
- 没有把贡献包列为正式第 13 个工具；
- 没有向任何外部人员发出征集或保存个人资料；
- 只新增研究、产品协议、JSON 模板、形成性测试模板和本地机器守卫。

## 完成内容

4. `contribution-package-template.json`：默认 `draft`、`review_only`、`no_quotes`、`none`，不包含联系人或原始同意证据。
5. `contribution-protocol-session-template.json`：C1–C5 走读参与/保存/公开/许可、最终副本、署名角色、撤回和 CC 不可撤销性。

7. 更新数据模型、MVP 边界、路线图、来源台账、项目索引、保真台账与 README。

## 关键产品判断

- 同意参加讨论不等于允许保存、公开引语或授予公共许可，这四项必须独立。
- 匿名化不产生公开许可；公开许可也不产生展示真实身份、健康资料或媒体的许可。
- CC 公共许可不可作为默认值；贡献者选择前必须理解已经取得副本者的许可通常不可撤销。
- 撤回承诺只有在资料能通过非公开贡献 ID 定位到同意、原始资料、编辑稿、公开稿、Claim 和页面时才可执行。
- 贡献角色需要分开生活经验、设计实践、调查、资料整理、分析、验证、翻译/沟通、写作、审阅与社群联络。
- 涉及儿童或额外保护需要时，普通模板不能直接升级为公开候选；本项目当前也没有足以开放此类征集的专业能力。

## 机器守卫

`pnpm contribution:check` 当前通过：

```text
contribution package ok: safe defaults + valid candidate + 11 publication guards
```

拒绝分支覆盖：

1. 未同意参与；
2. `review_only` 试图进入公开候选；
3. 未批准最终公开副本；
4. 无撤回定位键；
5. 联系资料或原始同意证据可能混入；
6. CC 不可撤销性未说明；
7. CC 未明确批准；
8. 第三方材料无来源/发布依据；
9. 选择公开引语却无批准记录；
10. 选择媒体却无逐项权利和批准记录；
11. 儿童/额外保护参与者缺少专业审查、相应监护许可、本人同意表达或停止升级计划。

机器通过只证明模板满足本项目写下的静态规则，不证明同意真实有效、许可合法或儿童安全审查完成。

## 权利与法律边界

- 本协议不是用户授权书、合同、隐私政策、法律意见、伦理委员会批准或儿童保护程序。
- 境外官方指南只提供产品治理问题，不能直接证明适用于中国大陆、香港、澳门或台湾。
- 真实征集前必须核验具体运营主体、地区、数据存储、责任人、响应时限、版权/隐私/儿童要求和补偿安排。
- 联系映射与同意证据不应进入 Git 仓库或可分享贡献 JSON。
