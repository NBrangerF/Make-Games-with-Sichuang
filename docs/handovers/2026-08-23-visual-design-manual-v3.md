## 视觉决定

### 产品名与系统名

- 产品可见品牌继续是 `桌游设计工坊`。
- `开放桌面 Open Table` 只作为设计系统内部名称。
- `仅限内部学习` 继续留在顶栏。
- 小于 480px 时几何标记隐藏，不挤占中文品牌和内部状态。

### 生产预算

风格板探索值为 `6 / 3 / 5`，生产页面不直接使用这个强度。生产上限为 `5 / 2 / 5`，入口页预算为 `3 / 1 / 3`。

### 三种入口形状

- 苔绿方形：学习
- 蓝色圆形：分析
- 陶土六边形：按问题找资料

它们只在资源首页顶层出现。下级入口不继续增加形状语法。当前状态使用边线、文字与语义属性，不使用圆形，避免与分析入口混淆。

### 重点页面

1. `ReadingShell` 使用章节轨加正文两栏，低于 960px 变单栏；不做不可成立的三栏。
2. `GuidedToolShell` 直接显示真实工具名、产出、来源、步骤与保存状态；不再双标题或横向步骤轨。
3. 方法详情先搜索或选问题，再显示少量结果；不把 287 个词条放进移动内嵌滚动区。
4. 全部资料明确为进阶查找，默认只显示搜索与少量推荐，筛选二次展开。

## 研究与权利边界

研究覆盖 Ticket to Ride、Pandemic、Carcassonne、Azul、Splendor、Codenames、7 Wonders、Wingspan、Root、Turing Machine 与 MicroMacro。最终提炼出的六条方法是：信息就地、状态外显、颜色冗余、规则分层、工作区贴合流程、材质承担功能。

研究文件已经完成第二轮事实与权利边界复核。它明确：

- 方法与具体表达需要区分。
- 翻译属于演绎作品范围，内部和非营利不会自动取得翻译权。
- 玩法版权判断不能替代商标、trade dress、专利与外观设计检查。
- 游戏名称可以在案例中准确识别来源，但不能成为本站品牌或制造授权混淆。
- 署名、来源记录和裁切本身不构成素材许可。
