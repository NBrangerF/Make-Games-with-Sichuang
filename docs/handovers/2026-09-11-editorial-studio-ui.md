# 落桌视觉更新与全站语言入口

本次将“有编辑感的桌游设计学习馆”落实到现有 React / Vite 站点。没有迁移框架、购买组件或使用额外 API。

## 已实现

- 全站共用页头、品牌字标、导航图标与选中反馈。移动端四个入口始终可见，修正旧导航负边距导致的溢出。
- 右上角常驻翻译图标及“中文 / EN”。菜单显示语言自称及当前项，使用 Radix 的焦点与键盘交互。
- 切换双语页面时保留当前文章、案例小节、查询、类型、设计问题和阅读返回链接；语言偏好保存在本机。旧工作区通过 `lang` 参数保留界面偏好，不改变项目、版本或轮次。
- 首页沿用过河原型图，统一按钮与目录层次。资源库将首屏长引导折叠，把搜索、分类与条目提前；以不同图标区分机制、主题、教学与比较。
- 案例页将更细的筛选折叠，激活筛选时保持展开。阅读页改善侧栏排版，在 900px 以下默认折叠目录，将相关内容移到正文之后。
- 工作台修正三项直接子元素自动排入两栏造成的巨型窄标题；任务入口采用统一纸色、深绿与陶土色。

## 双语范围

原创课程、文章、机制主题库、案例与隐私页面使用现有中英文内容。旧设计实践与工具仍有中文专用正文；英文导航进入这些页面时会明确提示。全站语言入口不能被解释为所有旧工具已完成翻译。旧工作区的数据与流程保持原样。

`switchRouteLanguage` 负责地点保持；阅读地址仍使用既有 `/zh-CN` 与 `/en`。旧工作区使用 `?lang=en`，避免把实践课误导向系统阅读首页。

## 验证

- `pnpm check`：TypeScript 检查。
- `pnpm build`：搜索索引、内容与领域检查、阅读导航、可访问性契约、构建检查等既有完整流水线。
- 新增 `qa:interface-language`：9 组切换、刷新与工作上下文用例，反向切换和无效参数；已接入完整检查。
- 浏览器实测：1280 桌面、768 平板、390 手机与 320 窄屏。检查页头、语言菜单、中英文资源库、首页、案例、阅读、工作台；实际测试 `worker` 搜索 + 机制分类从英文切回中文，随后进入同一条目。
- 320px 中英文资源库均无页面横向溢出；四个导航位于视口内。语言按钮点击区域至少 44px 高。
- 全量主入口压缩包由旧构建约 178,641 bytes 增至约 214,564 bytes（同一 Python gzip 方法测量，约增加 35 KiB）。Motion 完整入口已改为 mini。Vite 仍提示既有大内容 chunk；本轮没有扩大整书或全文数据的首屏加载范围。
