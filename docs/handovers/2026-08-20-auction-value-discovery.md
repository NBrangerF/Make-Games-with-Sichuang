## 关键产品决定

1. 不把“英式 / 暗标 / 二价”当完整设计。内容模型要求标的、价值、信息、竞价、分配、支付、资金去向、落败者、边界状态、反馈和整局连接。
2. 测试记录分开主观最高价值、实际报价、支付、后来兑现价值和当时解释；成交价不直接代理估值。
3. 赢家诅咒只在共同/相关价值和估值噪声边界内使用；私人价值的后悔保留阻断、预算、压价失败、误解与情绪升级等竞争解释。
4. 储备未达、并列、零报价、流拍与非法出价在开拍前写入协议并演练，不等首次发生再桌边裁决。
5. 竞价渠道按感知、算术、记忆、表达、动作、时间和社会压力做任务观察；替代提交方式必须保持相同信息与行动时机。
