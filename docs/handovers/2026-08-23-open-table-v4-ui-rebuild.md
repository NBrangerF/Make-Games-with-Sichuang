## 1. 本阶段结果

本轮把视觉设计手册应用到了正式 React 站点，不是只制作概念图或静态样板。资源站的信息架构、中文内容、资源规模、深链、懒加载、本地存储和工作单业务逻辑保持不变；全站基础、入口、资源、长文、方法、工具和系统页面获得同一套视觉语言。

本轮做出的核心判断：

- 网站首先是资源站。首页只保留学习、分析、按问题找资料三个并列入口，以及一个次级“搜索全部资料”。
- 桌游气质来自信息就地、状态外显、形状冗余、规则分层和贴合任务的工作区，不来自复制棋盘、美术、组件或品牌外观。
- 面向小学生到成人共同使用时，不做低龄主题和用户身份模式；用“先做一步、先看例子、理解原理”的按需脚手架控制阅读负担。
- 工具继续出现在相关资料和单元之后，正式工具深链保留，但不恢复顶栏工具货架。

## 2. 从经典桌游抽象出的实施规则

| 观察来源 | 只保留的问题解法 | 本站原创实施 |
| --- | --- | --- |
| Ticket to Ride | 路径必须同时让端点与当前位置可见 | 长文左侧章节关系轨与细线节点 |
| Pandemic / Ahoy | 高频规则与当前任务放在动作附近 | 阅读状态、就近工作单、工具当前步骤说明 |
| Carcassonne | 连接关系要明确，复杂规则按需加入 | 资源关系线、原生 `details`、移动折叠目录 |
| Azul | 输入、处理、产出和溢出各有归属 | 纵向工作单步骤、字段旁边界与持续摘要 |
| Splendor | 累计影响持续可见，一次只做一个主行动 | 工具摘要与单一实心保存动作 |
| Codenames | 可见范围与完成痕迹不能只靠颜色 | 具名状态、版本、文字与边线共同编码 |
| 7 Wonders | 类别需要颜色之外的第二编码 | 首页方形、圆形、六边形三种无数字入口标记 |
| Wingspan / Root | 第一次行动与完整规范源分层 | 例子、正文、术语和工作单读取同一中文内容体系 |
| Turing Machine | 防错发生在当前步骤 | 工具字段检查、缺失项、保存状态与恢复动作 |
| MicroMacro | 保留总览，但一次只问一个观察问题 | 分析入口的问题镜头与返回总览动作 |

这些来源只用于研究与决策记录。正式界面未复制任何地图、插画、卡框、角色、图标、硬件机制、原规则文字或标志性组合。

## 4. 页面模板映射

### 资源首页与入口

- 桌面使用文字行动区加原创规则书俯视图；960px 以下隐藏图像，不影响任何任务。
- 三个入口是一列开放列表，不是卡片墙；方形、圆形、六边形只作冗余编码，不显示 `01/02/03`，不暗示顺序。
- 标题、收益和下一步使用原生文字，图片没有烘焙 UI 文案。

### 资源主题与完整目录

- 阶段和当前问题仍是首要逻辑，列表使用线性资料记录而非缩略图或评分墙。
- 资源中文标题、适用理由、完整度和来源层级保持可读；574 条权威目录仍按需加载。
- 未增加年龄、身份、积分、推荐排名或外跳阅读。

### 完整中文长文

- Markdown H1 继续是页面唯一 H1，没有重复标题。
- 每个 H2/H3 有稳定 `reading-section-*` ID；桌面章节轨显示当前文章结构，低于 960px 改为折叠目录。
- 内容状态、正文、上下文工作单、上一篇/下一篇和来源记录处于同一阅读流。
- 表格保留局部横向查看能力，页面根级不横向溢出。

### 方法与概念

- 入口页继续只有“解决任务 / 理解方法 / 查设计词”三个行动。
- 方法详情、术语和专题指南保留原有懒加载与深链；V4 统一排版、边线、焦点、索引与详情层级。

### 配套工作单

- 外层 H1 是真实工具名，不再以“这一步的练习工具”占用主标题。
- 核心工作单在桌面使用左侧纵向步骤，移动端改为单列步骤；手机不再依赖横向步骤轨。
- 编辑区、持续摘要、保存状态与导出边界使用同一纸面和线条语法；所有原字段、本地保存和导出结构保持不变。
