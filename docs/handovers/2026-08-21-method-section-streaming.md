# 方法页标签级分片交接

日期：2026-08-21  
状态：implemented / production build verified / rendered timing pending

## 本轮目标

内容增长后，“方法”页的单一动态 chunk 已达 509.75 kB（gzip 169.46）。默认标签只显示 5 张理论框架卡，却同时下载 287 个完整词条和 32 篇专题指南。本轮要把加载边界改成用户实际选择的标签，不改内容、顺序或证据边界。

## 已完成

1. 删除把三类内容绑在一起的 `src/method-catalog.ts` 和 `MethodCatalog` 整包类型。
2. 新建 `framework-catalog`、`glossary-catalog` 和 `special-guide-catalog` 三个数据边界，各自动态导入、去重、且在失败后释放 Promise 以便重试。
3. 方法页的标题、导语和四个标签不再被数据请求阻塞。默认只加载框架；专题指南、词表和“资源怎么读”保持各自的第二层边界。
4. 主导航悬停/聚焦只预取默认框架；专题和词表按钮在鼠标悬停与键盘聚焦时对等预取。
5. 每个标签有自己的 `role=status`、`role=alert` 和重试按钮；一个标签失败不会把整个方法页伪装成空白页。
6. 新增 `pnpm qa:method-sections`，18 项守卫已接入 `content:check`；旧浏览器 QA 也改为分别检查三个 chunk 的意图前/后请求。
