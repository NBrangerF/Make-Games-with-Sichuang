# 资源库入口级分片交接

日期：2026-08-21  
状态：implemented / production build verified / browser timing pending

## 本轮目标

让新手进入资源库时只支付当前任务所需的 7–8 条策展资源，不因默认页面就下载 574 条资源与 574 份审阅。保留完整搜索、六维筛选、全部资源和九维审阅能力。

## 已完成

1. `pnpm resources:index` 现从三份权威 JSON 生成轻量来源索引、`id/title` 入口导航索引、入口 manifest 和 34 个包含完整资源+审阅的入口包。
2. 内容校验器检查生成文件集、顺序、字段范围、每条资源和每份审阅；权威数据变化但未重建时构建失败。
3. 资源库主导航只预取入口运行时、轻导航索引与默认入口。索引与默认包用 `Promise.all` 并行取得。
4. 切换入口时只加载对应 chunk；鼠标悬停和键盘聚焦具有对等预取。每个入口按 ID 去重 Promise，失败只释放对应缓存并可独立重试。
5. “查看全部 574 条”是唯一从资源页升级到完整目录的动作；“资源怎么读”因需完整审阅和量表，仍使用完整目录。
6. 新增 `pnpm qa:resource-entries`，23 项守卫已进入 `content:check`。浏览器 QA 改为断言：策展入口显示时完整目录未请求，点击“查看全部”后才请求。
