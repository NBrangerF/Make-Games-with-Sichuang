## 工具数据与边界

单条记录包含：版本、任务类型、玩家语境、主要教学媒介、目标动作、现在必须知道、延后信息、解释到行动、可重置实践、查询恢复、成功动作、第一次偏离、实际查看路径、主持人介入和下一版单一改动。

本地键：`tabletop-workshop-teaching-paths-v1`。  
导出：`schema_version: 1`、`method: single-learning-task-path`、`no_aggregate_score: true`。

有意不提供：理解总分、规则质量分、媒介排行榜、自动“已学会”、通用最佳教学顺序。一次记录只能说明当前版本、玩家语境、媒介与帮助条件下的当前任务。
