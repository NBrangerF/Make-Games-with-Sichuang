## 本轮目标

补齐研究问题地图中“纵向专家学习”的缺口，回答：项目数量、日志、比赛和 Game Jam 怎样才可能转成可迁移的设计判断；并把结论变成新手可直接执行、但不生成等级分数的专题指南。

## 关键产品决定

1. 不显示设计师总等级，也不按工时、项目数、版本数、参赛、名次或出版状态计算成长。
2. 最小学习单位是一条情境化判断，不是整个作品：原框架、行动、证据、修订边界、新情境和迁移结果。
3. 区分设计中同期记录、测试后复盘与后来作品叙事，避免后见之明覆盖当时未知。
4. Game Jam、比赛、课程和挑战统一视为“练习容器”；它们可以组织约束与反馈，但完成不等于学习。
5. 继续、适配、失效和搁置都是有效出口；基于证据停止不是个人失败。

## 证据边界

- Cross 是跨设计领域综述，不是桌游训练试验。
- Dorst/Reymen 的阶段模型主要来自一名工业设计学生的回顾自评，作者明确称其为初步探索。
- 职业设计访谈主要偏电子游戏，小样本且不是纵向效果研究。
- Game Jam 文献多为短期、描述性单案例，通常没有对照组；安全、包容和角色分工会改变学习结果。
- 学生日志来自单门多周桌游课程；日志长度和格式不等于能力。
- 设计师与比赛日记是自述，受商业、回顾、成功叙事和 AI 转录影响。
- 中文公开来源仍缺同一桌游设计师跨多年、同期、包含放弃项目的可核验轨迹。
- “判断迁移记录”是本站产品推论，尚未证明能提高长期能力。
