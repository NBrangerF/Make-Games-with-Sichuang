## 关键决策

1. 网站以设计迭代阶段/问题为主导航，资源类型为次级筛选。
2. 内容单元采用“意图—系统—证据”三层，而非只讲机制定义。
3. 首版工具优先连接思考和测试，不复制成熟的组件排版或在线桌面平台。
4. 所有来源区分学术、一手实践、教学策展、社区和商业内容。
5. 中文资料是明显缺口，用户课程资料会成为重要但需处理授权的内部来源。
6. PDF 不进仓库、不发布提取全文；只保存书目、页码定位和原创摘要。
