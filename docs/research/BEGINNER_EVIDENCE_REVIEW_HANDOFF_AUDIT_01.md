# 新手证据复盘交接审计 01

更新：2026-08-21

## 审计结论

旧工具能保存原话、四类标签、证据摘要和三个处理动作，但无法回答“来自哪场、哪个版本、哪条事件、有什么反证、为什么选这个方案、下一版只改什么”。它更像反馈收件箱，不足以承接已经完成的现场会话。

## 新手最容易断裂的地方

| 断裂 | 风险 | 本轮处理 |
|---|---|---|
| 从记忆开始复盘 | 事后解释覆盖原事件 | 只能显式导入已完成会话，并显示来源 ID、版本、问题与语境 |
| 先写解决方案 | 玩家建议变成待办 | 第三步先完成发现、条件、反证和缺失，第四步才开放版本决定 |
| 看见“3 次”就判严重 | 记录粒度冒充优先级 | 计数只显示支持/反驳/未定/语境，并配固定边界提示 |
| 只保留“要改什么” | 下一轮无法判断为何改 | 同时要求保持项、候选方案、拒绝方案、变化轴、回退信号和下一问题 |
| 工具替用户更新项目 | 未完成判断进入路线图 | 保存与显式复制为项目下一步分成两个动作 |
| 撤回只删原会话 | 派生发现继续存在 | 会话撤回按来源 ID 清除本地派生复盘；导出副本另行声明 |

## 完成门

- 新手能从现场会话一键进入复盘，但必须自己选择证据。
- 在没有选择证据时不能形成发现；没有条件、反证和缺失时不能进入决定。
- “修改”必须至少有两个候选方案，且只允许写一个变化轴。
- 保存不改变项目；显式复制后才更新项目下一步。
- 旧数据迁移不会伪造不存在的来源或版本。

## 仍需可用性验证

1. 15 分钟内能否理解“反证/其他解释”而不把它写成反对意见。
2. 三栏桌面布局是否让来源、证据和发现保持可见，而不造成表单压迫感。
3. 手机单栏中四步导航、长事件和变更简报是否仍能回看。
4. “保护 / 修改 / 继续调查 / 暂存 / 不改”是否足够互斥。
