# 随机性、运气与可控不确定性：研究启动记录 01

更新：2026-08-20  
状态：review；资源、主张、术语、指南与入口已落盘，待中文用户测试

## 为什么需要从“概率平衡”中拆出来

站内平衡专项已经说明期望值、结果分布和实测指标不能单独证明体验，但随机性仍被压缩成“算概率”。真实设计至少还包含：

- 不确定性来自骰子、洗牌、隐藏信息、其他玩家、系统复杂度还是表演/叙事；
- 随机事件发生在决定之前、之后，还是跨多次决定形成循环；
- 玩家在暴露于随机结果前能看到什么、能否选择承担风险；
- 玩家能否通过准备、分散、保留、重掷、改面、止损或事后适应改变结果；
- 随机性改变局面多样性，还是直接主导胜负；
- 新手与熟练玩家能否以不同程度缓解同一种随机源；
- 玩家把结果归因于自己的决定、他人、系统或运气时，学习与公平感怎样变化；
- 随机装置同时承担随机器、公共状态或长期计数时，读取与操作成本如何改变。

因此“输入随机好、输出随机坏”也不足以成为产品规则。

## 站内已有基础

- `game-balance-probability` 已覆盖期望值、分布、独立骰子与不放回抽牌；
- `uncertainty-in-games-book` 只有出版社元数据，尚未深读付费正文；
- `claim-probability-is-not-experience-proof` 已建立数学与体验边界；
- `expected-value`、`variability` 等术语可复用，但缺随机事件时点、暴露、缓解与结果归因；
- 单轮决定轨迹可记录随机结果前后的模型更新；
- 单人模式的信息模型已分开稳定信号与随机扰动；
- 人数、结束契约和无障碍材料已经证明随机性会与配置、时钟、组件用途和支持条件交互。

## 第一轮外部证据

### 1. 输入/输出是时点描述，不是质量裁决

- Daniel Piechnick 的实践文把输入随机描述为先取得随机材料再决定，输出随机描述为先决定再随机结算；他倾向输入随机，并用 Radlands 扩展原型说明把“失败”改成仍有可用结果。该立场可生成修订候选，不能证明输出随机普遍较差。
- Isaac Shalev 的 Random Loops 批评二元分类：随机输出会成为下一次决定的输入；更关键的是随机事件与玩家需要回应之间的时间距离，以及循环中是否持续出现新决定。
- Ross Przybylski 明确反对“输出随机一律应避免”，主张随机结果可让玩家学习在不确定下准备。文章以数字策略游戏为主，是设计论证而非效果研究。

### 2. 随机事件数量不等于随机性对胜负的影响

Goodman、Perez-Liebana 与 Lucas 的 *Measuring Randomness in Tabletop Games* 用固定/改变随机种子的代理实验比较 15 款已实现桌游，并尝试拆开设置、牌库、骰子等不同随机源。论文指出：一次随机事件可以直接决定胜负，100 次事件反而可能互相平均；玩家技巧又可能缓解坏结果或利用好结果。

该方法支持问“某随机源对代理结果方差贡献多大”，不测：

- 玩家是否觉得结果公平、有趣或可理解；
- 代理是否像目标玩家；
- 主题、戏剧性、社交归因与实体操作；
- 哪个数值是普遍甜点。

论文的 2025 扩展 *Seeding for Success* 进一步讨论技巧与随机性的交互及误差范围。后续应避免把计算随机度做成用户质量分。

### 3. 输入随机也可能降低满意度

Zhang 等用自制数字集换式卡牌游戏比较四种输入/输出随机条件；摘要报告输入随机可以显著降低满意度。这一结果直接反驳“输入随机天然较好”，但需要取得全文方法、样本、效应与任务细节后才能使用；它也不能直接迁移到实体桌游、多人社交或熟练社群。

### 4. 可控性要拆成具体动作

“有运气缓解”不能作为单一标签。至少分开：

- **事前准备**：构筑、资源储备、位置、保险；
- **选择暴露**：是否攻击、抽牌、继续 push、选择风险档；
- **改变分布**：加骰、改面、移除坏牌、调整袋中组成；
- **选择结果**：掷后分配、择一、保留部分结果；
- **重试与代价**：重掷、支付、消耗行动；
- **结果转换**：失败仍获得学习、位置、资源或新的决定；
- **事后适应**：把已经发生的结果变成下一次决定输入；
- **止损与退出**：保存收益、停止继续冒险。

每项都会改变不同的决定、信息与成本；更多缓解按钮也可能只是增加查询和显然操作。

### 5. 一手案例候选

- *With a Smile & a Gun* 的设计日志把骰子改成共享池，玩家选骰决定移动；特定点数制造对手阻断与等待，而行/列访问让一次 hate draft 不至于直接毁局。它展示随机结果如何成为公开竞争输入。
- *Takeover* 日志记录 RNG-heavy 的特殊行动让玩家感到决定不重要，随后把效果改得更可靠并增加固定轮次结构。它是一个“减少结果漂移以恢复控制感”的具体商业案例。
- *Flatiron* 团队提到基本行动应始终可用，随机/可变部分只增加额外选项；适合研究“随机不锁死核心功能”，但需要找到直接文章与完整语境。

## 首轮研究问题

1. 不确定性来源与随机装置如何分开记录？
2. 随机事件发生在决定前后多久，玩家有几次回应机会？
3. 玩家是否自己选择暴露于风险，是否理解可能结果与代价？
4. 哪个随机源改变局面，哪个随机源改变胜负，哪个只增加维护？
5. 缓解动作改变分布、选择结果、重试还是事后适应？它的成本和所有权是什么？
6. 同一随机种子对新手与熟练玩家的影响是否不同？
7. 玩家如何解释胜负与单次坏结果，是否能从反馈学习？
8. push-your-luck 中的“继续/停止”需要多透明的概率、损失与回报？
9. 首局、不同人数、不同可访问性支持下，随机组件的读取和计算是否仍可执行？
10. 模拟与真人测试分别能回答哪些随机性问题？

## 候选产品方向

专题指南候选：`special-randomness-contract` / “先画随机事件前后的决定，再调概率”。

可能的五步：

1. 写目标不确定性与不想制造的失效；
2. 画“决定—随机事件—回应—下一决定”链；
3. 写暴露选择、信息、分布与 stakes；
4. 逐项标缓解动作、代价、所有权与维护；
5. 分开计算/代理与真人轨道，按经验、人数与版本复测。

可能复用：`decision-trace`、`test-plan`、`balance-pass`、`playtest-selector`、`feedback`。

## 明确不做

- 不生成随机度、运气、策略性或公平总分；
- 不把输入随机自动称为好、输出随机自动称为坏；
- 不把更多重掷、改面或补偿自动称为更多能动性；
- 不从事件次数推断对胜负的随机影响；
- 不把代理种子实验当玩家体验；
- 不把单次坏结果、玩家抱怨或“感觉很随机”直接改写成概率错误；
- 不把概率公开自动当可访问、可计算或可承担；
- 没有真实记录前不新增骰子优化器、自动随机度评分或最佳缓解推荐。

## 研究拆分与检索路径

本轮把大问题拆成五个可独立查证的子问题：

1. 输入/输出随机究竟是质量判断，还是相对某次决定的时间描述？
2. 如何区分随机事件数量、单次方差与随机源对整局结果的贡献？
3. “有运气缓解”具体改变暴露、分布、结果还是失败后状态？
4. 设计师与玩家如何描述控制、张力、无力和止损？
5. 代理测量、真人满意度与玩家自我归因分别能回答什么？

检索先从站内概率、体验与《Uncertainty in Games》元数据建立词表，再向一手论文、设计师本人文章、商业项目日志和玩家长评扩展。技术与实验主张只采论文/作者原文；实践判断与玩家声音保留其身份、项目和非代表性边界。最终深读 Zhang、Goodman、Shalev、Ernest、Piechnick 与 *Spots* 六项材料，并交叉复核其方法或完整上下文。

## 发现一：输入/输出是时点，不是质量标签

经典定义以某次决定为界：随机在决定前揭示是输入，在决定后结算是输出。但 Shalev 指出真实游戏是连续循环：Risk 一轮战斗的随机损失是这次攻击的输出，也立即成为“是否再攻”的输入；Carcassonne 抽到地块是当前摆放的输入，也会兑现之前布局对某些地块的押注。

所以至少要记录：

```text
decision_before → random_event → result_locked
→ response_window → post_result_decision → next_exposure
```

Zhang 等的实验进一步阻止站点把分类当裁决。18 名大学生在四天内体验自制数字集换式卡牌的四个条件：无随机、输入、输出、两者都有；输入随机以“玩家构筑外出现 mystery card”实现，输出随机以卡牌效果偏离牌面实现。含输入随机条件的总体满意度较低（重复测量结果 `F(1,15)=6.275, p=.024, partial η²=.295`），输出随机和交互未显著；作者同时承认研究可能功效不足、只测一种游戏且条件极端。

这不是“输入随机更坏”的新定律，而说明实现内容、选择被拿走的方式、对手、样本与经验可能比二元标签更重要。

## 发现二：事件次数、波动与结果影响要分开

Goodman 等的核心反例很直接：一次掷骰可以决定整局，100 次掷骰却可能互相平均。2025 扩展让同一随机种子运行大量代理对局，比较 15 款桌游，并在部分游戏中分别固定角色、地图、牌库或骰序列。它回答的是：

> 在代理、版本、座位与指标固定时，改变某个规则内随机序列会怎样改变结果分布？

它不回答“玩家觉得多随机吗”。论文也显示代理能力不是中性：原 2024 工作中的 Catan 代理太弱，无法利用好地图或骰序；改进代理后才观察到随机种子影响，而且初始地图对所选结果指标的贡献大于后续骰序。更高技巧有时会让某个有利种子更稳定地被利用，而非简单“技巧消除运气”。

因此站点保留四个不同字段：

- 随机事件数量与装置分布；
- 选定随机源对选定结果指标的贡献；
- 不同经验/代理利用机会的能力；
- 玩家看到的序列与主观随机感。

固定种子比较适合定位问题，不生成作品随机度或公平总分。

## 发现三：能动性首先在“是否承担”与“怎样回应”

Ernest 的 Crazy Train 框架让玩家在稳定路线与高波动路线间选择；重点不是每条路线谁期望值更高，而是随机暴露是否由玩家拥有、选择前知道什么、损失是否可恢复。Shalev 的回应距离再补一层：玩家在事件后立即锁死、同回合止损、下一轮调整，或下一局才学习，体验完全不同。

*With a Smile & a Gun* 提供实体案例：骰子先形成共享池，玩家选骰决定移动和阻断；行/列访问确保一次针对性拿骰不会直接切断关键行动。这里骰值仍随机，但随机结果经过：

1. 公开信息；
2. 玩家选择；
3. 对手读取与阻断；
4. 替代访问；
5. 高骰的长期代价。

它展示的是随机怎样进入决定结构，不证明共享池必然更好。

## 发现四：运气缓解必须写“操作—成本—所有者”

本轮形成八类而非一个 mitigation 标签：

| 类型 | 改变什么 | 最低记录 |
|---|---|---|
| 事前准备 | 进入随机前的承受力 | 构筑、位置、储备与机会成本 |
| 选择暴露 | 是否进入该分布 | 谁选择、看到什么、有无稳定路线 |
| 改变分布 | 好坏结果的概率/组成 | 加骰、移牌、改面、袋构筑 |
| 选择结果 | 揭示后保留哪一个 | 掷几取几、谁分配、信息公开性 |
| 付费重试 | 再次抽样 | 全体/部分、成本、次数、是否延迟同一失败 |
| 结果转换 | 较弱结果仍给什么 | 退款、状态、学习、新决定 |
| 事后适应 | 结果怎样改变后续计划 | 回应窗口、撤退、换目标 |
| 止损/保存 | 何时锁定已有收益 | 继续/停止、损失范围、退出所有者 |

Piechnick 的 Radlands 例把可能杀死角色的医院失败改成退款并转成仍可用的 punk；这是结果转换。*Spots* 评者则具体反感必须全体重掷、不能挑骰，以及一次坏掷在很低阈值下清空进度；同一评者又认可储备 Treat 作为保险、选择性重掷和掷多取二。其价值是展示这些操作体验不同，不是确认哪个机制客观有效。

## 发现五：状态多样不等于决定多样

洗牌、骰值和随机地图当然能让每局状态不同，但设计目标可能只是视觉变化、惊喜、平衡差距、记忆防解、故事或策略适应。若每个状态都要求相同显然操作，随机性只增加维护；若坏结果切断核心行动，它可能制造无力而非新策略。

*Takeover* 的团队回顾：开放行动叠加依赖命中的 RNG-heavy 特殊效果，使测试者觉得胜负与决定无关。团队同时提高效果可靠性、把每轮固定为四组牌、恢复跟牌限制，并改成单牌能力。因为多个结构一起变化，案例不能证明“少 RNG”单独修好游戏，却提示测试要同时看可靠性、限制、信息可推断性和轮结构。

最低重复游玩记录因此不是“设置不同”，而是：

```text
random state changed
goal changed?
candidate actions changed?
ranking of options changed?
new adaptation appeared?
maintenance only?
core function blocked?
```

## 发现六：计算结果、真人体验与结果归因是三条轨道

Goodman 等测代理结果，Zhang 等测实验满意度；两者回答不同问题。Wohl 与 Enzle 的纯机会实验摘要又显示，仅仅拥有选择就可能提高个人幸运感和自觉胜算。Okamoto 等让触屏反馈在真实技能与随机状态间隐藏切换：66 名参与者中 51 人进入主要分析，参与者更常在正反馈后判断为技能、负反馈后判断为随机。

这些相邻心理学证据不能直接迁移现代桌游，却足以否定两种粗暴做法：

- 玩家感到有控制，因此概率一定被改变；
- 玩家说输在运气，因此系统随机源一定主导胜负。

真人测试至少把以下内容放在同一事件行：

```text
version / configuration / experience
uncertainty_source / random_sequence
decision_before / information / exposure_choice
result / valence / response
player_attribution / confidence / next_action
observer_note
```

设计者再将这些观察与概率、固定种子或配对序列结果并列，而不是压成单一分数。

## 研究综合：随机性契约

本轮最终采用六层结构：

1. **承诺层**：为什么需要不可预测，不能制造什么失效；
2. **来源层**：随机装置与隐藏信息、对手、复杂度等分别是什么；
3. **循环层**：决定—随机—回应—下一决定的时点与距离；
4. **暴露与缓解层**：谁承担、知道什么、能怎样改变或止损；
5. **系统结果层**：随机源对明确结果指标的贡献；
6. **体验与归因层**：目标玩家如何理解、感受、回应并解释结果。

其中第 5 层不能证明第 6 层，第 6 层也不能自动诊断第 5 层。指南 `special-randomness-contract` 把六层压缩成五步任务，并复用现有决定轨迹、测试计划、平衡通行证、反馈分类和测试选择器，不新增自动推荐器。

## 剩余限制与下一验证

- Zhang 样本只有 18 人且为数字卡牌/AI 对手；需要实体、多人与中间强度随机条件；
- Goodman 使用已实现游戏与 MCTS，代理行为和所选指标限制解释；
- 纯机会与视觉运动心理学不是现代桌游；迁移只生成测试问题；
- 设计日志与玩家长评没有代表性或单变量对照；
- 本轮英语来源仍占主导，尚缺中文设计师对骰子、袋抽与 push-your-luck 的完整一手日志；
- “stakes”“seed”等中英词对中文新手是否清楚尚未验证；
- 后续真人测试应同时覆盖首局/熟练、关键人数、视觉/数感/精细动作支持，以及至少一种不以胜负为唯一结果的游戏。
