# Kathleen Mercury 教学资源：结构研究

状态：review  
研究日期：2026-08-13  
入口：[Resources to teach strategy game design](https://www.kathleenmercury.com/)

## 为什么研究它

Kathleen Mercury 的网站不是普通博客归档，而是一套经多年课堂修订的免费教学资源。首页解释了她最初也难以找到合适资料，因此把从玩家、设计师、出版者和教育者处学习并改造的材料公开出来。这与本项目的起点高度相似，但也提醒我们：资源的原创归属和再利用许可需要按单项核对，不能因为“免费访问”就默认可以复制。

## 教学路径

其主线大致是：

```text
先玩多种策略游戏
→ 学会教游戏与分析游戏
→ 认识机制、冲突、目标和主题
→ 比较机制如何服务主题与决定
→ 快速原型
→ 测试与结构化反馈
→ 写规则
→ 最终评估
```

与很多“先想完整规则”的指南相比，Kathleen 后来主动把原型提前：她反思学生花太久写目标和胜利条件，而这些内容常在动手后改变，于是只保留足够的主题与机制思考，让学生更早制作、添加/删减机制和测试。[设计过程页面](https://www.kathleenmercury.com/the-design-process.html)把这种变化说得很清楚。

## 可借鉴的教学设计

### 1. 体验在术语之前

学生先玩约十种使用不同机制的游戏，再标记自己实际体验过的机制、讨论按功能分类，并通过修改简单游戏来观察机制如何改变选择。[How I Teach Mechanics Now](https://www.kathleenmercury.com/how-i-teach-mechanics-now.html)

**对本项目的影响**：机制学习页不应从长定义表开始。先给一个可在 5 分钟内玩的微型局面，让用户比较两个规则变化如何改变决定，再命名机制。

### 2. 机制是行动与决定的工具

[What Are Mechanics](https://www.kathleenmercury.com/what-are-mechanics.html)把机制首先解释为玩家可采取、或他人可对玩家采取的行动，并强调它们构造决策机会。熟悉机制也能降低学习成本，因为玩家能把已知规则块迁移到新游戏。

**对本项目的影响**：机制数据模型至少包含玩家动作、作用对象、所需信息、决策类型、典型规则块、学习前提，而不只是“定义/代表游戏”。

### 3. 从名词主题走向冲突/任务

[Conflict in Game Design](https://www.kathleenmercury.com/conflict-in-game-design.html)用“海豚”这类只有题材没有任务的学生创意说明：设计者需要描述整体层面和每回合层面的冲突，才能形成可玩的核心。

**对本项目的影响**：用户输入“海盗/太空/做饭”等题材后，工具继续追问：谁想改变什么？什么阻止它？玩家每回合在哪个稀缺条件下做选择？这里的“冲突”应宽泛理解为目标与阻力，不局限于直接攻击。

### 4. 用并列草图比较机制，而非在脑内选一个

[Choosing Your Mechanics](https://www.kathleenmercury.com/choosing-your-mechanics.html)让学生把同一主题应用到多种机制，或深入四种候选并绘制草图。这把“选择机制”变成比较实验。

**对本项目的影响**：提供三格机制草图，而不是机制推荐算法。每格只回答：玩家做什么、为什么难、产生什么互动、如何结束一次循环。

### 5. 原型材料应该支持丢弃

[Recommended Materials](https://www.kathleenmercury.com/recommended-materials.html)强调快速、廉价，列出纸、索引卡、旧游戏零件、硬币、方块、空白骰子和学校用品。

**对本项目的影响**：原型指南按功能推荐替代物，例如“隐藏信息”“可堆叠资源”“位置关系”，并显示最低成本方案。避免用精美组件图让新手误以为早期原型需要像产品。

### 6. 先设计反馈环境

[WINQ 页面](https://www.kathleenmercury.com/providing-feedback-on-prototypes-the-winq.html)把反馈分为 Works、Improvement、New ideas、Questions，要求诚实、建设性、具体，批评游戏而非设计者，并要求设计者预备至少三个问题。

**对本项目的影响**：WINQ 是优秀的课堂脚手架，但我们的项目模式应再分开“观察事实”和“解决建议”，防止 New ideas 淹没设计目标。可以链接原表并注明来源，不直接复制其完整表单。

### 7. 规则写作也是设计媒介

[Writing Rules](https://www.kathleenmercury.com/writing-rules.html)明确认为写规则不仅是捕捉成品，也是在进行游戏设计。她建议先录下自己教学，再转录成初稿，然后用模板和风格指南整理。

**对本项目的影响**：可以设计“口头教法 → 结构化规则初稿”的练习，但必须提醒口语教学顺序未必等于最终参考手册结构，还需盲测验证。

## 不应照搬的部分

- 课程以 13 岁资优学生、学期制和教师主持为背景；自学成人、设计团队和短工作坊需要不同节奏。
- 其定义有时是为课堂清晰度做的简化，例如“所有桌游都模拟冲突”适合作为生成问题，不宜当作排除其他设计观的普遍定律。
- 作者本人说明旧材料曾大量参考 Board Game Designers Forum，措辞归属可能混合；应优先链接原页面并创作自己的框架。
- 部分资源位于 Google Docs，访问权限、版本与许可需逐一核验。
- “出版商寻找新机制”等行业表述会受时间和市场影响，不能作为稳定事实。

## 对首版产品的具体改变

1. 在“开始设计”前加入 3 个微型可玩/可观察练习，不先展示机制大全。
2. 把“题材”输入扩成“主体—任务—阻力—每回合矛盾”。
3. 机制选择采用三格并列草图，并要求写出各自产生的玩家决定。
4. 原型清单按功能提供家用品替代方案，并默认黑白、低成本。
5. 测试表中要求设计者先写 1–3 个问题；反馈者填写事实、体验、疑问、建议。
6. 规则工具支持从口头教学记录开始，但生成后必须进入结构检查与盲测。
