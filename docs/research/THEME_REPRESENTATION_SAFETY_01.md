# 专项研究 09：主题承诺、历史表达、文化协作与情绪安全

状态：review  
研究日期：2026-08-17  
范围：现代桌游为主；情绪安全部分明确标注 TTRPG、自由形式与 LARP 的相邻证据边界。

## 这轮要回答什么

1. “主题先”、“机制先”和“主题融合”是否是同一件事？
2. 历史游戏无法避免抽象时，设计师应记录什么？
3. “历史准确”、“不冒犯”和“双向文化协作”的边界在哪里？
4. 玩家的拒绝、不适与设计者意图不一致时，网站应怎样呈现而不把任何一方写成人群总体？
5. 内容提示、退出、修复与“安全”各自能承担什么，不能承担什么？

## 综合结论

### 1. 主题是一组系统承诺，不是一层包装

“主题先”与“机制先”只记录设计起点。成品是否融合，要看玩家反复执行的动词、系统奖励的结果、因果反馈、可玩角色、语言、组件和插画是否支持同一承诺。这也是 Values at Play 要将价值从抽象概念转译为特征，再经验证的原因。

产品转译：不问“主题感 1–10 分”；要求并排一句承诺、可玩位置、重复行动、奖励/后果和被自动化或省略的部分。

### 2. 抽象不能避免，但抽象不是中性的空白

每款历史游戏都要省略。问题不是“是否省略”，而是：

- 谁获得了可玩动词、信息和否决权；
- 谁被做成无名资源、阻碍或美术背景；
- 哪些暴力、强制、抵抗或关系被自动结算；
- 什么结果被换成分数、增长或声望；
- 设计为什么在这个受众、时长和研究问题下作出这些取舍。

产品转译：工具不要求“加入全部历史”；它要求说明什么是史料、什么是解读、什么是虚构，并将省略记成可讨论的决定。

### 3. 历史准确不等于视角完整，文化协作也不是末期背书

Coyote & Crow 把文化咨询明确写成“不只是准确或盖章”，并建议在项目开始时加入。Jason Perez 的 Taíno 牌组案例则显示，顾问可以与设计者往返，使历史与生产特征真正改变派系机制。MIT 的参与式项目展示了将所表达地区的参与者放入构思、原型和反馈回路的另一种实践。

本项目从这些一手记录中提取了“早、双向、能改系统”三个检查词，但不把它们写成已被实验验证的因果结论。工具还要记录顾问的具体位置、权限、阶段、付费、署名与分歧，不宣称一人代表社群。

### 4. 设计者意图与玩家影响必须分开保存

《Designing the Narrative》的文档分析说明规则、美术与组件可以抵消设计者声称的叙事意图。Beyond Solitaire 的文章则保留了一个具体玩家的拒绝边界：某些玩家不是在询问模拟是否足够“有后果”，而是不愿扮演该位置。

产品转译：

- 设计者意图、文件分析、玩家反应与社群协作记录使用不同字段；
- 不用一位玩家的拒绝推导人群偏好；
- 也不用“我本意是批判”否定已发生的影响。

### 5. 内容提示负责告知，不负责认证安全

Bridgland 等人的元分析报告：内容/触发提示对接触后情绪反应、回避和理解没有有意义的平均效果，但接触前焦虑有可靠上升。本项目因此不会声称内容提示能“降低伤害”或“防止脆弱玩家接触”。

这并不意味着应取消透明告知。一张好的内容提示仍可以让人知道：

- 会遇到什么内容；
- 内容通过文字、图像、组件、选择、扮演还是对他人施加进入；
- 它是否为必玩核心，还是可移除模块；
- 在购买前、组局前和游玩中有哪些选择。

结合角色扮演安全话语，本项目将“安全工具”降格为“待验证的退出与修复程序”，且明确不要求玩家披露创伤史。

## 产品决定

### 新指南

《别问主题够不够浓，追它让玩家做了什么》，五步：

1. 主题承诺与受众/桌面语境；
2. 可玩视角、重复行动、奖励与省略；
3. 史料、解读、虚构与文化协作；
4. 暴露强度、告知、选择、退出与修复；
5. 修第一处不匹配，在相关语境复测。

### 新工具

“主题承诺与伤害复核”：

- 本地保存，导出 JSON；
- `method: theme-commitment-and-harm-review`；
- `no_aggregate_score: true`；
- `no_safety_certification: true`；
- 不收集真实姓名与创伤经历；
- 不输出真实性、伦理、安全或社群认可总分。

## 待验证问题

1. 中文新手能否区分“被资源化”与“资源机制本身有害”？
2. “史料/解读/虚构”三分法是否对非历史题材仍有用，还是需要更广义的“来源/设计判断/创作”？
3. 18 个字段是否对新手过重？是否应在第一屏只展示承诺、行动、奖励、暴露与下一步，其余为深度模式？
4. 内容提示的写作范例是否能让测试者区分“主题名称”与“参与强度”？
5. 退出/修复程序如何适配不同桌游媒介，且不把 TTRPG 方法直接复制成封闭系统桌游处方？

## 结论边界

这轮研究支持一套更好的记录问题，不支持一个“好主题”或“无害游戏”的判定器。项目不做以下声称：

- 文化顾问可以为社群认可背书；
- 史实准确就意味着伦理或叙事完整；
- 内容提示可以防止痛苦、回避或伤害；
- 任何一项程序可以认证一张桌面“安全”；
- 一位玩家的拒绝或接受可以代表一个人群。
