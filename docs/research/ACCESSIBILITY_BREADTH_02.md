# 专项研究 04：跨维度桌游无障碍与适配代价

最后更新：2026-08-14  
状态：review  
前置：[专项研究 03：规则书与任务无障碍](RULEBOOK_ACCESSIBILITY_01.md)

## 研究问题

上一轮已经建立视觉、规则格式和任务自主性的基线。本轮补查五组问题：

1. 身体操作是否应覆盖开盒、设置、够取、精细动作、重复动作与收纳；
2. 听觉和沟通障碍是否只靠音量或文字替代就能解释；
3. 认知与神经多样性相关适配怎样避免由设计者代替玩家推测；
4. 情绪安全、退出和社交权力怎样进入具体任务观察；
5. 专版、配件、打印和适配劳动是否属于可访问性的组成部分。

检索采用英文关键词组合：`tabletop accessibility physical motor dexterity`、`board game deaf hard of hearing communication`、`neurodivergent adults accessible board games co-design`、`emotional accessibility tabletop games`、`socioeconomic accessibility board games cost`。优先顺序为可阅读全文的研究、明确方法与局限的论文、残障顾问的一手实践，再到只能核验目录的专著。没有把商业宣传、医学诊断清单或单个社区意见写成研究结论。

## 综合发现

### 1. 无障碍维度是检索入口，不是玩家分类

同一任务往往跨越多个维度：玩家要先看见信息、理解后果、够到组件、在有限时间内移动，再向其他人表达决定。把“视觉”“操作”“认知”拆开有助于发现问题，但不能据此假设每类玩家内部相同。MCD 还明确提醒交叉障碍：例如用更多口头说明替代图形，可能为沟通相关玩家制造新的门槛。

本站因此保留维度标签用于筛选，却不显示按维度汇总的通过率，也不把诊断名称作为需求代理。

### 2. 身体操作从包装开始，到收纳结束

需要记录的不是“棋子够不够大”，而是动作链：打开包装、取出组件、设置、够取、抓握、翻转、堆叠、保持位置、重复动作、在时间压力下操作以及收纳。动作的次数、范围和精度都可能改变负担。

他人代为移动并不自动解决问题。若代理者看见私人信息、替玩家选择合法位置、赶不上实时节奏或持续承担劳动，系统功能已经改变。反过来，玩家主动选择团队分工时，代理操作也可能正是想要的社交方式。因此要记录玩家选择与代价，不先判定帮助好坏。

### 3. 沟通障碍存在于节奏、位置和权力中

听障玩家研究显示，音量只是其中一项。多人同时发言、看不见说话者、座位无法支持读唇或手语、游戏不指示当前说话者、解释需要等待口译、讨论被强势玩家控制，都会影响参与。部分玩家报告“没有问题”也不能证明桌上其他人没有被排除。

对设计的转译不是“一律轮流说话”，而是把当前沟通机制写清：谁在什么时候必须表达什么、允许哪些媒介、错过信息会怎样、谁控制节奏、改变节奏会牺牲什么体验。

### 4. 认知适配需要玩家原话，也需要任务观察

Games Inclusion Lab 的一个关键反例是：部分参与者口头上把活动描述为简单或有趣，但观察记录显示他们仍无法独立完成任务。结论不是否定玩家原话，而是把两类证据分开：原话描述感受和偏好，任务观察描述系统怎样被使用。

参与式变体也必须保留语境。某组玩家更喜欢合作、减少复杂图像或拒绝蒙眼/捂耳规则，不等于所有神经多样性玩家都需要相同变化。下一轮应邀请玩家共同选择候选变化，再用同一任务复测。

### 5. 情绪安全是机制和现场共同产生的

本轮没有找到足以建立普遍效果量的桌游情绪安全研究。现有启发式与从业文章提示的候选问题包括：公开巨大分差、淘汰、羞辱性表演、欺骗压力、感觉剥夺、不可预期内容和无法无代价退出。这些问题必须写成具体机制与现场行为，不能把“焦虑”“自闭”等诊断名称变成预设结论。

因此本站把情绪/安全保留为观察维度，要求记录玩家原话、退出与暂停条件；暂不提供“情绪安全通过”标签。

### 6. 价格、可获得性与适配劳动属于同一记录

如果标准版无法使用，而参与需要更贵专版、额外配件、3D 打印、手工贴标、寻找代读者或持续设置劳动，那么“能不能玩”与“以什么代价玩”不能分开。免费可编辑文件通常值得提供，但不会自动消除打印设备、材料、技能、运输和时间差异。

本站不对某个价格给出普遍阈值，而是在观察中记录：额外花费、获取渠道、制作时间、由谁承担、是否每局重复。

## 对产品的直接决定

1. 任务无障碍观察新增“暂定的障碍描述”字段，强制把实际动作与设计判断分开。
2. 观察维度继续用于检索，不计算总分、通过率或玩家类别画像。
3. 工具提示加入跨维度复测：一个适配可能制造另一项操作、沟通、认知、隐私、时间或成本障碍。
4. “协助代价”示例扩展到适配劳动、额外费用和可获得性。
5. 资源库区分全文研究、从业经验和仅核验元数据的书籍；网站上的最后核验日期解释为人工内容审阅，而不是实时链接健康证明。

## 仍未解决的证据缺口

- 中文残障桌游玩家的一手研究和长期社群资料仍不足；
- 肢体相关来源中，从业经验多于跨玩家实证研究；
- 情绪安全缺少桌游专门的比较研究和共同设计方法报告；
- 经济可访问性的成本、地区差异与出版生产数据仍非常薄弱；
- 研究常把残障类别分开招募，交叉需求、疲劳和长期使用经验较少；
- 现有样本多来自欧美机构，不能代表中国家庭、学校、桌游店和社区空间。

这些缺口不是以后补一张清单就能解决。下一步应建立中文玩家访谈与共同设计招募方案，同时继续寻找有方法说明、样本和失败记录的生产案例。
