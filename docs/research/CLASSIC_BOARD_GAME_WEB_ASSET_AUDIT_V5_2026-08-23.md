# 经典桌游网络视觉素材审计 V5

*生成日期：2026-08-23｜范围：现代经典桌游与传统桌游的网页视觉素材｜候选：12 组｜置信度：高（文件授权）/ 中（被摄游戏美术的二层权利）*

## 结论先行

这次不应继续只做“受桌游启发的抽象几何”。网站可以直接使用一组可追溯的桌游照片与图形，让六角地形、路线网络、拼板、彩色方块、棋盘轨迹和实体组件真正进入页面。

最合适的首发组合是：

1. **CATAN**：六角地形与道路网络，作为首页主视觉里的现代桌游识别点。
2. **Azul**：彩色花砖与方格计分面板，承担高饱和色彩和触感。
3. **Ticket to Ride**：路线、节点和有色列车，承担“资源路径”视觉语法。
4. **Carcassonne**：方形地块拼接，承担资源单元和章节拼接语法。
5. **Pandemic**：地图网络和彩色方块，承担问题—系统—反馈的可视化语法。
6. **麻将 / 七巧板**：低权利风险的实体块面与可重组几何，承担全站背景纹样和图形标记。

其中前五组的照片虽然在 Wikimedia Commons 上有 CC 或公有领域标记，但照片里仍出现商业桌游的棋盘、卡牌或商标。**开放许可明确覆盖摄影作品，并不当然解决画面内产品美术、商标等所有二层权利。** Commons 自己也提醒复用者逐文件核验，且商标、人格权等非版权限制可能另外适用。因而本项目当前可在“不公开、内部学习”的前提下本地化使用；一旦准备公开，应重新做发布审计或向出版方取得许可。[Wikimedia Commons 复用指南](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/en)

“非公开、非营利”是当前产品范围，不是自动取得第三方美术授权的法律依据；本审计仍以文件许可、被摄作品和商标三个层次分别判断。

## 风险等级与使用边界

| 等级 | 含义 | 当前内部站 | 未来公开站 |
| --- | --- | --- | --- |
| 低 | 公有领域 / CC0，且主体主要是传统棋盘、简单几何或普通实体组件 | 可直接本地化、裁切、调色 | 保留来源记录即可；署名仍建议保留 |
| 中 | 摄影作品许可清楚，但画面包含商业桌游的棋盘、卡牌、商标或产品美术 | 可小面积、编辑性使用；不要伪装官方联名 | 发布前重新核验或请求许可 |
| 高 | 第三方表达性插画是画面主体，摄影许可不能充分解释插画权利 | 仅内部参考页；不作为装饰资产 | 未经许可不发布 |

执行红线：

- 不从 Pinterest、Google 图片搜索结果或 BoardGameGeek 缩略图直接取图；必须回到权利人或 Commons 文件页。
- 不复制任何单款桌游的完整 trade dress，不把 logo、盒面或角色插画变成本站品牌标识。
- 商业桌游照片只做“视觉标本”：局部、有限、带来源，文字永远放在独立纯色底板上。
- CC BY / CC BY-SA 素材必须在站内“视觉素材来源”页给作者、文件名、文件页、许可链接和改动说明。
- CC BY-SA 素材保持为独立文件；若裁切、改色或重绘，给该衍生资产同样或兼容许可，不把它混进无法拆分的品牌总图。
- Commons 不建议热链；正式实现应下载到本地并保存来源元数据。[Commons 对下载、热链与署名的说明](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/en)

## 下载与登记规范

每个实际使用的资产都应同时保存一个同名 `.license.json`，至少包含：

```json
{
  "title": "原文件名",
  "localFile": "/assets/classic/本地文件名",
  "sourcePage": "Commons 文件页或官方页面",
  "downloadUrl": "原文件下载入口",
  "creator": "作者 / 机构",
  "license": "CC0 / CC BY 2.0 / CC BY-SA 4.0 / Public Domain",
  "licenseUrl": "许可全文或 deed",
  "changes": "裁切、调色、压缩、改色等",
  "useScope": "internal-only / publication-ready / reference-only",
  "reviewedAt": "2026-08-23"
}
```

站内来源页的署名格式统一为：

> 《文件名》— 作者 / 机构；许可；原文件页；本站所做改动。

CC BY 的基本要求包括适当署名、许可链接和改动说明；CC BY-SA 还要求衍生内容以相同或兼容许可发布。[Creative Commons BY 4.0 legal code](https://creativecommons.org/licenses/by/4.0/legalcode.en)；[Commons 常见许可复用说明](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/licenses)

## 方法与来源覆盖

本轮以 4 类问题进行检索：

1. 现代经典桌游在 Commons 是否有经过许可标记的摄影或简化图。
2. 官方出版方是否提供 press / media kit，以及条款是否明确允许本站复用。
3. 哪些传统桌游和拼图有 CC0 / public domain 矢量素材，可成为长期设计系统。
4. Commons 与 Creative Commons 对署名、改动、ShareAlike、热链和其他权利的要求。
