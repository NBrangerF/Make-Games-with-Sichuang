# 新手跨轮证据综合交接审计 01

日期：2026-08-21

| 新手断点 | 误用风险 | 交互护栏 | 验收信号 |
| --- | --- | --- | --- |
| 直接把两场笔记堆在一起 | 不同问题被当成同一发现 | 只承接已完成复盘；至少选择两份 | 未选两份不能冻结来源 |
| 同样一句发现就认定可比 | 版本、玩家和任务差异被隐藏 | 第二步必填共同问题、可比较条件与关键差异 | 缺任一必填字段不能进入矩阵 |
| 把更多支持当作正确 | 少数反例被吞掉 | 逐份人工关系；界面不显示支持率 | 页面无分数、置信或自动优先级 |
| 把新版本当复现 | 改动轴与语境变化丢失 | 每行显示来源/目标版本、语境和改动轴 | 用户能指出哪一项改变了 |
| 把熟练玩家当新手 | 教学、首次理解与时长问题被掩盖 | 玩家语境与版本并列展示；可标不可比 | 测试者能把首次局与重复局拆开 |
| 看到反例却不知道怎么办 | 只剩“支持/不支持”二元结论 | 生命周期含收窄、拆分、被反驳、退役 | 用户能解释反例怎样改变表述 |
| 拆分后丢失边界 | 两个分支只是换名字 | 拆分必须填写两个表述与适用边界 | 缺任一分支字段不能保存 |
| 综合直接变成待办 | 推断被误当事实和承诺 | 独立保存；项目下一步另行显式复制 | 保存综合不会改变项目 |
| 来源撤回后综合仍存在 | 参与者资料继续传播 | 会话撤回级联清除关联复盘与综合 | 本地 records 与 draft 均不再引用会话 |
| 导出被当作证明 | 外部副本失去边界 | 导出内写禁止自动化与证据边界 | JSON 包含来源、限制与导出时间 |

## 结论

跨轮工具不是统计仪表盘，也不是自动洞察仓库。它应让新手多做一次“这两份材料真的能一起读吗”的判断，并留下为什么收窄、拆分或退役的沿革。
