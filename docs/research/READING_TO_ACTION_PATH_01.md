# 从设计资源到上桌行动：新手阅读路径研究 01

日期：2026-08-21  
状态：review  
产品输出：`special-reading-to-action`

## 研究问题

网站已有大量书籍、课程、博客、设计日志、玩家长评和学术材料。新的问题不是继续增加一份“必读书单”，而是：

> 新手怎样把一本书或一篇文章，转成当前项目中一次小而可反驳的设计行动？

这条路径必须同时避免四个错误：把知名度当质量，把商品简介当全文审阅，把一位设计师的流程当通用线性成熟度，以及把免费访问当成可再出版授权。

## 一手入口复核

### Kathleen Mercury

[Resources to Teach Strategy Game Design](https://www.kathleenmercury.com/) 当前仍将入门游玩、快速工作坊、机制、目标、主题、原型、测试、WINQ 反馈和规则写作组织为课堂路径。首页的权利语言同时说明：

- 资源免费，期待使用者署名并分享如何使用或修改；
- 作者明确不允许他人将这些材料自行出版；
- 站内存在多种来源和长期改编，不应假定所有单项素材都有相同许可。

产品含义：本站可以链接、原创概括课程结构并学习其任务编排，不复制工作纸、不默认翻译权，也不把青少年教师主持课程当所有成人自学者的唯一顺序。

### Kobold Guide to Board Game Design

[Kobold Press 官方商品页](https://koboldpress.com/kpstore/product/kobold-guide-to-board-game-design/) 在本轮复核时仍把完整英文版列为 144 页、15 位贡献者，范围为 conception、design、development 和 presentation，并将原型、平衡、测试和呈现放在同一本书的开发路径中。官方页同时是商业销售语境；它可以核验书目和当前入口，不能代替正文审阅或购买建议。

用户提供的中文 PDF 本轮重新校验：

- SHA-256：`59a7d1a9439968ccc96ff0249015f2c3c2849b6cfbf6fc7dcdb4a24a1a5f4ebf`；
- 55 页，未加密，带结构标签，文件自标“预读版”；
- 目录出现后续章节，实际正文只含第一章五篇文章和第二章第一篇；
- PDF 第 50 页视觉复核确认“撰写规则”被描述为迫使系统可执行、暴露设计漏洞的方法。

产品含义：站点可以使用 K01–K11 的页码化原创概括作为内部设计证据，不发布 PDF、不发布长段提取文本、不从目录标题臆测未收录章节的观点。

## 综合路径

新专题使用五步：

1. 冻结一个会改版本的设计问题；
2. 只选一条学习主线，并如实标明审阅深度；
3. 补一个玩家语境、反例或反对解释；
4. 把阅读压缩为只改一个条件的上桌行动，事先写行为预测和反驳信号；
5. 测试后回写当时判断、观察、其他解释、决定与下一次迁移语境。

这不是一个学习成效模型。阅读时长、章节数、笔记数、书单完成度和来源知名度都不生成评分。路径只帮助使用者留下一条可反驳的设计—证据链。

## 产品映射

- 专题指南：`special-reading-to-action`；
- 资源入口：`choose-learning-spine`，标题改为“选一条能产出行动的学习主线”；
- 复用工具：体验意图、改造熟悉游戏、决定轨迹、原型范围、测试计划、证据复盘和测试方式选择；
- 未新增阅读评分器、书单排名、自动摘要器或正文复制功能。

## 未验证问题

1. 中文新手能否在 12 分钟内把“我想学平衡”改写成一个会改版本的问题？
2. “一条主线 + 一个异议语境”能否减少无限收藏，还是只增加填表负担？
3. 用户能否正确区分 metadata_only、article_level 和 full_text？
4. 权利提示能否阻止“免费 = 可再发布”的误读？
5. 阅读后是否真的只改一个条件，并会在反驳时放弃或修订候选？

完成真实任务测试前，不声明这条路径会提高阅读效率、学习迁移或游戏设计质量。
