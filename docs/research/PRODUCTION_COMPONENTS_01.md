# 专项研究 10：生产可行性、组件规格与真实成本边界

状态：review  
研究日期：2026-08-17  
问题类型：多来源实践综合；不是报价、商业计划、合同审阅或合规意见

## 研究问题

1. 什么时候应把制造与物流约束带回游戏设计，而不让它过早压扁原型？
2. 一份能被生产方理解的组件规格至少要说明什么？
3. 工厂单价、落地成本和完整项目成本为什么不能混成一个数字？
4. 数字校样、组件样、产前样和量产样分别能回答什么问题？
5. 盒子、内衬与组件怎样同时影响游玩、装配、仓储、运输、可访问性和环境影响？
6. 网站怎样帮助新手取得下一条可验证证据，而不是生成看似精确的报价？

## 执行摘要

- **来源事实**：生产方需要可枚举的组件清单与规格才能报价。Panda 当前流程要求按规格提交组件列表，并把报价、文件核验、产前样（PPC）、量产样（MPC）、装配和运输列成不同关卡。[Panda 流程](https://pandagm.com/our-process/)、[工具与规格模板](https://pandagm.com/tools/)
- **来源事实**：同一游戏的单价会随组件、数量、材料、加工、装配方式与供应模式变化。The Game Crafter 明确要求先在编辑器中建立实际组件，才能看到对应批量价格；其 2026-06-01 页面也说明部分产品不适用批量流程。[Bulk Pricing](https://help.thegamecrafter.com/article/84-bulk-pricing)
- **来源事实**：制造完成仍不等于交付。Kickstarter 2026 年履约指南把生产、货运、报关、仓库入库与末端履约列为不同时间和费用节点。[From Funded to Delivered](https://updates.kickstarter.com/from-funded-to-delivered-a-creators-guide-to-fulfillment/)
- **实践共识**：组件不是单纯成本项。材质、形状、尺寸、包装和内衬会改变识别、抓取、设置、收纳、桌面占用与作品气质；因此“便宜替代”仍要回到同一玩家任务复测。[Entro Games](https://entrogames.substack.com/p/how-to-make-a-game-manufacturing)、[Store All the Bits](https://www.storeallthebits.com/site/2021/10/22/board-game-insert-designer-diary-assess-space-and-components/)
- **项目推断**：本站不应输出“这盒会花多少钱”。最小有用产出是一份带证据状态的生产假设账本：每个组件与成本范围标明来源、日期、包含/不包含项、版本和仍未知的条件。
- **项目推断**：生产验证不能只做文件检查。最终图形、材料、尺寸、包装与桌面任务需要在接近成品的实物上重测；早期纸片原型通过不能证明最终印刷可读、可拿、好设置或装得下。

## 1. 生产约束应进入设计，但不能取代早期探索

Oakleaf 的核心观点不是“第一张草图就联系工厂”，而是把组件视为有机会成本的设计变量：额外物件可能增加规则表达、触感或主题，也可能增加工装、装配、盒型与物流负担。Entro 将供应方常见的成本驱动概括为材料、工装和装配时间，同时强调玩家感受到的是触感、辨识与主题。

这两种视角不能合成单一“越少越好”。例如把四种异形木件换成同色小方块可能减少制作复杂度，却也可能破坏角色辨识、抓取和不用颜色识别的路径。合理顺序是：

1. 早期原型先证明该物件承担的玩家任务与系统功能；
2. 当核心循环稳定，建立组件规格与替代方案；
3. 每次为了成本、尺寸或供应而替换后，用相同任务复测；
4. 只有实际规格足够明确时，才把估算升级为正式报价。

**产品决定**：工具中的每个组件必须先写“玩家/系统功能”，再写材料和规格。替代方案不能只有“更便宜”，还要说明保持了什么功能、需要复测什么。

## 2. 报价需要的是规格，而不是机制名称

Panda 的当前报价流程要求组件列表遵守规格指引；其工具页把印刷模板与非纸组件规格表分开。The Game Crafter 也要求把实际组件加入游戏后才显示对应的批量价格。这些来源共同支持：

- “120 张牌”仍不完整：尺寸、纸材/芯层、表面处理、是否随机装包都会改变流程；
- “一个版图”仍不完整：展开/折叠尺寸、板厚、折法和盒内尺寸要匹配；
- “木制资源”仍不完整：形状、尺寸、厚度、颜色、印刷/雕刻与每盒数量都需说明；
- “一个盒子”不能只写外观尺寸，还要记录盒型、内部可用空间、堆叠高度、内衬和装箱后的实测重量。

**项目推断**：这里适合使用 `BOM/组件规格表` 概念，但不要求新手一次写成工业文件。网站先要求：类型、数量、尺寸/材料/加工、玩家功能、替代方案、证据状态。

## 3. 工厂单价、落地成本和项目全成本是三个问题

Kickstarter 的 2026 指南把制造、国际货运、海关资料、仓储收货和末端履约拆开。小批设计日志则显示包装方案会同时改变单件包装费、运费与货架呈现。即使不做众筹，这个结构仍提醒我们：一个报价数字必须带范围。

本站采用三层而不计算利润：

| 范围 | 至少记录 | 常见漏项 |
|---|---|---|
| 工厂/生产范围 | 组件、工装、印刷、表面处理、装配、包装、数量 | 样品、改模、备件、外箱 |
| 落地范围 | 上述内容，加货运、保险、税费/关务、入仓 | 偏远附加、查验、仓储等待 |
| 项目全成本范围 | 上述内容，加原型、美术、编辑、测试、平台、履约、替换与售后 | 人工时间、损耗、汇率与第二次运输 |

工具不把这些数字相加，因为币种、含税状态、数量和日期不同会制造假精度。用户只需选择当前数字属于哪一层，列出明确包含/排除项，并标记它是粗估、目录/计算器、书面报价还是实际发票/实测。

## 4. 校样链条不是重复检查

Panda 把文件核验、数字校样/组件样、PPC、MPC 与装配检查拆开。它们解决的不是同一问题：

| 检查点 | 主要能发现 | 仍不能证明 |
|---|---|---|
| 文件/印前核验 | 尺寸、出血、刀线、色彩模式、字体/图像与模板问题 | 实际颜色、手感、装配、桌面使用 |
| 组件样/材料样 | 材质、工艺、颜色或自定义部件是否接近规格 | 全盒装配与完整游戏体验 |
| 产前样 PPC | 接近成品的印刷件、组件配合、盒内 fit、规则与视觉 | 整批生产一致性 |
| 量产样 MPC | 实际量产线首批结果、完整包装和最终装配 | 所有单位零缺陷、所有运输路径无损 |
| 入库/抽检 | 数量、装箱、损坏、批次与仓储接收问题 | 每一盒与每位玩家的体验 |

中文设计师新茂特别提醒：工厂按文件生产，不承担作品校对责任；实体勘误会重新触发生产与物流。TTGDA 的教育资料进一步说明，最终印刷文件的复核时间与最终图形版本的陌生玩家实测，应在责任和日程里预先约定。

**产品决定**：工具要求用户选择当前验证门，并写“这次样品要验证的任务、预期、实际结果和谁可批准下一步”。“看起来不错”不是批准依据。

## 5. 包装同时是容器、桌面接口与物流单位

Store All the Bits 的内衬日志先测盒底内部空间，再测组件整组与单件尺寸，并检查托盘能否直接在桌上使用。Jack Neal 的小批日志则展示另一组真实取舍：更便宜、更轻、更好开的小型透明盒，与零售货架表达和传统“高级感”并不一致。

因此盒子/内衬至少要完成五类任务：

1. 运输中保护组件；
2. 玩家能够打开、取出、识别并复原；
3. 支持设置、分发和桌面取用，而非增加额外分类劳动；
4. 适配仓储、外箱、重量与运输计费；
5. 与目标渠道和作品表达相容。

这也说明为什么不能只测“所有东西是否能塞进去”。若组件只能紧压、玩家戴牌套后装不回去，或内衬要求精细抓取，尺寸虽然成立，玩家任务仍失败。

## 6. 轻量化是可测试方向，不是道德标签

GameLab Lausanne 的说明基于三个假设盒型的 LCA，报告重量更高的场景整体影响更高，并在其模型中发现纸与纸板因为占主要重量而贡献最大。这个结果支持“减少不必要材料与重量值得测”，却不支持简单的材料善恶排行：

- 研究只覆盖指定小/中/大盒内容与特定数据库假设；
- 材料变化还会影响耐用度、替换频率、可回收性与供应链；
- 更小、更少可能损害可读性、可抓取性或信息冗余；
- 运输距离不是唯一环境变量，纸板也不能自动等于低影响。

**产品决定**：工具只记录“材料/重量/包装假设与验证来源”，不生成环保分、绿色认证或材料禁用清单。减少物料后仍要复测同一可访问性与玩法任务。

## 7. 新手生产假设账本

本站把本轮综合转译为一条最小流程：

1. **选交付路线与受众地区**：投出版社、PnP、小批/POD、自出版大货或众筹不是同一规格问题。
2. **建立带功能的组件表**：类型、数量、规格、玩家功能、替代方案和证据状态。
3. **冻结报价场景**：数量、币种、日期、报价范围、包含项与排除项必须成组保存。
4. **测包装与桌面动作**：内部尺寸、整盒重量、设置、取用、收纳、牌套与辅助需求。
5. **定义当前验证门**：文件、组件样、PPC、MPC 或入库抽检；写批准责任。
6. **只升级一个未知项**：例如把“盒内尺寸粗估”升级为工厂模板，或把“运费猜测”升级为写明目的地和重量的书面报价。

导出必须声明：

```json
{
  "schema_version": 1,
  "method": "production-assumption-ledger",
  "no_price_prediction": true,
  "not_a_manufacturing_quote": true,
  "not_compliance_advice": true
}
```

## 证据缺口

- 缺少可公开复核、来自中国大陆独立桌游项目的完整 BOM—报价—实付—履约差异记录；现有中文文章多为流程说明或旧经验。
- 缺少把组件替代同时放入成本、玩家任务、残障玩家使用和环境生命周期中比较的桌游案例。
- 供应商页面能说明自身流程，不能比较供应商质量；本轮没有把任何厂商列为推荐排名。
- 2026 年关税、海运、地区税务与合规快速变化；本报告有意不保存具体费率或给法律结论。
- 真实新手能否理解“报价范围”“证据状态”和四级样品门，仍需可用性测试。

## 方法

围绕组件规格、报价、POD/大货、盒型、内衬、校样、量产、物流、履约、环境影响和中文生产经验进行多轮中英文检索。查看 16 个来源：生产商/平台官方材料 5 个、行业协会 2 个、众筹平台 1 个、设计师与专业实践 6 个、中文设计师文章 1 个、研究传播 1 个。深读 10 个页面或文档的相关段落；Daniel Solis 页面本轮持续返回 429，因此只保留元数据级入口，不用它支撑精确尺寸。当前页面和时效信息核验日期为 2026-08-17。
