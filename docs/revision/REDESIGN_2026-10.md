# 前端重新设计（2026 年 10 月）

这一轮把一桌点子的界面整体搬进 sichuangfan.com 的实验室设计语言，并在课程里加入可以直接上手的互动。名字、字标、网址和内容都不变。

## 设计系统：`src/lab/`

| 文件 | 内容 |
| --- | --- |
| `fonts.ts` | 自托管字体（CSP 只允许 `font-src 'self' data:`）：Anybody（英文标题与数字）、Newsreader（英文正文）、Noto Serif SC（中文）、IBM Plex Mono（标签） |
| `tokens.css` | 纸、墨、规线；桌面（绿色毡垫、粉笔、印刷格）；物件色（番茄、蛋黄、粉、薄荷、牛皮纸、钴蓝）；五条主题线；字号、间距、圆角、阴影；全局链接与焦点样式 |
| `legacy-bridge.css` | 旧样式层（`--ot-*`、`--v51-*`、`--learning-*`、`--course-*`）的变量全部指向实验室变量，让课程单元、学习地图、资料页、工具、方法与隐私页一并换装 |
| `shell.css` | 顶栏、主导航、语言切换、页脚；≤1040px 导航换到第二行，≤520px 变成五格图标标签栏 |
| `interactives.css` | 按钮、骰子、分段选择、棋盘、三个互动组件的外框 |
| `surfaces.css` | 原型卡、玩着学、案例（列表、详情、两个小实验）、机制与主题库 |
| `workbench.css` | 设计工作台：毡垫上的主入口、纸面表单、六格进度、六步迭代轨道 |

规则：浅色单主题；深色表面一律用毡垫（`--mat`），不用纯黑；按钮是墨色胶囊；可点的格子用真正的 `<button>`。

## 可以上手的部分

| 组件 | 位置 | 做什么 |
| --- | --- | --- |
| 规则试验台 `RuleBench` | 课程首页；第 5 章（精简版） | 两人轮流掷骰，比较 B、C、R、E 四份草稿；记录用课程记法，统计回合与等待 |
| 一回合检查 `TurnCheck` | 第 1 章（基础）、第 9 章（边界） | 给出位置和点数，在棋盘上点出这一回合停在哪里；逐题反馈，回合计分 |
| 终点概率 `EndingOdds` | 第 16 章、第 25 章 | 从 18–23 格出发，三种终点规则下几回合能走完；精确的马尔可夫链计算，不是模拟 |

三个组件都只用 `race-model.ts` 的规则（`resolveRaceMove` 未改动）。插入位置按章节小标题定位，见 `src/lab/chapter-interactives.tsx`；改小标题时要一起改这里。

## 顺带修好的问题

- 旧皮肤删除后，工作台、相关阅读链接、文章表格、两个案例小实验失去样式，已在新文件里重写。
- `App.tsx` 引入的 `original-reading.css` 原先排在旧样式层之前，同权重规则会输给旧层；现在 `main.tsx` 先载旧层，再载应用与实验室样式。
- 英文顶栏在 1041–1320px 之间超出页面宽度，语言按钮被挤成两行；已收紧并验证 375–1440px 各档宽度。
- 英文的“本章要做”卡片，标签列宽不够，文字重叠；标签列改为按最长标签自适应。
- 6 nimmt 小实验的牌行原来是两列网格，五张牌会错行；改为一行牌面。
- 工作台第一步的输入框没有可读名称，已补 `aria-label`。
- 旧样式中 187 处写死的宋体、楷体、Georgia 字体栈，改为实验室字体变量；4 个蓝灰色值改为实验室变量。
