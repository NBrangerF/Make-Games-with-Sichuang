# 节点化学习系统修订章程

## 目标

把当前以课程、阶段和资料入口为主的站点，改造成一条任何新手都能逐步走完的学习主线。用户在任一时刻只需要面对一种思维、一个工具、一次动作和一个完成结果。

## 权威来源

- `content/learning-nodes.json`：主线节点、呈现模式、支线和来源映射的唯一权威数据。
- `content/learning-units/`：原始完整课程正文，保留为深入阅读和来源，不由节点正文覆盖。
- `content/guides.json` 与 `content/special-guides.json`：基础方法和专题支线。
- `content/resources.json` 与 `content/resource-assessments.json`：资料事实、导读和限制。
- `content/glossary.json`：概念定义；节点只按需引用。

当节点与长文摘要发生冲突时，节点决定主线中的当前动作，长文保留完整论述和方法边界。

## 纳入范围

- 首页、主导航、学习主线和节点详情
- 学习正文、案例、专题、概念与资源的入口关系
- 节点进度、呈现模式、轻量工作区和完整工具交接
- 路由、内容校验、浏览器回归与无障碍检查

## 明确不做

- 不删除或改写开放许可译文
- 不把学习者包装成能力等级、分数、经验值或雷达图
- 不改变现有工具 ID 和本地记录格式
- 不把 574 条资源导入首屏主包
- 不用年龄决定课程顺序；年龄只影响语言、时间和带领方式

## 内容结构

1. 十二个主线节点
2. 与节点相连的问题支线
3. 案例、完整长文、资源、概念和框架组成的资料库

## 发布闸门

- 十二节点通过结构校验
- 每节点恰好一个主工具、最多三个概念和三个资料入口
- 桌面与移动端可以在首屏看见当前思维、动作和开始入口
- 旧学习正文、旧问题入口和工具深链继续可访问
- 自动化 QA、键盘路径、控制台和响应式检查通过
- 真实参与者验证保留为独立后续证据；自动检查不得冒充真人测试
