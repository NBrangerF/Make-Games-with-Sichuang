# 节点任务测试协议

## 目标流程

进入学习首页 → 找到当前节点 → 说出现在要做什么 → 使用轻量工具留下结果 → 判断已经完成 → 进入下一节点。

## 观察任务

1. 十秒内指出当前动作。
2. 用自己的话解释本节点的一句话思维。
3. 不展开全部参考内容，开始填写轻量工具。
4. 产出符合完成信号的结果。
5. 找到下一节点或相关问题支线。

## 记录

- 第一次停顿的位置
- 请求解释的词
- 主持人介入次数和内容
- 是否误把参考资料当成必读前置
- 是否误把完整工作台当成第二个任务
- 是否知道何时完成
- 是否知道下一步去哪

## 样本闸门

- 每种呈现模式至少五次独立任务。
- 每种模式至少四次能找到动作、完成产出并找到下一步。
- 没有一个节点需要解释两个以上新术语才能开始。
- 自动化检查只能证明结构与交互可运行，不能计入真人参与证据。
- 涉及未成年人时由合适的带领者组织，并遵守项目既有的隐私与同意边界。
