# 新手路线修订（2026 年 10 月）

这一轮修订针对一个反馈：课程的组织和内容，对第一次做游戏的人不够友好。

## 看到的问题

1. **试玩来得太晚。** 原来的顺序里，第一次请人试玩在第 22–23 章。新手要先读 21 章才第一次把草稿交给别人，而新手最需要的，正是尽早发现“别人并不像我想的那样玩”。
2. **目录不说你会做什么。** 部分介绍和章节标题多是问句，读者看不出读完这一段手里会多出什么。
3. **第一章先讲版本差异。** 开头就是产品编号和终点规则差异，信息准确，但新手还没摆出棋盘。
4. **动手的部分默认收起。** 练习全部折叠，第一次来的人容易一路只读不做。

## 这次的改动

**顺序：第一次试玩从第 22–23 章提前到第 7–8 章。**两条路线（蛇梯棋主线与过河替代路线）同步调整，章节 ID 和网址不变，保存过的链接继续有效。

| 部分 | 章 | 内容 |
| --- | --- | --- |
| 从熟悉的一局开始 | 1–4 | 玩一局、观察桌边、想清楚请谁来、写一句方向 |
| 改一条规则，请人试一次 | 5–8 | 小点子、写成动作、只回答一个问题的小草稿、第一次试玩 |
| 让每一次选择都值得想 | 9–14 | 结算、选择、信息、资源与终点、位置、等待 |
| 看看规则怎样互相影响 | 15–19 | 经济、节奏、组合、合作、人数 |
| 让人看懂，也愿意玩 | 20–23 | 主题、故事、说明与组件、参与 |
| 再请人试，读懂记录 | 24–25 | 读记录、从反馈找到要改的规则 |
| 定稿，再交出去 | 26–28 | 取舍、独立规则测试、交付 |

约束保持不变：两条路线逐章对应；过河路线里 12 个原有主线章节的相对顺序不变；每个前置章节都排在后面章节之前（`pnpm content:check` 全部通过）。

**为提前而改的文字（中英文同步）：**

- 两条路线的原型一章：去掉对尚未出现的变体（E、S、天气）的依赖。
- 过河路线“结算”一章：“上一章的草稿”改为“第 6 章的草稿”。
- 过河路线“读记录”一章：“上一章安排的问题”改为“第 8 章安排的问题”。
- 比较条目里的章节号随新顺序更新。

**新手入口：**

- 课程首页加“第一次来？先走第一轮”：要准备的东西，以及第 1–3、4–6、7–8 章各做什么。
- 每个部分的介绍改成“这一部分你会做什么、做完手里有什么”。
- 第一章开头说明第 8 章会请朋友试玩，并列出需要的材料；版本差异改成先说结论、再举两个产品例子。
- 第 1–8 章的小练习默认展开，第 9 章以后保持默认收起。

## 还没有做、值得接着做的

- 第 2–8 章正文的逐段精简：按 `COPY_RULES.md` 的“先例子再术语、一段只做一件事”，把每章压到新手一次能读完的长度。
- 每个部分结尾加一个“你现在手里应该有”的检查清单，与练习结果对应。
- 用真实的新手试读验证这次改动：本次只调整了结构和入口，没有学习效果的证据。
