## UI 减法与读者脚手架

内容增加，入口数量保持不变：

1. 首页仍只有学习、分析、按问题找资料三个主入口，以及一个次级“搜索全部资料”。
2. 学习方式页仍只有系统学习、设计师思考、边玩边学、小练习四个入口。
3. 系统学习页沿用一列短目录；可完整阅读的单元从 5 个增加为 7 个，完整九单元路线仍折叠。
4. “边玩边学”入口只有一个主要按钮“开始第一份完整记录”，没有叠加筛选、等级、进度或卡片墙。
5. 同一正文通过短路径、示范、表格、边界提示和进阶任务照顾不同背景，而不按年龄给读者分组。
6. 外部来源以站内来源记录呈现；三份新正文各有 0 个可点击外部链接，阅读过程不离站。

视觉实现继续使用已接受的 V2 字体、留白、红色序号、蓝色行动和单列结构。首页与概念图的决定数量、层级、视觉重心都未改变；必要偏离只有二级列表和站内长文随内容增长而变长。
