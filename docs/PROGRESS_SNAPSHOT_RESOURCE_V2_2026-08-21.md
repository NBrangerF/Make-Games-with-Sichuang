## 本阶段实际完成

### 1. 默认资源首页继续做减法

默认 `#resources` 只显示：

1. 开始学习桌游设计
2. 从设计师角度分析一款游戏
3. 按正在解决的设计问题找资料
4. 次级入口“搜索全部资料”

六阶段、34 个问题入口、筛选器和 574 条资源没有删除，只是不再同时出现在默认页。

### 2. 第一入口保留四种开始方式

- 系统性学习
- 看设计师怎样思考
- 边玩边学
- 从一个小练习开始

系统性学习保留九单元骨架，但首屏不展示九张等权课程卡。当前完成前三个原创单元：

1. 单元 0：从一个具体问题开始
2. 单元 1：玩家体验与设计意图
3. 单元 2：决定与核心循环

三篇都使用本站自己的中文结构、桌面例子、练习、边界与来源，不是把某一篇外文资料改写成课程。

### 3. 设计问题入口变成二段式

第三个主入口不再一次展示六阶段与 34 个具体问题。

第一段只问“你现在做到哪一步？”，显示六个设计阶段。读者选择阶段后，第二段只显示该阶段的问题。选择一个具体问题后，主题页只显示：

- 问题与预期结果
- 3 份起步中文内容
- 按需展开的适用边界
- “搜索全部资料”次级入口

主题页不会自动回到完整长列表。用户主动进入完整目录后，才加载搜索与筛选。

### 4. 旧资源深链继续保留

旧的 34 个任务入口和逐条资源深链仍可恢复。V2 的减法只改变默认呈现和进入顺序，不删除研究、策展数据、资源记录或旧地址。

### 6. 三篇原创设计师案例综合完成

1. Daniel Solis：一次只测试一种变化，《Monsoon Market》怎样收缩变量
2. Paul Dennen：一张牌怎样接起两个系统，《Dune: Imperium》起点案例
3. Cole Wehrle：删掉旧机制后系统为什么垮了，《John Company》的承诺机制重做

三篇都以具体设计决定组织，覆盖语境、问题、选项、决定、证据、结果、仍未知与迁移动作。它们是本站原创中文案例综合，不是来源文章的完整翻译；作者报告、本站推断和未知项保持分开。

### 7. 版权边界进一步收紧

当前政策是：**没有开放许可或明确书面授权的外文资料，不制作或接入全文翻译，内部学习也不例外。**

这意味着：

- 免费可读不等于可以翻译和再发布；
- 未授权设计师博客只用于事实核验、来源链接和原创案例综合；
- 不复制原文结构、长段表达、图片、评论、头像或页面外壳；
- 取得明确许可后，才可以另建版本化完整译文；
- 当前 2 篇完整译文都有 CC BY 许可依据；3 篇设计师案例都使用 `original_case_synthesis`。
