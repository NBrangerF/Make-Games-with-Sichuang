# 专项指南：先别问去哪出版，先画清谁要把游戏交到谁手里

状态：review  
阶段：呈现与发布  
核心阅读：10 分钟

## 你要得到什么

“找出版社最省事”“POD 没库存所以没风险”“众筹成功就能生产”都把不同问题压成了一句口号。

这篇指南不替你选路线。你会得到一张发布路线责任图：接收者、公开承诺、不可交换条件、八类工作、所有者、证据状态、当前验证门和退出条件。

## 1. 先写谁要完成什么行动

不要先写“我要出版”。先写接收者和可观察行动。

例：三家目前接受家庭轻策投稿的出版方编辑，能用同一份 v0.9 规则、三分钟视频和原型，在不需要我口头补充的情况下完成首次内部评估。

这与“让 100 名玩家下载低墨 PnP 并独立打印”或“让众筹支持者在中国大陆收到实体回报”是三条不同责任链。

## 2. 选路线，同时写不可交换条件

路线可以是投出版社/授权、PnP、POD、库存自出版、众筹、比赛/展示或混合。写你为什么考虑它，以及什么不能为了这条路线牺牲。

例：考虑授权，因为我只想承担设计和开发；不可交换条件是保留历史顾问复核最终文本的参与节点。若合作方无法写进开发流程，就不是当前可接受路线。

路线不是身份。今天投出版社，之后仍可在权利与承诺允许时改做 PnP；但已经签约、收款、承诺回报或产生库存后，回退成本会改变。

## 3. 把八类工作逐项分配

至少分开：

1. 游戏设计与开发；
2. 美术、图形、规则编辑与产品化；
3. 权利、合同、署名与许可；
4. 生产、样品、质检与安全；
5. 受众、营销、展示与销售；
6. 预算、收款、税务与合规协调；
7. 货运、仓储、末端履约、替换和客服；
8. 版本、勘误、更新与撤回。

例：在 POD 平台，平台可能负责按单生产和寄送，但设计者仍负责成品检查、页面、推广、文件权利、玩家支持和版本更新。“平台”不能粗略填满全部八格。

## 4. 区分名字和证据

“出版社会做美术”“平台会发货”“朋友懂税务”只是责任假设。为每项标记证据：尚未核验、官网当前要求、书面沟通、合同/服务条款，或已完成实测。

例：Piatnik 当前页面要求先邮件发送简介、规则和照片，并明确不要主动寄实体原型。这只证明 Piatnik 当前第一步，不证明它会签约、负责哪些开发工作或接受同一作品的其他版本。

任何平台或投稿页面都记录核验日期。征稿关闭、比赛截止、费率和地区规则变化后，旧截图不能继续批准行动。

## 5. 把承诺、资金与权利单独写出来

写出已经对外说过什么、收过什么、交出过哪些权利，以及目前承担多少不可逆暴露。

例：已在比赛提交 v0.8，但未签排他协议、未收款、未公开售卖；计划同时联系出版社前，先核对本届比赛是否限制同期投稿和未发行资格。

众筹金额不是可自由支配余额；支持人数会变成回报档、add-on、SKU、国家、地址、生产、发货和异常处理。库存也不是“以后慢慢卖”的抽象数字，而是占用现金、空间与长期客服的承诺。

## 6. 一次只升级一个会改变路线的未知

当前验证门可以是：确认目标、核对投稿、请求样品、审阅合作/合同、验证需求、冻结众筹前预算、核对履约，或发布入口盲测。

例：最大的未知不是版税，而是目标出版方是否仍收 60–90 分钟历史策略游戏。下一步只做一件事：核对三家当前目录与官方征稿页，记录开放状态、第一份材料和核验日期。

同时写退出条件：连续三家因体量不匹配拒绝不等于游戏不好，却足以让你回到受众/产品定位；正式报价显示现金暴露超过上限，则回到 POD 或授权路线，而不是靠更乐观销量填洞。

## 常见误区

| 误区 | 下一动作 |
|---|---|
| 把出版方目录当成质量排行榜 | 只检查当前匹配、开放状态和第一步材料 |
| 把“出版社负责”或“平台负责”写满所有责任 | 按八类工作逐项回到官网、书面沟通、合同或服务条款 |
| 用可能的单盒收益选择路线 | 先写不可逆资金、库存、时间、权利与公开承诺 |
| 众筹成功后才研究履约 | 发起前冻结回报 SKU、地区、供应链、预算和异常处理所有者 |
| 把 PnP 当成只上传一个 PDF | 盲测下载、打印、制作、设置、版本更新和支持入口 |

## 什么时候不要照做

- 只是给朋友制作一份礼物时，可以把责任图缩成接收者、权利、文件/实物检查和交付；不必假装经营公司。
- 已收到合同、税务、产品安全或跨境责任问题时，本工具只能整理问题，不能替代当地专业人士。
- 出现抄袭、未授权素材、共同创作者争议、玩家安全或无法履约风险时，先暂停公开承诺，不等本轮表格填完。

## 25 分钟练习：一张路线责任图

为同一 `v0.9` 选一条当前主路线，写接收者、希望行动和不可交换条件。给八类工作指定所有者与证据状态，圈出尚未确定的责任。最后只选一个当前验证门、下一条证据和退出条件。

完成信号：你能指出平台/出版方没有承担什么；每项所有者有证据状态；公开承诺、资金/库存和权利分开；下一步不会同时联系十家、开众筹和下生产单。

## 证据与边界

本指南综合设计师/出版者博客、协会合同教育、具体出版方投稿页、POD/数字/众筹平台文档，以及中国设计师自出版和合作复盘。它不提供路线排名、成功率、收益预测、合同条款、平台合规或法律/税务意见。当前征稿、费率、资格、平台和地区规则必须在行动时重新核验。
