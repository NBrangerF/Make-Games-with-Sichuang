# 别只计秒，追一次身体—时间窗口

阶段：测试与反馈  
核心用时：10 分钟记录，实际测试另计  
状态：review

## 你可能卡在这里

实时或操作型原型看起来很紧张，但你分不清玩家面对的是有意挑战，还是来自计时、桌面、组件、座位与协助方式的意外摩擦。

四名玩家要在 45 秒内把三角零件送进红色区域。不要先问“时间够不够”；先冻结一名玩家的一次动作窗口，追踪他要看见、够到、拿稳、决定、表达、确认与恢复什么。

## 这次带走什么

一页身体—时间窗口记录：

- 版本、人数、任务与体验承诺；
- 一个从触发到结果或修复结束的动作窗口；
- 身体、工具、材料与桌面条件；
- 看、听、触、决定、表达、确认和等待的权限链；
- 第一次偏离与修复；
- 只改变一个条件后的体验得失。

## 五步工作单

1. **冻结承诺与一个动作窗口**：写版本、人数、任务和希望出现的体验，只追一个短窗口。整局平均时间会遮住具体玩家在具体位置发生的事。
2. **写清身体与材料条件**：记录玩家愿意公开的操作方式，以及任务相关的工具、姿势、触达、精度、力度、速度和重复次数；同时写桌面尺寸、表面、座位与噪声。不要诊断玩家身体。
3. **画注意—权限链**：按顺序写谁能看、听、触、决定、说、确认与等待。实时不只是变快，也会重新分配信息和行动权。
4. **记录第一次偏离与修复**：写预期动作第一次在哪里改变、谁先发现、谁触碰或解释、是否取得同意，以及玩家失去或恢复了哪些信息、决定权、操作权和节奏。
5. **只改一个条件再测**：只改计时、暂停规则、组件、表面、座位、角色或输入中的一项，用相同任务重测。替代版本可以很好，但不要预先称它与原版等价。

## 贯穿例

原版中，玩家甲坐在长桌短边，需要越过两块板图，用指甲挑起贴桌的薄零件。乙看见目标但不能移动；甲能移动，却被丙的口令打断；丁掌管计时器，但没人知道能否暂停。甲拿不起零件后，乙未经确认直接代拿：任务完成了，甲保留答案，却失去选择路线和落子的时机。

第二轮只给零件增加 8 毫米拉片。甲能自己拿起，耗时多 4 秒，团队口令减少；但拉片让零件更难堆叠。下一轮不延长总时间，只检验拉片是否遮挡图标和转移整理负担。

## 常见误区

- **只记秒数与输赢**：补记动作序列、注意转移、权限交接、第一次偏离与恢复成本。
- **把快、吵、笑或手忙脚乱当成投入**：强度不是参与质量的代理；回到体验承诺、行为、原话和反例。
- **线上模拟顺利就宣称实体操作已验证**：触感、够取、遮挡、同步口令与组件恢复仍是实体版未知项。
- **有人代做后任务完成，就认为问题解决**：完成、同意、信息、决定权、操作权与关系成本必须分开。

## 何时先停止或改用别的方法

- 出现疼痛、疲劳、惊慌或安全风险时立即停止；退出和恢复优先于完成记录。
- 粗糙材料可以回答流程问题；若问题正是抓取、触感、视线、同步或空间，它不能回答高精度问题。
- 协助可以是玩家主动选择的互相依赖体验。不要预设独立操作总是目标，但要记录谁选择、谁承担和谁可撤回。
- 回合制、远程或替代输入可以成为有效版本；应写清它保留和移走的体验。

## 完成信号

- 记录明确到一个版本、一个体验承诺和一个短动作窗口；
- 身体与物理环境信息只按任务需要收集；
- 能复述注意、信息与行动权怎样流动；
- 第一次偏离与修复包含同意、信息、行动权和恢复成本；
- 第二次测试只改变一个条件，并使用相同任务；
- 结论同时写新增和失去的体验。

## 证据边界

这份指南综合桌游互动研究、关于实体代理与时间的理论文章、相邻的全身游戏系统综述、无用户测试的 Crokinole 辅助原型、官方实时游戏规则与设计日志，以及一名身体残障玩家的第一人称文章。

它们支持把身体动作、桌面条件、时间和权限当作可观察系统变量，但不提供普遍秒数、体能门槛或无障碍认证。全身游戏综述主要来自数字媒介；Crokinole 原型未由残障玩家测试；规则书和设计日志只能证明结构与设计意图；单篇玩家文章不能代表全部经验。中文第一人称实体桌游操作资料仍明显不足。

完整来源、逐篇限制与产品判断见[实时、技巧与身体化桌游专项研究](../research/EMBODIED_REALTIME_PLAY_01.md)。
