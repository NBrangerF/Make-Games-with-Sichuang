# 专题指南：战役状态护照

对应专题：`special-campaign-state-passport`  
阶段：测试与反馈  
更新：2026-08-19

## 用户问题

游戏有章节、成长、秘密或永久组件变化。规则一改、有人缺席或换手后，设计者无法判断后续数据是否仍属于同一测试序列。

## 核心产出

一张 12 分钟可写完的无剧透状态护照：

- 一个只在跨章节出现的机制问题；
- `campaign_state_id` 和规则版本；
- 世界、角色、玩家知识三类独立变化；
- 本局新揭示、永久改造与出席变化；
- 接续方法保存/牺牲的功能；
- 改版后的旧分支、迁移、并行复制或新组重开决定；
- 副本、存档、恢复凭证与退出资料的保管。

## 四条历史

| 历史 | 示例 | 不能用什么代替 |
|---|---|---|
| 规则 | v0.8，新贴入规则 R3 | 第几局 |
| 世界 | 地图贴 A2、牌库移除 E7 | 规则版本 |
| 角色 | 伤痕 S1、退休、换手 | 玩家熟练度 |
| 玩家 | 甲乙知包 4，丙不知 | 全组章节号 |

同一规则版可以有多个世界分支；同一世界中的玩家也可以知道不同内容。重置组件只能恢复部分物理状态，不能重置记忆。

## 迁移四选一

原型关键改版时必须选择并记录：

1. 旧组继续旧版分支；
2. 旧状态映射到新版；
3. 复制世界为并行分支；
4. 新组按新版重开。

四种选择都可以合理。不能做的是覆盖旧版本后把迁移局继续画成同一条熟练曲线。

## 接续不是等价

缺席、加入或回归时，可使用补偿、无剧透摘要、角色托管、自动玩家、跳过或暂停。每种方法只声明：

- 保存了什么机械状态；
- 谁看见了揭示；
- 谁作了不可逆决定；
- 谁承担设置与维护；
- 回归者怎样恢复决定权。

不要用“资源追平”代替关系、依恋、知识和行动权分析。

## 隐私、版权与退出

- 公开护照只使用内部编号，不复制隐藏卡文、贴纸、谜题或分支答案；
- 玩家可以拒绝剧透、永久改造、录音/录像、继续记录或继续战役；
- 退出时明确角色、实体副本、私密备注、撤回映射和未揭示内容怎样处理；
- 不以战役完成、连续出席或不退出评价参与者。

## 完成信号

- 只追一个跨局机制；
- 四条历史独立可辨；
- 逐名知识范围没有被全组章节号覆盖；
- 接续写明功能和决定权；
- 改版有四选一分支和不可比较项；
- 保管、恢复、停止和退出都可执行。

## 证据边界

本指南综合 Legacy 理论、学位创作研究、商业设计者一手复盘、官方 FAQ、长期测试者记录、战役测试博客、设置事故报道与两项 CHI 桌游研究。它们没有验证本站表单，也不提供通用战役长度、固定组人数、完成率或补偿公式。四历史护照和迁移四选一是本站产品综合，必须通过真实中文新手、缺席回归者和战役主持者测试。
