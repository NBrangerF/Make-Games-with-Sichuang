## 完成检查

- [ ] 窗口的观察、决定、行动/回应、锁定、冲突、执行、确认和交接都有所有者。
- [ ] 行动经济含资格、机会成本、免费/触发动作、反应与维护，不只写行动点。
- [ ] 钟表等待、决定延迟、预案存活、强制监看、交接与恢复分开。
- [ ] 删除或自动化维护前，已写它现在承担的功能。
- [ ] 同步方案另写锁定、泄密、冲突、最慢者、速度优势和修复。
- [ ] 下一版只改一个窗口或粒度，并预先写反驳信号。

## 停止条件

出现抢夺组件、速度/感官要求造成安全或明显排除、玩家要求暂停、争执无法按当前规则修复，或记录者必须持续介入才能维持状态时，停止当前任务；不要为了拿到完整时长继续。
