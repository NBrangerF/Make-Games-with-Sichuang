# 专项指南：别数谁说得多，追一次共同决定

状态：`review`  
阶段：测试与反馈  
核心阅读：16 分钟

## 这篇指南解决什么

合作、谈判或隐藏信息测试中，设计师常把“谁说得最多”直接当成谁控制游戏。这个判断会混在一起：被请求的教学、善意建议、角色许可、信息优势、沟通速度、组件操作与真正的非自愿决定代办。

本指南产出一条具体共同决定轨迹，不评价人格、领导力或合作能力。

## 五步路径

1. **先写参与约定和一个决定时刻。** 用角色/颜色代号记录版本、语境和具体决定；确认本桌希望自由建议、行动者拍板、共同共识、指定导师或其他方式。
2. **画信息与权限，而不是数发言。** 分开谁知道什么、能否分享，以及谁可提案、修改、否决、拍板和执行。
3. **追提案、回应与沉默。** 按顺序写提案、追问、反提案、接受、拒绝与中断。沉默只写“无法判断”。
4. **比较归属、执行、后果与同意。** 写最终决定、执行者与后果归属；局后用中性问题确认指导是否被请求、是否符合约定。
5. **只修第一次错位，再复现。** 只改一处信息、权限、轮次、沟通通道、时间或提示，用相近决定复测。

## 不要这样判断

- 发言多、音量大或经验丰富不自动等于决定代办。
- 私人信息和禁言不是默认解决方案。
- 角色能力不同不自动代表每个人有真实决定权。
- 桌谈热闹不自动代表谈判有杠杆或能收束。
- 沉默、笑声、胜利或配合执行都不能单独证明同意。

## 一次可直接运行的练习

冻结一次不超过三分钟的行动，写下：参与约定、决定归属、信息与权限、提案顺序、回应、最终拍板、执行者、后果、同意核对、沟通条件和第一处错位。

示例：本桌约定驾驶员拍板；侦察员持有风暴信息，所有人可提案；红连续给出结论并替蓝选航线，蓝沉默，记录员执行，燃料由蓝承担。局后蓝说想自己从两个选项中选。下一版只加入行动者复述并确认后拍板的停顿。

## 工具与边界

网站工具“共享决定观察”会本地保存并导出这一记录，导出显式标注不生成总分。只使用角色、颜色或代号，不写真实姓名。

一条记录只能描述当前版本、玩家和局面。它不能诊断某人是“alpha player”，不能从沉默推断同意，也不能证明某种机制普遍有效。详细来源和证据边界见 [合作、谈判、隐藏信息与共同决定专项研究](../research/COOPERATION_SHARED_DECISION_01.md)。
