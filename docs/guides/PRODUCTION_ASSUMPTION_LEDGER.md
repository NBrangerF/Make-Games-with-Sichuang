# 专项指南：别先问一盒多少钱，先冻结一份生产假设

状态：review  
阶段：呈现与发布  
核心阅读：14 分钟

## 你要得到什么

“这盒做出来大概 30 元”看起来像答案，却没有说明印量、组件、币种、是否含工装、运输、税费、仓储或履约。下一次组件改版后，这个数字可能已经不再描述同一个产品。

读完本指南，你会得到一份可交给出版方、生产方或下一位团队成员继续核验的生产假设账本。它不预测价格，而是让每个组件、数字、样品和未知项都有版本、来源与下一条证据。

## 1. 先选交付路线和这次要作的决定

投出版社、免费 PnP、小批/POD、自出版大货和众筹面对不同责任。先写清：这次是为了删减原型、取得可比报价、批准产前样，还是估计某个地区的交付风险。

例：`v0.8，自出版 1500 份，目标首发中国大陆与新加坡；本轮只决定是否把四种异形木件改成标准圆片后再询价。`

## 2. 给每个组件写功能，再写规格

组件表至少写类型、数量、尺寸/材料/加工、玩家功能、替代方案和证据状态。不要只写“120 张牌”或“若干木块”。

例：`每盒 24 枚 20×4mm 木圆片、四色、单面丝印；用于盲抽后靠形状+颜色识别阵营。备选纸板圆片会保留图标，但要复测抓取和磨损。`

早期可以标“未知”。假装知道比保留未知更危险。

## 3. 冻结一份有范围的成本证据

记录数量场景、币种、日期、证据级别，以及明确包含/排除项。把工厂范围、落地范围和项目全成本分开。

例：`USD，1500 份，2026-08-17，供应商书面报价；含印刷、木件、装配、盒与外箱，不含模具修改、国际货运、税费、入仓和末端履约。`

不要把不同数量、不同版本或不同范围的单价直接比较。

## 4. 把盒子和内衬当作一组玩家任务

实测盒内尺寸、装箱后重量、牌套、设置、分发、桌上取用、复原和辅助需求。组件能塞进盒子不等于包装完成。

例：`戴牌套后卡堆增加 13mm；现内衬可放入但无法用一只手取出，且四人设置必须先把所有资源倒到桌上重新分类。`

## 5. 只批准当前验证门能证明的东西

区分文件/印前、组件样、产前样 PPC、量产样 MPC 与入库抽检。为当前样品写验证任务、预期、实际结果与批准者。

例：`PPC 只验证卡牌颜色/文字、冲切偏移、盒内 fit 与完整设置；不据此断言整批无色差或国际运输无损。`

最终图形与材料需要重新做陌生玩家实物测试。纸片原型通过不能证明最终字号、对比、抓取和收纳通过。

## 6. 只把一个未知项升级成更强证据

选择当前最可能改变决定的一项未知，把它从“粗略假设”升级为模板、实测、正式报价、样品或发票。写清升级后会作什么决定。

例：`下周只取得两种木件方案在同一 1500 份数量、同一盒型下的书面差价，并让三位玩家用纸板替代件复测盲抽识别；其余规格不变。`

## 常见误区

| 误区 | 下一动作 |
|---|---|
| 用一个工厂单价表示整项成本 | 标注范围、币种、数量、日期、包含与排除项 |
| 组件越少或越便宜就一定更好 | 先写玩家功能；替换后用同一任务复测 |
| 美术完成后才第一次询价 | 核心机制稳定后先冻结规格与备选，再投入不可回收的最终资产 |
| 看过 PDF 校样就批准所有生产 | 区分文件、材料、PPC、MPC 与入库门，每门只证明对应风险 |
| 所有东西塞进盒子就算包装完成 | 测开盒、取出、设置、桌上取用、复原、牌套和辅助需求 |
| 写了“环保材料”就宣称可持续 | 记录材料、重量与供应链证据；不生成绿色认证，仍检查耐用与可访问性 |

## 何时不要照搬

- 投出版社时，设计者通常不负责最终生产，但组件功能、替代底线与希望参与的审阅节点仍应在沟通或合同中明确。
- 免费 PnP 不需要大货报价，却仍有打印尺寸、耗材、裁切、可访问性和玩家自制劳动。
- 艺术品、小批手工版本或特殊收藏版可能主动接受较高单位成本；账本用于说明取舍，不强迫最低成本。
- 不同地区的安全标识、测试、知识产权、税务、海关与消费者规则会变化；本指南只要求标出责任和未知，不能替代专业意见。

## 20 分钟练习：冻结一个报价场景

选择当前版本和一种交付路线，列出三个最影响产品的组件。为每项写玩家功能、规格、替代方案和证据状态；再写一个数量场景、成本范围、包装任务、当前样品门和下一条要升级的证据。

示例产出：`v0.8 / 小批 100 份；牌、木圆片、折叠板三项。当前只有平台计算器价格，不含运费；盒内尺寸尚未实测。下一步先用戴套卡堆和全部组件测量最小内部空间，再在相同规格取得平台正式购物车价格。`

## 完成信号

- 交付路线、目标地区、数量场景与当前决定明确。
- 每个关键组件都有玩家功能、可复核规格、替代方案和证据状态。
- 成本证据带币种、日期、范围、包含项和排除项，没有被包装成价格预测。
- 包装完成实际设置、取用、复原和整盒尺寸/重量检查。
- 当前验证门、验证任务、实际结果和批准责任明确。
- 下一步只升级一个会改变决定的未知项。

## 证据与边界

本指南综合生产商当前流程/模板、小批平台计价规则、行业协会的开发与最终图形审阅、众筹平台履约指南、设计师制造日志、中文生产实践和三个假设盒型的 LCA 传播材料。供应商页面描述自身流程，不代表行业统一标准；设计师日志是具体项目；环境研究不能给单款游戏算环保分。本站不提供报价、利润预测、供应商排名、合同/税务/海关/合规意见或可持续认证。所有时效敏感数字必须回到当前正式文件、书面报价与专业人员。
