# 计分契约：一页模板

适用：游戏能结算，但玩家只追同一路线、看不懂进展，或终局才发现方向错了。  
不适用：自动求最佳分值、策略、公开比例或公平总分。

## 1. 先拆三条规则

```text
版本 / 人数 / 经验：
目标体验：
游戏何时结束或进入收尾：
什么状态决定胜 / 败 / 平：
哪些行动或状态怎样换算：
希望玩家反复做什么：
不希望玩家靠什么行为赢：
```

结束条件、胜利条件和计分函数可以重合，但不要在记录里省略它们的关系。

## 2. 追踪一个得分事件

```text
事件所有者：
得分前最后一个真实决定：
当时能看到的信息：
实际考虑的合法候选：
放弃了什么：
即时非分数反馈：
何时得分 / 多少 / 谁可见：
怎样改变下一次目标或重复行为：
对手知道后能合法回应什么：
```

只写“交货得 4 分”不足以解释这 4 分选择了什么行为。

## 3. 比较两条候选路径

| 字段 | 路径 A | 路径 B |
|---|---|---|
| 需要先承诺什么 |  |  |
| 所需状态与时点 |  |  |
| 机会成本 |  |  |
| 中途切换损失 |  |  |
| 对手/队友能影响什么 |  |  |
| 失败何时可见 |  |  |
| 开局/中盘/终局贡献 |  |  |

若同一引擎无成本同步推进两栏，先称“两个计分来源”，不要称“两条策略”。

## 4. 写速度、可见性与回应

```text
计分时点：即时 / 阶段 / 延迟 / 终局
可见性：公开 / 私密 / 可推断 / 可追踪但隐藏
实际进展：
玩家感到的进展：
计算 / 查询 / 记忆劳动：
玩家知道分数后能改变的合法行动：
终局揭晓是否超出可解释范围：
```

公开不自动更互动，隐藏也不自动更有悬念。先问这项信息支持什么回应。

## 5. 分轨验证，只改一个关系

| 证据轨 | 本轮只记录 |
|---|---|
| 系统结果 | 分差、路径贡献、触发次数；不替代体验 |
| 决定理解 | 玩家行动前怎样解释路径、代价与兑现 |
| 互动 | 阻断、围攻、协商、目标选择与记忆劳动 |
| 感知进展 | 玩家何时觉得领先、落后、可追或被反超 |
| 体验与归因 | 能力、自主、主题后果、乐趣，以及为何赢/输 |

```text
本轮只改：分值 / 时点 / 可见性 / 非分数反馈（选一）
预计行为变化：
反驳信号：
下一条最小证据：
```

## 完成信号

- 三条规则分别写清；
- 一个得分事件已连接决定、代价、反馈和下一行为；
- 两条路径已比较承诺与切换，不用项目数量冒充路径；
- 时点、可见性、实际/感知进展和合法回应已记录；
- 系统、理解、互动和体验分轨；
- 下一轮只改变一个激励关系，并预先写反驳信号。

完整证据与限制见[计分、目标、奖励与激励错位](../research/SCORING_GOALS_INCENTIVES_01.md)。
