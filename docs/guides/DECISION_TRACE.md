# 专项指南：别数选项，追一轮真实决定

状态：review  
阶段：核心系统  
核心阅读：12 分钟

## 你要得到什么

得到一条“规则允许什么 → 玩家真正比较什么 → 选项在哪里第一次退出 → 玩家预期什么 → 实际发生什么 → 下一次怎样更新”的决定轨迹。它不判断决定好坏，也不计算游戏深度。

## 五步路径

1. **冻结一个时刻。** 写版本、玩家语境、轮次、阶段、资源与刚发生的事件，不复述整局。
2. **分开合法与被考虑的选项。** 合法选项来自规则；被考虑选项来自指向、比较、询问、停顿、行动与经同意记录的简短原话。
3. **标记第一次坍缩。** 先记录显然更差、后果相同、信息不清、不可支付、负担过重、被他人封锁、未进入考虑或其他，不立即解释成玩家能力问题。
4. **连接预测、行动与反馈。** 写玩家当时目标、机会成本、其他玩家的影响路径、行动前预测、实际行动、实际后果和后果何时可见。
5. **只改一个上游条件。** 根据第一次坍缩选择一处信息、成本、互动或反馈变化，用相同局面或可比较局面复测。

## 常见误区

| 误区 | 修复 |
|---|---|
| 只数规则分支 | 分开合法选项与玩家实际考虑的选项 |
| 把未口述当作没有思考 | 用多种行为证据，并标记记录方式和不确定性 |
| 把互动直接分成多或少 | 写出谁的行动经由哪条规则改变了谁的状态 |
| 一条轨迹就宣布“很有深度” | 跨多局、不同经验层追踪模型更新与策略变化 |

## 何时不要照搬

- 实时、动作、记忆或强身体操作游戏需要视频、时间线或空间记录；
- 谈判、隐藏身份和合作游戏需要同意、关系与信息权限字段；
- 专家可能压缩大量推演，口述会遗漏或改变过程；
- 纯随机揭示后的情绪反应不一定构成行动前决定；
- 一条局部轨迹不能证明最佳策略、平衡、深度或可重玩性。

## 20 分钟练习

从最近一次测试选一个真正犹豫或迅速跳过的时刻。先独立列出合法选项，再只根据记录列出玩家实际考虑的选项；圈出两者第一次分叉的位置，写行动前预测、实际后果和下一版唯一改动。

完成信号：版本和玩家语境明确；合法/考虑选项没有混写；至少写出一项机会成本或说明没有；互动以影响路径表达或明确留空；预测与后果分开；下一版只改一处。

## 证据边界

Nature 研究覆盖超过 1000 名参与者和 121 款多数陌生的双人策略棋盘游戏，但不代表谈判、合作、隐藏信息、身体操作和专家长期学习。超过 27000 名在线玩家的次要目标 A/B 研究使用数字游戏留存/进度指标，不能直接推出实体桌游乐趣或可重玩性。设计师与玩家博客提供可操作语言，但不是普遍效果量。
