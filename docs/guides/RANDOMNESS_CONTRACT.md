# 随机性契约：一页模板

更新：2026-08-20  
状态：review；对应 `special-randomness-contract`

## 1. 不确定性承诺

```text
原型 / 版本：
人数、模式与座位：
玩家经验与支持条件：

这一段为什么需要不可预测：
目标体验：惊喜 / 适应 / 冒险 / 平衡差距 / 对手读取 / 叙事 / 其他
不可接受失效：

不确定性来源：随机装置 / 隐藏信息 / 他人行动 / 系统复杂度 / 记忆 / 实体执行 / 其他
随机装置与分布：
```

不要把“使用骰子”写成设计目的。

## 2. 决定—随机—回应循环

连续写两轮，不只标输入/输出：

| 事件前决定 | 随机事件与揭示 | 结果何时锁定 | 回应窗口 | 结果后决定 | 下一次暴露 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |
|  |  |  |  |  |  |

回应窗口同时写时间、信息和可执行选择。一次输出通常会成为下一决定的输入。

## 3. 随机暴露与 stakes

```text
谁选择承担：玩家 / 对手 / 共同 / 系统强制
选择前可见信息：
稳定替代路线：
最好 / 常见 / 最坏结果：
可能性或组成：
本次可失去：
永久损伤：
失败恢复路径：
是否能保存已有收益：
```

若概率刻意隐藏，写玩家仍能读取的信号，不自动填“未知”。

## 4. 缓解动作清单

| 动作 | 类型 | 时点 | 所有者 | 成本 | 真正改变什么 | 维护/查询成本 |
|---|---|---|---|---|---|---|
|  | 事前准备 / 选择暴露 / 改分布 / 择果 / 重试 / 结果转换 / 事后适应 / 止损 |  |  |  |  |  |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |

“重掷”仍需注明全体或部分、付费者、次数与是否只再次抽样。

## 5. 三条观察轨道

### 系统结果

```text
固定的版本 / 配置 / 代理或玩家：
共享的种子 / 抽取序列：
被改变的随机源：
结果指标：
观察到的贡献：
代理与指标限制：
```

### 真人决定与体验

| 玩家/经验 | 看到什么 | 实际选择 | 结果后回应 | 理解/情绪 | 是否改变下一决定 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

### 结果归因

```text
玩家认为结果来自：自己 / 对手 / 系统 / 运气 / 混合
依据：
确信程度：
事件真实来源与观察者记录：
```

不要把三条轨道合成“随机性 7/10”。

## 6. 下一轮只改一个风险

```text
本轮最重要症状：
证据：
当前解释：
唯一改动：
预期改变的循环位置 / 暴露 / 缓解：
若观察到什么则反驳：
保持不变的分布、stakes 或回应：
下一轮测试配置：
```

## 完成检查

- [ ] 目标不确定性与随机装置分开。
- [ ] 至少两轮决定—随机—回应已画出。
- [ ] 暴露所有者、事前信息与最坏 stakes 可见。
- [ ] 每个缓解动作都有类型、成本、时点与所有者。
- [ ] 事件次数与结果贡献没有混为一谈。
- [ ] 计算结果、真人体验和玩家归因分别记录。
- [ ] 下一轮只有一项可反驳改动。
