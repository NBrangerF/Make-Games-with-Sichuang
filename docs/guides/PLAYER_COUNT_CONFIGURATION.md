# 玩家人数配置契约

更新：2026-08-19  
状态：review；对应 `special-player-count-configuration`

## 用途

在把“2–5 人”写进规则或盒侧前，先把每个人数、队伍、角色和模式拆成独立配置，说明它保留什么、改变什么，以及如何验证。

## 一页模板

### 1. 配置身份与承诺

| 配置 ID | 人数 / 队伍 | 角色与模式 | 版本 / 座位 | 层级 | 保留的体验 | 不承诺 |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  | 主要 / 支持 / 实验 / 不支持 |  |  |

### 2. 互动拓扑

- 直接影响关系：
- 第三方怎样受益或受损：
- 邻接、联盟、投票与队伍：
- 信息向谁流动：
- 谁提议、谁决定、谁执行：
- 落后者与领先者的恢复/压制路径：

### 3. 总行动与公共密度

| 配置 | 自己回合动作 | 局外触发 | 公共阶段 | 真正同时 | 仍需串行解析 | 总量假设 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
|  |  |  |  |  |  |  |

| 缩放项 | 当前数量/规则 | 要保存的功能 | 固定 / 线性 / 分段 / 结构变化 | 失败信号 |
| --- | --- | --- | --- | --- |
| 地图 / 市场 / 牌库 / 候选 / 目标 / 轮数 / 资源 / 结束条件 |  |  |  |  |

### 4. 角色、dummy 与同步修补

- 缺失或过量的功能：
- 选择：设置变化 / 功能性 dummy / 角色合并或拆分 / 团队 / 同时行动 / 独立模式
- 该修补唯一承担的工作：
- 玩家维护动作与查询：
- 行动前可见信息、平手与无合法行动：
- 锁定、冲突顺序与错误恢复：
- 牺牲或不再承诺的体验：

### 5. 配置分轨测试

- 目标玩家与新手/熟练度组合：
- 换座、首末位、邻接与队伍轮换：
- 总行动、局长、等待、市场/地图密度：
- 桌面空间、组件、设置、教学和协助变化：
- 第一次配置特有故障：
- 本轮只改一项：
- 可跨配置比较的指标：
- 已失去相同含义、不可直接比较的指标：

### 6. 外部信号边界

- 设计者/发行方标注与日期：
- BGG 或其他社区票数、总票数与抓取日期：
- 具体长评及其版本、局次与语境：
- 这些信号只触发哪一个后续观察：

## 停止条件

当角色合并无法安全完成、同步行动没有锁定与冲突规则、dummy 必须由玩家临场替它设计策略，或关键胜负/团队关系已经改变却仍试图合并数据时，停止跨人数体验判断。把配置改标为实验或独立模式，先修复其协议。

## 证据边界

本模板来自 `docs/research/PLAYER_COUNT_SCALING_01.md` 的跨来源综合。它不提供通用最佳人数、资源/地图公式、等待秒数、dummy 复杂度、同时行动收益、社区偏好比例或测试局数；仍需中文新手、混合熟练度和不同可访问性玩家验证。
