# 专项指南：别问主题够不够浓，追它让玩家做了什么

状态：review  
阶段：体验意图（跨核心系统、测试与发布）  
核心阅读：18 分钟

## 问题

“尊重历史”、“关于共情”、“有文化顾问”和“列了内容提示”都不能单独说明玩家实际被要求做什么。

## 五步

1. **承诺与语境**：写希望谁透过哪个位置看见哪种关系，并写预期受众和桌面语境。
2. **角色、行动、奖励与省略**：写玩家的信息/权限，每轮重复做什么，系统奖励什么，谁只是资源或背景。
3. **来源、解读、虚构与协作**：分开史料与不确定性、设计判断、创作隐喻；涉及在世社群时，记录谁能在何时改变什么。
4. **暴露、告知、选择、退出与修复**：追玩家是阅读、观察、选择、执行、扮演还是对他人施加；不询问玩家创伤史。
5. **修第一处不匹配**：只改一处系统条件或补一项研究/协作，再在相关受众语境复测。

## 快速检查模板

```text
版本：
预期受众/桌面语境：
一句主题承诺：
玩家的可玩位置：
每轮重复行动：
奖励与可见后果：
被自动/资源化/省略的人与过程：
史料、来源与不确定性：
解读、隐喻与虚构：
文化协作对象/阶段/权限/付费/署名/分歧：
内容暴露方式：
具体内容提示：
选择/跳过/退出/修复：
第一处不匹配：
下一版只改或只补：
```

## 不要这样用

- 不把“主题先”当成真实性证明。
- 不把史实正确当成视角与伦理已处理的证明。
- 不请一位顾问代表整个文化盖章。
- 不用内容提示认证安全。
- 不要求玩家为退出披露、证明或解释创伤。

## 完成信号

- 承诺、受众和语境已写明。
- 角色、行动、奖励与省略已并排。
- 来源、解读、虚构和不确定性已分开。
- 协作边界已写明或标记待办。
- 告知、选择、退出与修复不再混成一个“安全”标签。
- 下一步是单一、可验证的设计、研究或协作行动。

## 证据边界

本方法同时使用学术方法论、桌游文本分析、大尺度元数据研究、设计师/顾问实践、参与式项目、玩家博客与相邻安全研究。这些来源适合形成检查问题，不足以输出伦理分、真实性认证、安全认证或社群认可。情绪安全的大量话语来自 TTRPG/LARP，不可直接当作封闭系统桌游的已验证处方。
