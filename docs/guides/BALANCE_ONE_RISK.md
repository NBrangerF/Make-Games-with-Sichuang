# 专项指南：先定义这轮到底在平衡什么

状态：review  
机器可读正文：`content/special-guides.json#special-balance-one-risk`  
配套工具：`balance-pass`

## 适用情境

你已经有一条可以重复发生的核心决定，也开始看到胜率、分差、选项使用率或玩家抱怨，但还不能指出“哪里以什么方式偏离了目标体验”。

若核心决定仍未出现，先回到最小原型；若问题是规则误读、组件可见度或玩家无法自主操作，改用盲测或任务无障碍观察。

## 最小流程

1. 写目标玩家、人数、时长与要保护的体验。
2. 只选一种失效风险：选项支配、先手/座位、滚雪球、追赶过强、随机主导、经济停滞/爆炸、节奏或非对称差异。
3. 画产生差距的最小关系：资源流、成本—收益或反馈回路。
4. 只计算当前问题需要的基线，并写它不能证明什么。
5. 选择最多三项会改变设计决定的记录，让它们回到版本、人数/座位、玩家经验、测试方式和样本量。
6. 在看新结果前写反驳信号；下一版只改变一个上游条件。

## 证据边界

这不是平衡合规表、胜率门槛或样本量计算器。工具不生成总分，也不把一轮结果写成 `balanced/unbalanced`。完整来源、反例与产品推断见 [专项研究 04](../research/BALANCE_PROBABILITY_01.md)。
