# 牌库构筑、抽牌概率与循环控制契约

状态：review  
日期：2026-08-20  
适用阶段：核心系统、最小原型、规则与信息、测试与反馈

## 你可能卡在这里

“加了强牌却一直抽不到”“删牌后引擎突然无限”“市场翻不到需要的路线”“玩家买牌但终局前从没用过”“一局要洗十几次牌”“得分牌只让手牌变废”都不是单纯卡值问题。完成本契约后，你会得到一张牌库功能表、一张获得—兑现时间线、一份透明概率计算、一次压缩/膨胀诊断和一份包含洗牌与辅助成本的单字段测试。

## 五步契约

### 1. 把牌库按功能与区域拆开

列出抽牌堆、手牌、打出区、弃牌堆、持续区、移除区、未来注入和终局区。每种牌标记行动许可、支付、抽取、筛选、检索、压缩、污染、得分或多用途。

示例：10 张起始牌中 7 张支付、3 张得分；当前 2 张基地在持续区，不能把它们继续计入“本轮可能抽到”。

### 2. 追踪一次获得到首次兑现

写购买/获得窗口、进入区域、是否立即可用、下一次洗牌距离、预计首次出现轮次、剩余循环数和终局去向。

示例：第 4 轮购买牌 A 进弃牌；抽牌堆还剩 7 张、每轮净抽 5 张；若无额外抽取，最早跨下一次洗牌后出现，不能把本轮卡面收益算入购买回报。

### 3. 写清概率模型和例外

记录 N 张未知牌、K 张目标、抽 n 张、是否不放回、已知牌、跨洗牌、顶置、检索、弃后重抽和组合条件。满足简单条件时算“至少一张”；否则枚举或模拟。

示例：20 张未知牌有 4 张移动牌，抽 5 张至少一张为 `1-C(16,5)/C(20,5)`；若牌顶已知是移动牌，概率问题已变成确定状态。

### 4. 连接压缩、膨胀、组合与终局

对一次新增或移除写牌库净变化、目标密度、功能损失、付出窗口、下一循环距离、同手组合、合法行动/资源，以及终局前预计兑现次数。

示例：移除一张起始金币把移动牌密度从 4/20 提到 4/19，但也让昂贵购买路线少一个支付；若只剩一轮，密度提升可能来不及兑现。

### 5. 重放循环并只改一个字段

让新手执行购买、清理、抽牌不足、洗牌、跨边界补牌、移除和终局；记录洗牌次数/时间、查询、掉牌、协助和恢复。只改进入区域、手牌数、目标牌数、压缩成本、洗牌触发、市场刷新或终局之一。

示例：v0.4 只把新购牌从弃牌改为牌顶。支持信号：路线牌能在终局前至少出现一次；反驳信号：先手取得的高强度牌立即形成无法回应的滚雪球。

## 常见误区与修复

1. **误区：强牌越多，牌库越强。** 修复：记录新增后的目标密度、行动许可、失败手牌和终局前兑现次数。
2. **误区：压缩总是正确。** 修复：写被删牌的支付、得分、行动或缓冲功能，以及压缩成本和领先者收益。
3. **误区：牌库有 20% 目标牌，所以每手必有一张。** 修复：用不放回模型计算分布，并保留连续未抽到的短局风险。
4. **误区：洗牌只是几秒钟维护。** 修复：记录每位玩家的频次、方法、疼痛/掉牌、协助、等待和秘密泄露。
5. **误区：买到就算获得价值。** 修复：追踪进入区域、首次可用、预计循环数和终局时钟。

## 可以有意打破的情形

- 固定顺序牌库可以取消随机洗牌；要明确可查询、记忆与牌序控制边界。
- 一次性剧情或战役牌可以只出现一次；价值可来自揭示而非循环回报。
- 膨胀路线可把大量弱牌本身作为得分或盾牌；应验证它没有意外切断基本行动。
- 终局前购买“废牌得分”可以有意制造引擎转分时机；要让玩家读到剩余循环。
- 数字实现可以自动洗牌和计算；仍需解释区域、概率假设和为何没有合法行动。

## 25 分钟练习：追踪一张新牌的第一生与第二生

选一次真实购买，摆出牌库、弃牌和手牌。记录新牌进入哪里、何时第一次抽到、第一次打出后去哪、何时第二次出现、终局前预计还能出现几次。再移除一张起始牌，只重算密度和循环，不改卡值。

示例输出：A 在第 3 轮进入 8 张弃牌堆；牌库余 2，补 5 时先抽 2、洗 8、再抽 3；A 本轮出现概率 3/8。打出后回弃牌，预计第 6 轮第二次出现。v0.5 只把购买改为入弃牌顶，不改变成本。

## 完成信号

- 所有核心牌都能按功能和区域计数；
- 至少一次获得能追到首次/再次兑现与终局；
- 概率计算写明总体、目标、抽取、不放回与所有例外；
- 一次压缩或膨胀同时记录密度、功能、组合和终局副作用；
- 陌生玩家能正确处理跨洗牌边界且无需设计师补话；
- 洗牌、查询与辅助的时间、决定权和泄密已经观察；
- 下一版只改变一个牌库字段，并预写支持与反驳信号。

本契约综合六份规则/规则汇编、六项设计师与设计分析、六项概率/计算/洗牌研究、四项无障碍资料和四项非代表性玩家症状。它支持把牌库拆成区域与功能、追踪获得兑现、公开抽取模型、把压缩/膨胀/组合连接到终局，并记录洗牌和辅助成本；它不提供最佳牌库张数、手牌数、起始牌比例、压缩率、目标密度、循环次数、洗牌次数、市场槽位、组合长度或疲劳阈值。完整来源见 [专项研究](../research/DECK_BUILDING_DRAW_CYCLE_01.md)。
