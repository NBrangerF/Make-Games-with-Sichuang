# 隐藏信息与手牌经济契约

状态：review  
日期：2026-08-20  
适用阶段：核心系统、最小原型、规则与信息、测试与反馈

## 你可能卡在这里

“有隐藏手牌”并不能说明玩家为什么要推断；“每人只能给一个线索”也不能说明线索何时有效。常见症状是：玩家纯猜、第一轮没信息、熟人靠表情碾压、手牌越抽越卡、公开过的内容只能靠记忆、协助读牌会泄密、挑战没人愿意做，或终局才发现整局没有可回应信息。

完成本契约后，你会得到一张信息矩阵、一张牌的完整生命周期、一条可验证的推断路径、一份沟通/协助协议，以及下一版只改变一个信息字段的测试计划。

## 五步契约

### 1. 写谁在何时知道什么

对每项核心信息填写：真实状态、当前持有人、可见者、信息来源、可靠度、能否记录/转述/查询、失效条件、揭示窗口，以及知道后能采取的合法回应。

示例：乙知道自己的角色；甲只知道乙曾宣称 Duke；全桌看见两张 Duke 已永久公开；挑战前无人能验证乙当前是否持有第三张。

### 2. 追踪一张牌的完整生命周期

画出抽取来源、进入手牌的位置、可见范围、可用动作、锁定/保留、打出或支付、公开、弃置/移出/洗回和终局残值。注明手牌顺序、上限和补牌时点。

示例：牌 A 从牌库末知抽入手牌末端，不得重排；下轮到牌首必须种植，交易接受后才可抽离，收到的交换牌不进手牌且必须立即种。

### 3. 写一条可推断、可验证、可回应的路径

选一个声明或事件，列至少两种合法解释、每种解释产生它的条件、当前证据、一次验证或对冲行动、猜错代价和反馈时点。不要把眼神、犹豫或语气写成可靠识谎器。

示例：丙声称能阻挡。可能真的持牌，也可能因被刺杀本来就会出局而零成本诈唬；甲可以挑战、换目标或接受，三种选择都有不同成本与揭示。

### 4. 写沟通、记忆与协助协议

明确允许/禁止内容、对象、次数、成本、窗口、媒介、同时/顺序、确认、失误修复和替代渠道。再写协助者能看什么、能做什么、是否替代推断或暴露意图。

示例：每次任务仅一次；一墩开始前公开一张非王牌，标记最高/唯一/最低，标记不随状态更新；持牌困难者可用卡架，但代读者不得看牌面后建议行动。

### 5. 重放并只改一个信息字段

让新手区分“我知道 / 我相信 / 他声明 / 已验证 / 已揭示”，执行抽取到弃置，再在中断后恢复。只改可见者、线索次数、验证成本、揭示时点、手牌上限、顺序或记忆接口之一。

示例：v0.5 只把已公开弃牌从散堆改为按角色分类。支持信号：玩家无需询问即可更新概率；反驳信号：分类让领先者锁定所有剩余角色并消除诈唬。

## 常见误区与修复

1. **误区：隐藏越多，推理越深。** 修复：检查玩家是否收到会排除解释的信号，并能采取验证或对冲行动。
2. **误区：允许说谎就会产生诈唬。** 修复：分别写诚实、说谎、挑战与不挑战的收益、风险和反馈。
3. **误区：公开过的信息就算公开。** 修复：决定是否可查询、怎样摆放、何时失效；别把可追踪信息变成强制记忆测验。
4. **误区：手牌上限只是平衡数字。** 修复：同时检查选项搜索、循环速度、隐藏价值、持有机会成本和实体持牌。
5. **误区：有人代读就解决无障碍。** 修复：记录信息泄露、意图暴露、代办推断、时间成本与玩家同意。

## 可以有意打破的情形

- 纯悬念或故事揭晓可以让信息在行动期不可回应；要明确承诺是惊喜而不是策略推断。
- 记忆游戏可以有意不提供查询；要明确记忆是核心技能，并测试目标玩家与替代版本。
- 社交表演游戏可以让语气、目光和关系成为材料；不得把游戏表现推断成现实诚实、人格或能力。
- 完全公开的组合游戏可以没有私密状态；仍要管理信息量、远座读取和查询。
- 数字辅助可秘密分发与验证信息；仍要让玩家知道权限、错误恢复、设备共享和数据边界。

## 20 分钟练习：一张牌，五种知道

选一张当前原型中的牌，依次写：牌主知道什么、其他玩家看见什么、他们能推断什么、有人能声明什么、什么时候可以验证。然后把牌从抽取走到终局，标出每次状态改变和合法回应。

示例输出：牌主私知角色；公开宣称 Duke 不改变牌面；任何人可在行动结算前挑战；证明成功后牌公开一瞬、洗回并补新牌，旧知识失效；失去影响时永久公开。下一版只把挑战窗口印到角色辅助上。

## 完成信号

- 核心信息均有角色—时点—来源—可靠度—回应字段；
- 至少一张牌能从抽取追到终局，顺序、上限、补牌和弃置可执行；
- 至少一条推断包含两种合法解释、验证/对冲、猜错代价和反馈；
- 沟通与协助不会靠设计师临场裁定谁能说、看、记或代做；
- 新手能区分知道、相信、声明、验证和揭示，并在中断后恢复；
- 下一版只改变一个信息字段，且已写支持与反驳信号。

## 证据边界

本契约综合五份规则案例、设计师与中文实践、桌游/HCI 与相邻识谎研究、两篇无障碍长评和非代表性玩家症状。它支持把隐藏信息写成角色化生命周期、把手牌写成状态链、为诈唬补充挑战与反馈、把沟通限制写成渠道协议，并记录协助泄露与记忆劳动；它不提供最佳手牌数、线索数、隐藏角色比例、诈唬率、挑战成本、揭示频率、记忆阈值或难度公式。完整来源见 [专项研究](../research/HIDDEN_INFORMATION_HAND_ECONOMY_01.md)。
