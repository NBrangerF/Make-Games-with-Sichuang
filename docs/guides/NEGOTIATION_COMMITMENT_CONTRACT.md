# 谈判与承诺契约

适用：原型里写了“玩家可以自由交易/结盟/承诺”，但桌谈被忽略、交易拖时、强势玩家垄断对话、未来承诺争议多，或联盟直到终局才突然决定赢家。

## 五步

1. 写目标社会体验和不可接受结果：互利交换、威胁、试探、共同承担风险、公开政治或短期联盟，不能只写“互动多”。
2. 列谈判对象与外部选项：谁拥有什么资源、权限、信息、否决和时机；不成交时每方还能做什么。
3. 画交易生命周期：报价、反报价、接受、记录、结算、到期、违约、修复；逐条标约束、非约束或条件约束。
4. 检查联盟与渠道：谁被排除、第三方怎样受影响、联盟怎样进入和退出；私聊/公开、顺序/同时、口头/书面与限时给谁增加负担。
5. 只改一个变量：约束性、结算时机、记录组件、谈判窗口、公开范围或退出规则；预先写期望行为与反驳信号。

## 最小记录表

| 字段 | 示例 |
|---|---|
| 报价 | 甲给乙 2 金，换乙本轮不封锁北港 |
| 听见者 | 全桌公开 |
| 接受 | 乙说“接受”并拿取交易标记 |
| 立即部分 | 甲立刻交 2 金，约束 |
| 未来部分 | 乙本轮不封锁，非约束；回合结束到期 |
| 违约可见 | 乙放置封锁棋时由全桌识别 |
| 第三方影响 | 丙失去北港路线，但可公开反报价 |
| 联盟/退出 | 不构成持续联盟；没有跨轮共同资产 |

## 不要混在一起的证据

- 成交数不等于有意义谈判；补拒绝、反报价、外部选项和第三方反应。
- 守约率不等于体验安全；补玩家怎样理解背叛、是否感到被迫或被排斥。
- 交易时长不等于投入；补谁在发言、等待、被打断和错过状态。
- 终局 kingmaking 不应脱离全局历史；补此前承诺、救援、违约与仍可追求的目标。
