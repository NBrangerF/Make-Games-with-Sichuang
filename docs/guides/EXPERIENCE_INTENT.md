# 指南 01：把题材变成可测试的体验意图

状态：review  
阶段：体验意图  
核心阅读：8 分钟

## 你要得到什么

“一款海上贸易游戏”还不是设计目标。把它改写成下面这样：

> 玩家要在公开航线与有限货舱之间做取舍；我预计他们会为了长期位置优势，至少一次放弃眼前得分。

这句话仍可能是错的，但它已经可以被测试。读完本指南，你会得到一段包含玩家决定、压力、预期行为和设计边界的体验意图，以及一个能被测试推翻的问题。

## 1. 先写玩家反复做什么

从动词开始，不从世界观开始：玩家反复在什么与什么之间选择？

海上贸易例：玩家反复在“立刻交货得分”和“把货物留给更远港口”之间选择。题材此时不是装饰；它帮玩家理解为什么现在的货物与未来的航线有关。

## 2. 写决定为何困难

有两个按钮不代表有两个有意义的选择。补上稀缺资源、信息不完整、时间压力或其他玩家带来的代价。

海上贸易例：货舱只有三格，港口需求公开，但对手下一步航线未知。立刻交货释放空间，保留货物则可能错过当前得分。

## 3. 把形容词换成可观察行为

“紧张”“有策略”“沉浸”很难直接验证。写你预计能在桌面上看到什么，并允许玩家做出相反行为。

海上贸易例：玩家会至少一次放弃当前得分，保留货物争夺下一港口。如果所有人总是立即交货，这个体验假设就没有得到支持。

MDA 可以帮助设计者从规则向运行中的行为、再向体验追问，但它不是保证情绪出现的公式。触感、限制、协作动作和信息结构都可能承载情绪；同一安排也会因玩家经历与群体不同而产生不同反应。

## 4. 给反馈划边界

写目标玩家、时长、复杂度，以及本轮故意不追求什么。否则任何反馈都可能把游戏改成另一款游戏。

海上贸易例：面向熟悉轻中策的 3–4 人，目标时长 60 分钟；本轮不验证历史模拟精度，也不追求零随机。

边界不是拒绝不喜欢的意见。反复出现的可用性障碍仍应记录，只是“增加更多策略深度”这类方向性建议要回到原目标判断。

## 5. 只问一个能被否定的问题

不要问“好玩吗”。把行为预测改写成问题：

> 玩家会为了后续航线优势，主动放弃至少一次眼前得分吗？

这个问题会影响你第一版需要做什么。只要港口、货舱、货物和最短的交货循环足以产生取舍，就不必先做完整地图或全部卡牌。

## 常见误区

| 误区 | 下一动作 |
|---|---|
| 只写“有趣、策略、沉浸” | 改写成玩家决定、压力和可观察行为 |
| 把剧情设定当成体验 | 追问玩家每回合做什么，题材怎样改变对后果的理解 |
| 直接指定一长串机制 | 先写机制要产生的行为，再把机制当作待测假设 |
| 假设所有玩家感受相同 | 记录目标玩家和语境，并保留不同反应 |

## 何时故意不照这个顺序

主题先行、机制先行或从一种触感开始都可以。`Wingspan` 的回顾展示主题如何映射到资源过程，`Undaunted` 的开发记录展示机制组合也可以先出现。这里要求的是说清两侧之间尚待验证的关系，不是规定唯一入口。

抽象、安静或合作游戏也不一定需要角色冲突。目标与阻力可以来自信息、时间、空间或共同任务。旧课程里“主题必须有冲突”的表达更适合作为构思问题，而不是普遍定律。

## 20 分钟练习：四句体验意图

1. 玩家反复在什么与什么之间选择？
2. 什么让这个决定有代价？
3. 你预计在桌面上看到什么行为？
4. 这一轮只问哪个测试问题？

完成信号：句子里有玩家动作；至少一个压力条件；一个可能被反驳的预测；一个明确不在本轮验证的目标。
