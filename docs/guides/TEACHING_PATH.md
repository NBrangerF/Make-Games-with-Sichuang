# 专项指南：让玩家先做对第一件事

状态：review  
阶段：规则与信息  
核心时间：12 分钟

## 你要得到什么

一张不生成理解分的单任务学习路径：当前版本和玩家语境、一个可观察动作、现在必须知道与可以延后的信息、解释后的桌面实践、卡住时的恢复入口、第一次偏离和下一版单一改动。

## 贯穿例

海上贸易游戏有十种港口奖励。首局不先讲完所有组合，只验证新玩家能否看懂一座港口的需求、选择一件货物并完成一次合法交货。讲完目标和当下步骤后，让玩家实际执行；如果货舱已满，观察他能否从个人辅助进入容量规则。

教学完成的证据不是讲者说完，也不是玩家点头，而是这个玩家在这个版本与帮助条件下做出第一个有意义动作，并能从卡点恢复。

## 五步路径

### 1. 冻结一个学习任务和语境

写版本、玩家经验与语言、人数、环境、主要媒介和一个动作。不要把“理解整款游戏”写成任务。

例：`v0.9；两名第一次接触项目的中文轻中策玩家；实体同桌；只完成一次合法交货。`

### 2. 分开现在要用与可以延后

只保留完成当前决定所需的目标、对象、动作和反馈。为少见例外、完整计分和策略建议指定一个真实出现时刻。

例：现在说明港口需求、交货和收入；货舱第一次装满时再指出容量入口；终局套装分暂不讲。

### 3. 解释后立刻安排桌面动作

使用真实组件安排一个可重置、低风险的决定。先写可观察的成功动作，不问“懂了吗”。

例：玩家从三个港口中指出合法目标，移动一枚正确货物并自己更新金币。

### 4. 给卡住时的查询与恢复入口

为高频步骤和易忘限制指定玩家辅助、索引、图示或数字入口。用玩家真实说出的词测试入口。

例：玩家问“船装满怎么办”，先在个人辅助找到容量图标，再按“货舱已满”找到弃置规则。

### 5. 记录第一次偏离并只改一处

记录最早的错误动作、停顿或换词；保留实际查看路径和主持人介入。下一版只改最早的上游信息，再用同一任务复测。

例：玩家先翻终局页并把订单当货物；主持人在 `03:10` 指向组件表。下一版只给订单背面增加同名标签。

## 常见误区

| 误区 | 修复动作 |
|---|---|
| 按规则书目录从头讲到底 | 按玩家下一步决定排序；查询结构另设入口 |
| 玩家点头或复述正确就宣布成功 | 让玩家执行、更新状态并尝试自己恢复 |
| 把全部规则压成一张小字辅助 | 为一个高频任务和明确持有人设计辅助 |
| 默认视频或互动教程比纸质更好 | 在同一任务、玩家与环境中比较，并保留版本兼容的查询入口 |
| 看到错误立即解释 | 先记录第一次偏离和介入时点，再帮助玩家继续 |

## 何时调整方法

- 隐藏身份、谜题或推理游戏不宜正式执行示例决定时，使用公开练习局面、虚构组件或结束后的反向教学。
- 极短派对游戏可以在一轮演示中完成上手，但仍应记录第一次无法开始的位置。
- 熟悉类型的玩家可跳过渐进教学，直接使用完整规则与查询入口。
- 数字教程可能断网、失效或过期；仍需维护与同一版本兼容的盒内规则和勘误路径。

## 完成信号

- 版本、玩家语境和一个学习任务已冻结；
- 现在必须知道与可以延后的信息已经分开；
- 解释后有一次可重置、可观察的桌面动作；
- 卡点有能从玩家真实用词进入的恢复路径；
- 第一次偏离、主持人介入和下一版单一改动都被保留。

## 证据边界

现有证据包括小样本学术研究、单一游戏案例、职业编辑/设计师实践、玩家博客和商业工具说明。它们不能给出统一教学顺序或媒介排名。本站路径是这些来源与《狗头人之桌游设计指南》预读版第 50–53 页规则写作/按规则试玩结构的产品转译，仍需真实中文新手验证。完整研究见 [专项研究 06](../research/TEACHING_RULES_01.md)。
