# 落桌 · 桌游设计馆

一座面向桌游设计学习者的资源馆；系统阅读、机制与主题库及游戏案例提供中文和英文。项目不把“理论”“经验”“工具”分割开，而是把它们放回真实的设计迭代中：从体验目标，到原型、测试、规则、呈现与发布。

## 当前状态

- 当前扩展：96 篇机制/主题/教学/比较文章与 18 款多角度案例已发布；最终内容与来源验收进行中。
- 阅读主线：28 章与 13 篇选读，一个内容版本、中文和英文。
- 正式网站：[落桌](https://luozhuo-tabletop-design.vercel.app/)
- 长期目标：形成可学习、可操作、可持续维护的桌游设计资源网站
- 当前产物入口：[项目索引](docs/INDEX.md)
- 当前维护入口：[机制、主题与案例内容维护](docs/handovers/2026-09-11-library-maintenance.md)

## 运行 MVP

使用 Node.js 24 与现有 pnpm；这是当前构建与直接运行 TypeScript 检查已验证的环境。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

类型检查使用 `pnpm check`，生产构建使用 `pnpm build`。启动本地服务后，可用 `QA_BASE_URL=http://127.0.0.1:5173 pnpm qa` 运行浏览器回归；脚本默认调用 macOS 的系统 Chrome。`pnpm content:check` 会先检查内容、权利/隐私边界、新手测试包、无障碍契约、分片与导航守卫。

早期 MVP 模块包含 6 篇核心指南、32 篇专题指南、574 条逐条审阅资源、34 个任务型阅读入口、322 条可追溯 Claim、287 个概念词条、5 张理论框架卡、57 份本地资料记录与 19 项正式工具。四个主视图、19 项工具、34 个策展入口和 898 个方法条目已有可分享 hash 地址；287 个概念全部可进入正式工具，其中 276 个还能进入实际引用它们的专题。`pnpm qa:concept-actions` 以 12 项守卫检查双向关系和非推荐边界。这些结构证据不替代真实浏览器、无障碍技术或真人新手测试。

本地课程资料清单可用 `pnpm local-materials:index` 重建。脚本只生成相对路径、文件元数据和哈希，不复制原件或提取文本到仓库。

57 份本地课程资料另有逐文件发布就绪门禁：当前全部仅限内部参考，公开站点只采用另写的原创摘要，发布候选数为 0。`pnpm local-publication:check` 会验证四个资料群的 11 道证据门、清单一一覆盖、禁入绝对路径/原文和候选拒绝分支；它不是法律、隐私、机构或未成年人保护批准。

未来玩家经验、设计日志和案例贡献目前只有默认私有的离线协议，不开放网页投稿。可用 `pnpm contribution:check` 验证安全默认值、完整发布候选和 11 个必须拒绝的分支；该检查不是法律、伦理或儿童保护批准。

新增或改名资源、概念后运行 `pnpm content:indexes` 重建首屏使用的轻量索引；也可分别运行 `pnpm resources:index`、`pnpm glossary:index`。资源索引命令现同时生成 34 个任务入口包；`pnpm content:check` 会拒绝过期、重排、缺失或包含额外字段的索引/入口包。进入资源库默认只加载轻量入口索引与当前 7–8 条策展资源；只有“查看全部”或资源审阅工作台会加载 574 条完整目录。方法页默认只加载 5 张框架卡，287 个完整词条和 32 篇专题指南只在进入各自标签时加载。`pnpm qa:resource-entries` 和 `pnpm qa:method-sections` 守卫这些分片、预取和失败恢复契约。

外部资源链接快照可用 `pnpm resources:health` 重建。自动巡检只区分可达、被拦截、明确失效与网络错误，不会自动删除资源；人工内容核验与网络健康是两套独立信号。

章程所需的两轮中文新手形成性测试现有统一主持包、空白会话、虚构示例、schema 与 25 项守卫，可运行 `pnpm qa:beginner-campaign`。它要求 Round A 先找阻断并单变量修订，Round B 再用至少 5 名新手验证定位、其中至少 4 名完成意图到测试记录与导出闭环。当前真实参与者会话仍为 0；机器生成的合格样本只测试校验器，不计入章程证据。

公开试用现有平台无关发布包：`#privacy` 数据说明、二次本地清理、显式 Vite base、试用期 `noindex`、静态主机/Vercel 安全响应头、缓存规则、Go/No-Go、烟测与回滚契约。`pnpm qa:release` 检查仓库准备度；真实部署还必须提供托管方、隐私联系人和构建 ID，并通过 `pnpm qa:release:strict`。Vercel 正式站已部署；部署边界见[公开试用发布契约](docs/product/PUBLIC_TRIAL_RELEASE.md)，当前发布核查方法见[内容维护指南](docs/handovers/2026-09-11-library-maintenance.md)。

键盘与语义硬门现有 WCAG 2.2 一手依据、K1–K8 键盘任务、S1–S8 屏幕阅读器任务和 18 项构建守卫。首轮 Browser/IAB 发现并修复 skip-link 与 hash 路由冲突，同时移除工具内四个嵌套主地标；`pnpm qa:a11y-contract` 已进入内容门。修后焦点、抽屉焦点圈定、VoiceOver/NVDA 和真实残障玩家任务仍未完成，因此不能声称 WCAG 合规或“无障碍通过”。

## 工作原则

1. 面向行动：每个知识点都要能导向问题、练习、模板或工具。
2. 证据分层：学术研究、设计师经验、玩家讨论和商业内容分别标注。
3. 来源可追溯：记录作者、链接、访问时间、适用阶段与版权/复用注意事项。
4. 原文不搬运：以摘要、评论和指路为主；可复用内容必须核对许可。
5. 小步迭代：每个阶段都有范围、产物、验证结果和下一步。
